문법

겉은 Go와 Python을 닮았고, 블록은 :에서 ;;까지다. 들여쓰기에는 의미가 없다.

# 한눈에 보는 fung
import fs

fn total_size(dir):
  fs.list(dir)!
    |> map(f => fs.stat("${dir}/${f}")!.size)
    |> fold(0, (acc, n) => acc + n)
;;

size = total_size(".")
label = size > 1_000_000 then "big" else "small"
print("${size} bytes (${label})")

어휘

주석

#부터 줄 끝까지. 다른 주석 형식은 없다(//는 정수 나눗셈이다). 파일 첫 줄의 #!/usr/bin/env fung도 그냥 주석이다.

이름과 태그

  • 소문자, _, 또는 대소문자가 없는 글자(한글 등)로 시작하면 이름: file_list, _cache, 파일목록.
  • 대문자로 시작하면 태그: Ok, Circle. 선언 없이 쓴다(값과 타입).
  • 이름 표기는 snake_case. _로 시작하는 최상위 이름은 모듈 밖에서 보이지 않는다.
  • 이어지는 글자는 글자·숫자·_와 결합 문자(유니코드 UAX #31의 식별자 규칙): हिंदी, café. 이름은 NFC로 정규화해서, 조합형과 분해형으로 쓴 é는 같은 이름이다.

예약어

fn if else then match when for in not and or return import as type test assert true false nil

이름만 올 수 있는 세 자리, 곧 . 뒤, 맵 리터럴의 키, 맵 패턴의 키에서는 예약어도 그냥 이름이다. JSON의 type 같은 키를 그대로 쓰기 위해서다. 변수나 함수 이름으로는 쓸 수 없다.

event = {type: "deploy", match: "api-*"}
print(event.type, event.match)

숫자

형태예비고
정수42 1_000_00064비트. _는 숫자 사이에만.
진법0xff 0o17 0b1010정수.
실수3.14 2.5e-3 1e9소수점 양쪽에 숫자가 필요하다(.5, 1.은 안 됨). 지수가 있으면 실수.

문자열

  • "…": 이스케이프와 보간 ${식}. 이스케이프는 \n \t \r \\ \" \$ \u{1F600}뿐이고, 모르는 이스케이프("C:\new")는 컴파일 에러다. 실제 줄바꿈은 넣을 수 없다.
  • `…`: 원시 문자열. 이스케이프도 보간도 없고, 여러 줄이 된다. 정규식과 Windows 경로에 쓴다.
  • 보간 안에는 어떤 식이든 온다: "${m["k"]}".
  • 길이와 인덱스는 글자(유니코드 코드 포인트) 단위다. len("참치") == 2, "참치"[0] == "참". 따로 문자 타입은 없다.
name = "fung"
print("hello, ${name}! ${1 + 2}")
pattern = `^\d{4}-\d{2}$`

심볼

'ok, 'not_found. 이름만 있는 값으로, 선언 없이 쓰는 열거형이다. 문자열과는 다른 타입이라 'ok == "ok"는 거짓이다.

기간

500ms 30s 1.5s 1h30m. 단위는 ms s m h이고 큰 단위부터 쓴다. 숫자 바로 뒤에 붙여야 한다(30 s는 숫자와 이름 s).

문장과 블록

  • 문장은 줄바꿈이나 ;로 나눈다. 빈 문장은 괜찮다.
  • 블록은 :로 열고 ;;로 닫는다. 블록의 값은 마지막 식의 값이다.
  • 들여쓰기는 의미가 없다. 같은 코드를 한 줄로도 쓸 수 있다.
fn classify(n):
  if n < 0:
    "negative"
  else if n == 0:
    "zero"
  else:
    "positive"
  ;;
;;

fn classify_short(n) = if n < 0: "negative" else if n == 0: "zero" else: "positive" ;;

;;는 렉서가 항상 가장 길게 자른다. a;;는 a와 블록 끝이다.

줄 이어짐

줄바꿈은 문장 끝이지만, 다음 셋 중 하나면 다음 줄로 이어진다.

  1. 줄이 식을 끝낼 수 없는 토큰으로 끝날 때: 이항 연산자(+ - * / // % ** == != < > <= >= in ?? |> .. ..= and or), not, ,, =, =>, ->, ., 여는 괄호, 블록 시작 :.
  2. 다음 줄이 이어짐 전용 토큰으로 시작할 때: |> . ?? and or then else. 이 토큰들로는 문장을 시작할 수 없으니 모호하지 않다.
  3. 괄호 () [] {} 안: 줄바꿈은 공백이다. 단, 괄호 안에서 fn(x):처럼 블록이 열리면 그 ;;까지는 줄바꿈이 다시 문장 구분자다.
names = ["b.log", "a.txt", "c.log"]
logs = names
  |> filter(n => ends_with(n, ".log"))
  |> sort
ok = len(logs) > 0
  and all(logs, n => n != "")
print(logs, ok)

맵

  • {name: "a"}는 {"name": "a"}의 축약이다. 식별자 모양이면 대소문자와 상관없이 축약된다({DB_HOST: h}).
  • 값이 같은 이름의 변수면 키만 쓴다: {name, port}는 {name: name, port: port}.
  • 같은 키를 두 번 쓰면 컴파일 에러. 없는 키를 읽으면 런타임 에러이고, 기본값이 필요하면 get(m, k, d)를 쓴다.
  • 수정된 사본은 함수로 만든다: put, merge, remove.

연산자

산술

  • + - *, /는 항상 실수 결과(7 / 2 == 3.5), //는 내림 나눗셈(7 // 2 == 3), %는 //와 짝인 나머지(-7 % 3 == 2), **는 거듭제곱(2 ** 10 == 1024, 2 ** -1 == 0.5).
  • 정수와 실수를 섞으면 실수. 0으로 나누기, 정수 오버플로, NaN·Inf는 에러.
  • +는 문자열·리스트를 이어 붙인다. "a" + 1은 에러, 반복은 repeat(s, n).

비교·논리·포함

  • ==와 !=는 값 비교. 비교는 연쇄하지 않는다: a < b < c는 문법 에러(a < b and b < c).
  • and or not은 bool만 받고 단락 평가한다. 빈 리스트나 0을 거짓으로 보지 않는다.
  • x in c / x not in c: 리스트는 원소, 맵은 키, 문자열은 부분 문자열, 범위는 정수 포함 여부.

범위

a..b는 b를 빼고, a..=b는 넣는다. 정수만 된다.

파이프

|>는 실행 중의 연산이 아니라 컴파일할 때 평범한 호출로 바뀌는 문법 설탕이다. 규칙은 둘뿐이다.

  • x |> f(a, b)는 f(x, a, b): 오른쪽이 호출이면 왼쪽 값을 맨 앞 인자로 넣는다.
  • x |> f는 f(x): 오른쪽이 이름뿐이면 그것으로 부른다.

이어 쓰면 안쪽부터 감싸는 호출이 된다. xs |> filter(f) |> map(g)는 map(filter(xs, f), g)와 바이트코드까지 같다. 비용은 없고, 데이터가 흐르는 순서대로 읽힌다는 것이 전부다. 이름 인자도 그대로 따라간다: xs |> conc.pmap(f, limit: 2)는 conc.pmap(xs, f, limit: 2).

그래서 내장 함수는 모두 다루는 대상을 첫 번째 매개변수에 둔다: 리스트 함수는 리스트가(filter(xs, f)), 문자열 함수는 문자열이(split(s, sep)), 맵 함수는 맵이(put(m, k, v)) 먼저다. Python의 map(f, xs)나 데이터를 마지막에 두는 Haskell·OCaml과 달리 Elixir와 같은 쪽이다. 직접 만드는 함수도 이렇게 두면 파이프에 그대로 이어진다.

line = " ERROR,disk full "
fields = line |> trim |> lower |> split(",")
cfg = {host: "localhost"} |> put("port", 8080) |> merge({debug: false})
print(fields, cfg |> keys)

대상이 첫 자리가 아닌 함수에는 람다로 넘긴다: 5 |> (n => scale(2, n)).

파이프 안에서 _를 쓰지 않는다. "a.txt" |> path.join("/tmp", _)는 "/tmp/a.txt"가 아니라 함수다. 파이프가 "a.txt"를 첫 자리에 넣은 뒤에도 _ 자리는 비어 있으므로, 결과는 path.join("a.txt", "/tmp", _)를 부분 적용한 함수가 된다. 에러 없이 함수 값이 다음 단계로 흘러가므로 알아차리기 어렵다. 파이프로 넘길 값은 파이프가 첫 자리에 넣고, _는 map(path.join(dir, _))처럼 다른 함수에 넘길 함수를 만들 때만 쓴다.

"a.txt" |> path.join("/tmp", _)       # 함수가 나온다: (x) => path.join("a.txt", "/tmp", x)
path.join("/tmp", "a.txt")            # 원하던 것
files |> map(path.join("/tmp", _))    # _의 올바른 쓰임: map에 넘길 함수를 만든다

인덱스·슬라이스·필드

  • xs[i]: 음수는 뒤에서부터(xs[-1]). 범위를 벗어나면 에러.
  • xs[a..b], xs[..b], xs[a..], xs[a..=b]: 리스트와 문자열의 슬라이스. 범위를 벗어나면 에러이고, 있는 만큼만 원하면 take·drop을 쓴다.
  • m.name은 m["name"]과 같다. 모듈의 fs.read도 같은 규칙이다.
  • 튜플은 인덱스로 꺼내지 않는다. 패턴으로 꺼낸다: (a, b) = pair.
xs = [10, 20, 30, 40]
print(xs[-1], xs[1..3], xs[..2], "참치김밥"[1..3])

변수와 스코프

대입 x = 식은 이름을 값에 붙인다. 같은 이름에 다시 대입할 수 있지만 값 자체를 바꾸지는 않는다. 규칙은 넷이고 예외는 없다.

  1. 이름은 위에서 아래로 묶인다. 대입보다 앞에서 읽으면 컴파일 에러(E0204).
  2. 최상위 fn은 프로그램 시작 전에 모두 만들어진다. 그래서 순서와 상관없이 서로 부를 수 있다.
  3. 함수 값은 만들어질 때 보이는 변수의 값을 복사한다. 나중에 그 이름에 다시 대입해도 함수가 가진 값은 그대로다.
  4. 블록은 바깥 이름을 읽을 수 있지만 대입할 수 없다(E0205). 블록 안에서 만든 이름은 밖으로 새지 않는다(E0206).

여기서 따라 나오는 것: 최상위 fn은 최상위 변수를 볼 수 없다(만들어질 때 아직 없으므로). 설정 값은 인자로 넘긴다. 람다와 익명 함수는 그 자리에서 만들어지므로 그때까지의 변수를 복사한다.

dir = "./logs"
fn clean() = fs.list(dir)       # E0204: clean은 dir보다 먼저 만들어졌다
fn clean(dir) = fs.list(dir)    # 맞는 방법

total = 0
for f in files:
  total = total + 1             # E0205: 블록 안에서 바깥 변수에 대입할 수 없다
;;
total = len(files)              # 값을 식으로 만든다

함수

# 식 하나짜리
fn add(a, b) = a + b

# 블록 본문: 마지막 식이 반환값
fn report(dir):
  n = len(dir)
  "${dir}: ${n}"
;;

# 람다: 본문은 식 하나
double = x => x * 2
both = (a, b) => a + b
later = () => print("run")

# 익명 함수: 여러 문장이 필요할 때
shout = fn(s):
  t = upper(s)
  t + "!"
;;

print(add(1, 2), report("logs"), double(4), both(1, 2), shout("hi"))
later()

인자

  • 순서는 필수 → 기본값 있는 것 → 마지막에 ...rest 하나(남는 위치 인자를 리스트로 받음).
  • 기본값은 호출할 때마다 왼쪽부터 평가되고, 앞 인자를 참조할 수 있다. 기본값과 ...rest는 fn과 익명 fn(…):에서 쓴다(람다 =>에는 없다).
  • 호출할 때 위치 인자 뒤에 이름 붙인 인자를 쓴다: exec(cmd, cwd: dir). 내장 함수도 똑같다.
  • 인자 개수가 맞지 않거나, 같은 인자를 두 번 주거나, 모르는 이름이면 런타임 에러.
  • 매개변수 자리에 패턴을 쓸 수 있다: fn dist((x, y)) = …, pairs(m) |> map(((k, v)) => k).
fn greet(name, greeting = "hello", ...extra) = "${greeting}, ${name}${join(extra)}"
print(greet("fung"), greet("fung", greeting: "hi"), greet("fung", "yo", "!", "?"))

반환

마지막 식의 값을 돌려준다. 일찍 빠져나갈 때는 return 식(값 없으면 nil). return은 감싸는 함수나 람다에서 돌아오고, for 본문과 진입 파일 최상위에서는 쓸 수 없다(최상위에서는 exit()).

부분 적용

호출 인자의 _는 그 자리를 비운 새 함수를 만든다. f(a, _)는 x => f(a, x)이고, a는 그 자리에서 한 번 평가된다. 자동 커링은 없다. 파이프의 오른쪽에서는 쓰지 않는다(파이프의 경고).

import path
files = ["a.txt", "b.txt"]
print(files |> map(path.join("/tmp", _)))

꼬리 호출

함수 본문의 마지막 식, 꼬리 위치에 있는 if·match·then … else의 각 가지, 꼬리 위치의 x |> f(a)에 있는 호출은 프레임을 재사용한다. 상태가 있는 반복은 이렇게 쓴다. 자기 재귀뿐 아니라 모든 꼬리 호출이 대상이다.

fn count(n, acc) = n == 0 then acc else count(n - 1, acc + 1)
print(count(1_000_000, 0))

꼬리가 아닌 것: 연산자의 피연산자(1 + f()), f()!·f()?·f() ?? b, 다른 호출의 인자, and·or의 오른쪽. 반환 타입을 적은 함수도 제외된다. 꼬리가 아닌 재귀는 깊이 100,000에서 "stack overflow" 에러다.

조건

fn sign(n):
  if n > 0:
    "+"
  else if n < 0:
    "-"
  else:
    "0"
  ;;
;;
print(sign(5), 3 > 2 then "yes" else "no")
  • if는 식이다. else가 없고 조건이 거짓이면 값은 nil.
  • c then a else b는 한 줄짜리 조건 식이다. else가 반드시 있어야 하고, 사슬로 이을 수 있다.
  • 조건은 bool이어야 한다. 다른 값이면 런타임 에러.

match와 패턴

match value:
  0                  => …    # 리터럴 (음수, 문자열, 심볼, 기간, true/false/nil 포함)
  'ok                => …    # 심볼
  Ok(x)              => …    # 태그와 인자
  (a, b)             => …    # 튜플
  []                 => …    # 빈 리스트
  [first, ...rest]   => …    # 머리와 꼬리. 꼬리 이름은 생략 가능: [first, ...]
  {name: n}          => …    # 맵의 일부 키 (다른 키는 무시)
  {kind, line}       => …    # {kind: kind, line: line}의 축약
  x when x > 100     => …    # guard
  'a | 'b            => …    # 여러 패턴 중 하나
  _                  => …    # 나머지 전부
;;
  • 절의 본문은 다음 절이나 ;;가 나올 때까지의 문장들이다. 한 줄로도 쓴다: match x: 0 => "zero"; _ => "other" ;;.
  • 아무 패턴도 맞지 않으면 런타임 에러(E0601).
  • 패턴 안의 이름은 항상 새로 묶는다. 바깥 변수와 비교하려면 guard를 쓴다: y when y == x => ….
  • | 대안들은 같은 이름들을 묶어야 한다. 한 패턴에 같은 이름을 두 번 쓸 수 없다.
  • 괄호 없는 태그 패턴 Ok는 심볼 'Ok와 같은 뜻이 아니다. Ok(_)처럼 인자 모양까지 쓴다.

구조 분해 대입

대입의 왼쪽에도 같은 패턴을 쓴다. 맞지 않으면 런타임 에러(E0602).

(q, r) = (7 // 2, 7 % 2)
[top, ...rest] = ["a", "b", "c"]
{name, port: p} = {name: "api", port: 8080}
print(q, r, top, rest, name, p)

for

for는 map의 설탕이고 결과로 리스트를 돌려준다. 순회 대상은 리스트, 범위, 채널(값이 올 때마다, 닫히면 끝)이다. 문자열과 맵은 chars(s), pairs(m)으로 리스트로 바꿔서 돈다.

squares = for x in 1..=3: x * x ;;
for (k, v) in pairs({a: 1, b: 2}):
  print("${k} = ${v}")
;;
print(squares)

본문이 사실은 람다이므로 for 본문 안의 return과 ?는 컴파일 에러다. 찾기는 find, 검사는 all·any, 누적은 fold를 쓴다. while은 없다.

누적과 재귀의 비용. 리스트와 맵은 불변이지만 사본이 원본과 구조를 공유하므로, fold로 acc + [x]나 put(acc, k, v)를 쌓는 것과 [x, ...rest]·xs[1..]로 꼬리를 떼는 재귀는 모두 선형이다(2만 개에 수십 ms). 피할 것은 둘이다. 문자열을 acc + s로 쌓지 말고 리스트에 모아 join하고, 앞에 붙이기 [x] + acc는 매번 전체를 복사하므로 뒤에 붙인 뒤 reverse한다. 자세한 것은 컬렉션의 내부.

결과값과 에러

실패할 수 있는 함수는 Ok(값)이나 Err(내용)을 돌려준다. 표준 라이브러리의 Err 내용은 {kind: 심볼, message: 문자열, …} 맵이다. 세 축약 연산자로 다룬다.

왼쪽 값x!x?x ?? b
Ok(v)vvv
Err(e)프로그램 중단(종료 코드 1)현재 함수에서 Err(e)를 반환b
nil런타임 에러nil 그대로b
그 외런타임 에러런타임 에러그 값 그대로
 
text = fs.read("a.json")!                    # 스크립트: 실패하면 멈춘다
data = json.parse(text)?                      # 함수 안: 실패를 호출자에게 넘긴다
port = env("PORT") ?? "8080"                  # 없으면 기본값
match fs.read(p):
  Ok(text)                => use(text)
  Err({kind: 'not_found}) => print("no file")
  Err(e)                  => print(e.message)
;;

"여기 오면 버그"를 말할 때는 fail(msg)로 런타임 에러를 낸다. x ?? fail("config.port is required")처럼 ??와 짝이 맞는다. 에러를 잡는 구문은 없고, 정리는 fs.with_open 같은 감싸는 함수와 at_exit로 한다.

모듈

import fs                              # 표준 라이브러리: 이름
import "./lib/rename"                  # 내 파일: import하는 파일 기준 상대 경로, .fung 생략
import "./lib/rename" as rn            # 별칭
import "./lib/rename" (slug, to_kebab) # 이름만 직접 가져오기
  • 파일 하나가 모듈 하나다. 모듈 이름은 파일명이고, 이름 규칙에 맞지 않으면(my-lib.fung) as가 필요하다.
  • _로 시작하는 최상위 이름은 비공개. 나머지는 공개다. 가져온 이름은 다시 내보내지 않는다.
  • import된 파일의 최상위에는 import, fn, type, test, 이름 = 식만 올 수 있다. 처음 import될 때 한 번 실행되고 캐시된다.
  • 순환 import는 컴파일 에러이고 순환 경로 전체를 보여 준다. 진입 파일을 import할 수도 없다.
  • 모듈은 값이다: 함수 인자로 넘길 수 있고 type_of(fs) == 'module.

타입 표기

type Shape = Circle | Rect             # 별칭: 같은 모듈 안에서만

fn area(s: Shape) -> num = match s:
  Circle(r)  => 3.14 * r * r
  Rect(w, h) => w * h
;;
fn find_user(id: int) -> map | nil = …
fn load(p: str) -> Ok | Err = …
  • 타입 이름: int float num(int 또는 float) str bool nil sym dur time list map tuple range fn module task channel agent any, 그리고 태그 이름.
  • |로 유니온을 만든다. list[int]처럼 원소 타입을 적을 수 있지만 런타임은 바깥 타입만 검사한다.
  • 인자와 반환 타입에만 쓴다. 맞지 않으면 런타임 에러(E0403, E0404). 변수에는 쓰지 않는다.
  • 타입 이름은 값 이름과 다른 이름 공간이다. list = [1]이라는 변수가 있어도 x: list는 타입이다.

테스트와 디버깅

fn half(n) = n // 2

test "half rounds down":
  assert half(5) == 2
  assert half(-5) == -3
;;

# [파일:줄] half(10) = 5 를 표준 에러로 찍고 값을 돌려준다
x = dbg(half(10)) + 1
print(x)
  • test "이름": … ;;는 최상위에만 둔다. fung run은 무시하고 fung test가 실행한다. 블록 하나가 실패해도 다음 블록이 돈다. 다만 exit(n)이 불리거나(띄운 태스크에서도) 교착이 보고되면 그 파일의 나머지 블록은 건너뛰고, 건너뛰기를 실패 하나로 센다.
  • assert 식은 어디서나 쓴다. 비교가 실패하면 양쪽 값을 보여 준다(E0807).
  • dbg(x)는 식의 소스 텍스트와 값을 찍고 값을 그대로 돌려준다.

형식 문법

파서가 그대로 옮긴 EBNF다. 식의 층은 위 우선순위 표와 같다.

EBNF 펼치기 
(* 토큰: NAME(소문자·_·대소문자 없는 글자로 시작) TAG(대문자 시작) INT FLOAT DURATION
         STRING(보간 조각 포함) RAW_STRING SYMBOL NEWLINE, 예약어, 연산자 *)

program     = body .
body        = { sep } { stmt { sep } } .
sep         = NEWLINE | ";" .
block       = ":" body ";;" .

stmt        = fn_def | import | type_alias | test_block | assert | assign | expr .
fn_def      = "fn" NAME "(" [ params ] ")" [ "->" type ] fn_body .
fn_body     = "=" expr | block .
params      = param { "," param } [ "," ] .
param       = [ "..." ] NAME [ ":" type ] [ "=" expr ] | pattern .
import      = "import" ( NAME | STRING ) [ "as" NAME ] [ "(" NAME { "," NAME } ")" ] .
type_alias  = "type" NAME "=" type .
test_block  = "test" STRING block .
assert      = "assert" expr .
assign      = pattern "=" expr .                   (* 문장 시작에서 `pattern =`를 먼저 시도 *)

expr        = lambda | then_expr .
lambda      = ( NAME | "_" | "(" [ pattern { "," pattern } ] ")" ) "=>" expr .
then_expr   = or_expr [ "then" expr "else" expr ] .
or_expr     = and_expr { "or" and_expr } .
and_expr    = not_expr { "and" not_expr } .
not_expr    = "not" not_expr | cmp_expr .
cmp_expr    = pipe_expr [ cmp_op pipe_expr ] .      (* 연쇄 없음 *)
cmp_op      = "==" | "!=" | "<" | ">" | "<=" | ">=" | "in" | "not" "in" .
pipe_expr   = coalesce { "|>" coalesce } .
coalesce    = range { "??" range } .
range       = add [ ( ".." | "..=" ) add ] .
add         = mul { ( "+" | "-" ) mul } .
mul         = unary { ( "*" | "/" | "//" | "%" ) unary } .
unary       = "-" unary | pow .
pow         = postfix [ "**" unary ] .              (* 오른쪽 결합 *)
postfix     = primary { call | index | "." key_name | "!" | "?" } .
key_name    = NAME | TAG | KEYWORD .                (* 이름 자리에서는 예약어도 이름 *)
call        = "(" [ arg { "," arg } [ "," ] ] ")" .
arg         = [ NAME ":" ] expr | "_" .
index       = "[" ( expr | [ expr ] ".." [ expr ] | expr "..=" expr ) "]" .

primary     = INT | FLOAT | STRING | RAW_STRING | DURATION | SYMBOL
            | "true" | "false" | "nil" | NAME | TAG
            | "(" expr ")" | tuple | list | map
            | if_expr | match_expr | for_expr
            | "return" [ expr ]
            | "fn" "(" [ params ] ")" [ "->" type ] block .
tuple       = "(" ")" | "(" expr "," [ expr { "," expr } [ "," ] ] ")" .
list        = "[" [ expr { "," expr } [ "," ] ] "]" .
map         = "{" [ entry { "," entry } [ "," ] ] "}" .
entry       = ( key_name | STRING ) ":" expr | NAME | TAG .
if_expr     = "if" expr ":" body { "else" "if" expr ":" body } [ "else" ":" body ] ";;" .
match_expr  = "match" expr ":" { sep } { arm } ";;" .
arm         = pattern [ "when" expr ] "=>" body .
for_expr    = "for" pattern "in" expr ":" body ";;" .

pattern     = pat_term { "|" pat_term } .
pat_term    = "_" | NAME | [ "-" ] ( INT | FLOAT ) | STRING | SYMBOL | DURATION
            | "true" | "false" | "nil"
            | TAG [ "(" [ pattern { "," pattern } ] ")" ]
            | "(" ")" | "(" pattern "," [ pattern { "," pattern } [ "," ] ] ")"
            | "[" [ pattern { "," pattern } ] [ [ "," ] "..." [ NAME ] ] "]"
            | "{" [ pat_entry { "," pat_entry } ] "}" .
pat_entry   = key_name ":" pattern | NAME | TAG .

type        = type_term { "|" type_term } .
type_term   = NAME [ "[" type "]" ] | TAG .
이전: 기조와 핵심다음: 내장 함수

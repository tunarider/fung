§레퍼런스언어 명세

함수

fn, 람다, 인자 규약, 기본값, 클로저, 꼬리 호출.

# 식 하나짜리
fn add(a, b) = a + b

# 블록 본문: 마지막 식이 반환값
fn report(dir):
  n = len(dir)
  "${dir}: ${n}"
;;

# 람다: 본문은 식 하나
double = x => x * 2
both = (a, b) => a + b
later = () => print("run")

# 익명 함수: 여러 문장이 필요할 때
shout = fn(s):
  t = upper(s)
  t + "!"
;;

print(add(1, 2), report("logs"), double(4), both(1, 2), shout("hi"))
later()
3 logs: 4 8 3 HI!
run

인자

  • 순서는 필수 → 기본값 있는 것 → 마지막에 ...rest 하나(남는 위치 인자를 리스트로 받음).
  • 기본값은 호출할 때마다 왼쪽부터 평가되고, 앞 인자를 참조할 수 있다. 기본값과 ...rest는 fn과 익명 fn(…):에서 쓴다(람다 =>에는 없다).
  • 호출할 때 위치 인자 뒤에 이름 붙인 인자를 쓴다: exec(cmd, cwd: dir). 내장 함수도 똑같다.
  • 인자 개수가 맞지 않거나, 같은 인자를 두 번 주거나, 모르는 이름이면 런타임 에러.
  • 매개변수 자리에 구조 분해 패턴(_, 튜플, 리스트, 맵, 태그)을 쓸 수 있다: fn dist((x, y)) = …, pairs(m) |> map(((k, v)) => k). fn과 람다가 같고, 리터럴((1) => …)은 매개변수가 될 수 없다(값으로 고르려면 match).
fn greet(name, greeting = "hello", ...extra) = "${greeting}, ${name}${join(extra)}"
print(greet("fung"), greet("fung", greeting: "hi"), greet("fung", "yo", "!", "?"))
hello, fung hi, fung yo, fung!?

반환

마지막 식의 값을 돌려준다. 일찍 빠져나갈 때는 return 식(값 없으면 nil). return은 감싸는 함수나 람다에서 돌아오고, for 본문과 진입 파일 최상위에서는 쓸 수 없다(최상위에서는 exit()).

부분 적용

호출 인자의 _는 그 자리를 비운 새 함수를 만든다. f(a, _)는 x => f(a, x)이고, a는 그 자리에서 한 번 평가된다. 태그도 호출 형태라 같다: map(xs, Ok(_)). 자동 커링은 없다. 파이프 오른쪽 호출의 인자로는 쓸 수 없다(E0227, 파이프).

import path
files = ["a.txt", "b.txt"]
print(files |> map(path.join("/tmp", _)))
["/tmp/a.txt", "/tmp/b.txt"]

꼬리 호출

함수 본문의 마지막 식, 꼬리 위치에 있는 if·match·then … else의 각 가지, 꼬리 위치의 x |> f(a)에 있는 호출은 프레임을 재사용한다. 상태가 있는 반복은 이렇게 쓴다. 자기 재귀뿐 아니라 모든 꼬리 호출이 대상이다.

fn count(n, acc) = n == 0 then acc else count(n - 1, acc + 1)
print(count(1_000_000, 0))
1000000

꼬리가 아닌 것: 연산자의 피연산자(1 + f()), f()!·f()?·f() ?? b, 다른 호출의 인자, and·or의 오른쪽. 반환 타입을 적은 함수는 자기 자신으로의 꼬리 호출만 프레임을 재사용한다(반환값 검사는 끝에 한 번). 꼬리가 아닌 재귀는 깊이 100,000에서 "stack overflow" 에러다.

경계 사례와 에러

인자 수가 틀리거나 없는 이름 인자를 주면 호출 자리에서 멈춘다.

fn add(a, b) = a + b
print(add(1, 2))
print(add(1))
3
error[E0407]: missing argument `b`
  --> example.fung:3:10
  |
3 | print(add(1))
  |          ^
  |
 call path (innermost first):
   example.fung:3 <entry>

같은 이름 인자를 두 번 주면 컴파일할 때 잡는다.

fn f(a) = a
print(f(a: 1, a: 2))
error[E0116]: argument `a` given twice
  --> example.fung:2:15
  |
2 | print(f(a: 1, a: 2))
  |               ^
  |

꼬리가 아닌 재귀는 깊이 100,000에서 멈춘다. 꼬리 재귀나 fold로 쓴다.

fn depth(n) = n == 0 then 0 else 1 + depth(n - 1)
print(depth(1000))
print(depth(200000))
1000

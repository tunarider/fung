문자열

글자를 나누고, 잇고, 다듬고, 바꾼다. 문자열은 불변인 바이트 열이고, 인덱스와 길이는 바이트가 아니라 글자 단위다.

문자열이란

문자열(string)은 글자를 순서대로 늘어놓은 값이다. 큰따옴표로 쓴다: "web-1". 스크립트가 다루는 데이터의 대부분, 곧 파일 내용, 명령 출력, 로그 줄, 환경 변수, HTTP 응답은 처음에 문자열로 들어온다. 그래서 문자열을 쪼개고 다듬는 일이 스크립트의 절반쯤 된다.

fung의 문자열에 대해 알아 둘 것은 다섯이다.

  • 불변이다. upper(s)는 s를 바꾸지 않고 대문자로 된 새 문자열을 돌려준다.
  • 글자 단위다. 문자열은 UTF-8로 저장되지만 len, 인덱스 s[0], 슬라이스 s[1..3]은 바이트가 아니라 글자(유니코드 코드 포인트)를 센다. 그래서 "참치"[0]은 "참"이고 len("참치")는 2다.
  • 어떤 바이트든 담는다. 문자열은 바이트 열이고, 글자 연산이 그것을 UTF-8로 읽는다. 파일, 명령 출력, 환경 변수, 인자는 UTF-8이 아니어도 바이트 그대로 들어오고 그대로 나간다. UTF-8에 속하지 않는 바이트는 그 바이트 하나가 한 글자다. 값으로 보일 때는 "a\xff"처럼 \xHH로 보이고, 그 모양을 리터럴로 그대로 쓸 수 있다(바이트).
  • 잇기는 +, 끼워 넣기는 보간이다. "a" + "b"는 양쪽이 문자열이어야 한다. 값을 끼워 넣을 때는 "${name}: ${count}"처럼 쓴다. 보간은 어떤 값이든 str과 같은 규칙으로 바꿔 넣는다.
  • 문자열은 컬렉션 함수에 넣지 않는다. map("abc", f)는 에러다. 글자 하나하나를 다루려면 chars로 글자 리스트를 만든다.
s = "  ERROR disk full  "
clean = trim(s)
print("[${clean}]", len(clean), clean[0..5], lower(clean))
print(s == "  ERROR disk full  ")
[ERROR disk full] 15 ERROR error disk full
true

리터럴의 이스케이프(\n, \t, \u{301}), 여러 줄 문자열, 원시 문자열은 어휘에, 패턴으로 찾고 바꾸는 일은 regex 모듈에 있다.

나누기와 잇기

split

s를 구분자 sep로 나눈 문자열의 리스트를 돌려준다.

split(s, sep)

설명

sep가 나올 때마다 자른다. 구분자가 연달아 있거나 맨 앞·맨 뒤에 있으면 그 사이의 빈 조각도 남긴다(split("a,,b", ",")는 ["a", "", "b"]). 그래서 CSV처럼 칸 수가 중요한 데이터를 잘 다룬다. 구분자가 없으면 원래 문자열 하나짜리 리스트이고, 빈 문자열을 나누면 [""]이다. sep가 ""면 글자 단위로 나눈다(chars와 같다).

공백이 여러 개 섞인 글을 낱말로 나눌 때는 빈 조각을 걸러 낸다: split(s, " ") |> filter(w => w != ""). 줄로 나눌 때는 split(s, "\n") 대신 lines를 쓴다(마지막 줄바꿈과 \r을 처리해 준다). 정규식으로 나누려면 regex.split.

매개변수

  • s: 나눌 문자열.
  • sep: 구분자 문자열. 여러 글자여도 된다.

돌려주는 값

문자열의 리스트. 언제나 원소가 하나 이상이다.

에러

s나 sep가 문자열이 아니면 런타임 에러 E0403.

예제

빈 조각도 남긴다

print(split("a,,b", ","), split(",a,", ","), split("abc", "x"), split("", ","))
["a", "", "b"] ["", "a", ""] ["abc"] [""]

여러 글자 구분자, 글자 단위

print(split("a::b::c", "::"), split("abc", ""))
["a", "b", "c"] ["a", "b", "c"]

키=값 줄 읽기

line = "DB_HOST=db-1.internal"
[key, value] = split(line, "=")
print(key, "->", value)
DB_HOST -> db-1.internal

공백이 여러 개인 줄을 낱말로

line = "web-1    up   12d"
print(split(line, " ") |> filter(w => w != ""))
["web-1", "up", "12d"]

같이 보기

join, lines, chars, regex.split

join

리스트의 원소를 sep로 이어 문자열 하나로 만든다.

join(xs, sep = "")

설명

split의 반대다. 원소 사이에만 sep를 넣고 앞뒤에는 넣지 않는다. 빈 리스트는 ""이다. 문자열이 아닌 원소는 str로 바꿔 넣으므로 수의 리스트도 바로 잇는다. sep를 주지 않으면 그냥 붙인다.

문자열을 하나씩 +로 쌓는 것보다 리스트에 모아 한 번에 join하는 것이 빠르다. 여러 줄 출력을 만들 때는 join(rows, "\n").

매개변수

  • xs: 리스트, 범위, 받는 끝.
  • sep: 사이에 넣을 문자열. 기본은 "".

돌려주는 값

문자열.

에러

  • xs가 리스트 등이 아니면 런타임 에러 E0506(cannot join str).
  • sep가 문자열이 아니면 E0403.
  • 원소가 Ok·Err이면 E0519(결과값은 글에 말없이 넣지 않는다, 보간과 같다). 결과를 보이려면 map(xs, str)로 먼저 바꾼다.

예제

잇기

print(join(["a", "b", "c"], ", "), join([1, 2, 3]), join(0..4, "-"), "[" + join([], "|") + "]")
a, b, c 123 0-1-2-3 []

여러 줄 만들기

rows = [("web-1", "up"), ("db-1", "down")]
print(join(map(rows, ((h, s)) => "${h}\t${s}"), "\n"))
web-1	up
db-1	down

나누고, 고치고, 다시 잇기

path = "/usr/local/bin"
print(split(path, "/") |> filter(p => p != "") |> map(upper) |> join("."))
USR.LOCAL.BIN

같이 보기

split, str, print

lines

글을 줄의 리스트로 나눈다.

lines(s)

설명

\n으로 나누되, 줄 끝의 \r(Windows식 줄 끝 \r\n)을 떼고, 마지막 줄바꿈 뒤에 빈 줄을 만들지 않는다. 그래서 파일 끝에 줄바꿈이 있든 없든 같은 결과다. 가운데의 빈 줄은 ""로 남는다. 빈 문자열은 []이다. read_lines와 같은 규칙이다.

split(s, "\n")을 쓰면 끝에 빈 문자열이 하나 더 붙으므로(split("a\n", "\n")은 ["a", ""]), 글을 줄로 나눌 때는 언제나 lines를 쓴다.

매개변수

  • s: 문자열.

돌려주는 값

문자열의 리스트.

에러

s가 문자열이 아니면 런타임 에러 E0403.

예제

마지막 줄바꿈과 \r

print(lines("a\nb\n"), lines("a\r\nb"), lines("a\n\nb"), lines(""))
print(split("a\nb\n", "\n"))
["a", "b"] ["a", "b"] ["a", "", "b"] []
["a", "b", ""]

명령 출력을 줄로

out = exec(["printf", "web-1\nweb-2\n"])!.out
for (i, host) in zip(1..100, lines(out)):
  print(i, host)
;;
1 web-1
2 web-2

같이 보기

split, read_lines, fs.read_lines

chars

문자열을 글자 하나짜리 문자열의 리스트로 나눈다.

chars(s)

설명

글자는 유니코드 코드 포인트 하나다. 그래서 결합 문자로 쓴 "e\u{301}"(é)나 피부색이 붙은 이모지는 둘로 나뉜다. UTF-8에 속하지 않는 바이트는 그 바이트 하나짜리 문자열 한 글자다(chars("a\xff")는 ["a", "\xff"]). 글자 리스트를 얻으면 컬렉션 함수(map, filter, reverse, unique …)를 모두 쓸 수 있고, 다 고친 뒤 join으로 다시 잇는다.

매개변수

  • s: 문자열.

돌려주는 값

문자열의 리스트.

에러

s가 문자열이 아니면 런타임 에러 E0506.

예제

글자로 나누기

print(chars("참치a"), chars(""), len(chars("e\u{301}")))
["참", "치", "a"] [] 2

글자 단위로 다루기

word = "deploy"
print(chars(word) |> reverse |> join, chars(word) |> unique |> len)
print(chars("a1b2c3") |> filter(c => c >= "0" and c <= "9") |> join)
yolped 6
123

같이 보기

split, join, len

다듬기와 바꾸기

trim

양 끝의 공백을 지운다. cut을 주면 그 글자들을 지운다.

trim(s, cut = nil)

설명

cut이 없으면 양 끝의 공백 글자(스페이스, 탭, \n, \r, 유니코드 공백)를 모두 지운다. 가운데의 공백은 건드리지 않는다. 파일이나 명령 출력에서 읽은 값은 끝에 줄바꿈이 붙어 있는 일이 많으므로 비교하거나 수로 바꾸기 전에 trim한다.

cut을 주면 cut에 든 글자 하나하나를 지울 글자로 본다. 접두사·접미사 문자열이 아니다. trim("abcxcba", "abc")는 양 끝에서 a·b·c 중 하나인 글자를 계속 지워 "x"가 된다. 정해진 접두사 하나만 떼려면 starts_with와 슬라이스를 쓴다.

매개변수

  • s: 문자열.
  • cut: 지울 글자들을 모은 문자열, 또는 nil(공백).

돌려주는 값

문자열.

에러

인자가 문자열이 아니면 런타임 에러 E0403.

예제

공백과 줄바꿈

print("[" + trim("  x ") + "]", "[" + trim("\t\n v1.2.3 \r\n") + "]")
[x] [v1.2.3]

지울 글자 고르기

print(trim("--x--", "-"), trim("abcxcba", "abc"), trim("\"quoted\"", "\""))
x x quoted

명령 출력에서 값 얻기

count = exec(["echo", "42"])!.out |> trim |> int
print(count + 1)
43

같이 보기

replace, starts_with, lines

upper

대문자로 바꾼 문자열을 돌려준다.

upper(s)

설명

유니코드 기본 대소문자 변환(전체 매핑)을 쓴다. 그래서 글자 수가 바뀔 수 있다: upper("straße")는 "STRASSE". 한글처럼 대소문자가 없는 글자는 그대로다. UTF-8에 속하지 않는 바이트도 글자가 아니므로 그대로 둔다.

매개변수

  • s: 문자열.

돌려주는 값

문자열.

에러

s가 문자열이 아니면 런타임 에러 E0403.

예제

대문자로

print(upper("hello"), upper("straße"), upper("참치 v1"))
HELLO STRASSE 참치 V1

같이 보기

lower

lower

소문자로 바꾼 문자열을 돌려준다.

lower(s)

설명

전체 매핑이고, 그리스어 시그마는 단어 끝에서 ς가 된다: lower("ΟΔΟΣ")는 "οδος". 대소문자를 무시하고 비교하려면 양쪽을 lower해서 비교한다. UTF-8에 속하지 않는 바이트는 그대로 둔다.

매개변수

  • s: 문자열.

돌려주는 값

문자열.

에러

s가 문자열이 아니면 런타임 에러 E0403.

예제

소문자로, 대소문자 무시 비교

print(lower("ABC"), lower("ΟΔΟΣ"))
answer = "Yes"
print(lower(answer) == "yes")
abc οδος
true

같이 보기

upper, sort_by

replace

s 안의 모든 old를 new로 바꾼 문자열을 돌려준다.

replace(s, old, new)

설명

왼쪽부터 겹치지 않게 찾아 모두 바꾼다(replace("aaa", "aa", "b")는 "ba"). new가 ""면 지우는 것이다. old가 ""면 글자 사이사이와 양 끝에 new를 넣는다. 첫 번째 것만 바꾸거나 패턴으로 바꾸려면 regex.replace를 쓴다.

매개변수

  • s: 문자열.
  • old: 찾을 문자열.
  • new: 바꿔 넣을 문자열.

돌려주는 값

문자열.

에러

  • 인자가 문자열이 아니면 런타임 에러 E0403.
  • 결과가 1억 글자를 넘으면 만들기 전에 E0806.

예제

모두 바꾸기, 지우기

print(replace("a-b-c", "-", "+"), replace("aaa", "aa", "b"), replace("v1.2.3", ".", ""))
a+b+c ba v123

설정 템플릿 채우기

tmpl = "host={{HOST}} port={{PORT}}"
vals = {HOST: "db-1", PORT: "5432"}
print(fold(pairs(vals), tmpl, (acc, (k, v)) => replace(acc, "{{${k}}}", v)))
host=db-1 port=5432

같이 보기

regex.replace, trim, split

검사와 만들기

starts_with

s가 prefix로 시작하면 true.

starts_with(s, prefix)

설명

빈 접두사는 언제나 참이다. 부분 문자열이 어디에든 있는지는 x in s(또는 contains), 패턴은 regex.is_match로 본다.

매개변수

  • s: 문자열.
  • prefix: 문자열.

돌려주는 값

bool.

에러

인자가 문자열이 아니면 런타임 에러 E0403.

예제

접두사로 고르기

print(starts_with("fung.toml", "fung"), starts_with("a", ""))
log = ["# comment", "host=a", "", "# x", "port=1"]
print(filter(log, l => l != "" and not starts_with(l, "#")))
true true
["host=a", "port=1"]

접두사 떼기

tag = "v1.4.2"
print(starts_with(tag, "v") then tag[1..] else tag)
1.4.2

같이 보기

ends_with, contains

ends_with

s가 suffix로 끝나면 true.

ends_with(s, suffix)

설명

확장자 검사에 많이 쓴다. 대소문자를 가리므로 "A.LOG"도 받으려면 ends_with(lower(name), ".log").

매개변수

  • s: 문자열.
  • suffix: 문자열.

돌려주는 값

bool.

에러

인자가 문자열이 아니면 런타임 에러 E0403.

예제

확장자로 고르기

files = ["app.log", "app.log.1", "ERROR.LOG", "notes.txt"]
print(filter(files, f => ends_with(lower(f), ".log")))
["app.log", "ERROR.LOG"]

같이 보기

starts_with, path.ext

repeat

s를 n번 이어 붙인 문자열을 돌려준다.

repeat(s, n)

설명

fung에는 "a" * 3이 없다(문자열과 수의 곱은 에러다). 구분선이나 들여쓰기를 만들 때 쓴다. n이 0 이하면 ""이다.

매개변수

  • s: 문자열.
  • n: 정수.

돌려주는 값

문자열.

에러

  • 인자의 타입이 틀리면 런타임 에러 E0403.

pad_left, join

pad_leftfung으로 작성

왼쪽을 pad로 채워 n글자로 만든다. 이미 n글자 이상이면 그대로.

설명

수를 오른쪽으로 맞추거나 앞에 0을 채울 때 쓴다. pad가 여러 글자면 돌려 가며 채우고 모자란 만큼에서 자른다(pad_left("1", 5, "ab")는 "abab1"). 길이는 len처럼 글자 수로 센다. 한글처럼 화면에서 두 칸을 차지하는 글자도 한 글자로 세므로, 한글이 섞인 표는 터미널에서 줄이 어긋날 수 있다.

매개변수

  • s: 문자열. 수는 먼저 str로 바꾼다.
  • n: 만들 글자 수.
  • pad: 채울 문자열. 기본은 공백 하나.

돌려주는 값

문자열.

에러

  • s·pad가 문자열이 아니거나 n이 정수가 아니면 런타임 에러 E0403.
  • pad가 ""면 런타임 에러 E0403(argument pad must be a non-empty str, got str).

바이트

fung 문자열은 바이트 열이다. 바깥에서 들어온 값(파일, 명령 출력, env, args, 표준 입력, 소켓)은 UTF-8이 아니어도 바이트 그대로 들어오고, 그대로 쓰면 그대로 나간다. 그래서 fung으로 읽고 쓰기만 하는 스크립트가 파일을 바꾸지 않는다.

글자 연산(len, s[i], chars, 슬라이스)은 바이트를 UTF-8로 읽고, UTF-8에 속하지 않는 바이트는 그 하나가 한 글자다. 자르고 다시 이어도 바이트가 그대로 남는다. 값으로 보일 때(리스트 안, REPL, dbg)는 그런 바이트가 \xff처럼 보이고, 리터럴에도 "\xff"로 쓴다. \xHH는 바이트 하나다: "\xc3\xa9"는 UTF-8로 é이고, "\xe9"는 é가 아니라 바이트 0xE9 하나다(글자 é는 "\u{e9}").

대부분의 함수는 그런 바이트를 그대로 둔다: 비교(바이트 순, UTF-8이면 코드 포인트 순과 같다), +, split, replace, trim, upper·lower, 정규식. 형식 자체가 글을 요구하는 곳만 에러 E0518로 멈춘다: json.stringify, 정규식 패턴, 시간 형식, 호스트 이름. 바깥에서 온 값을 읽는 parse_int 같은 함수에는 그런 바이트가 읽을 수 없는 입력일 뿐이라 Err다.

s = "a\xffb"
print([s, s[1], s + "!"], len(s), byte_len(s), valid_utf8(s))
["a\xffb", "\xff", "a\xffb!"] 3 3 false

정수.

에러

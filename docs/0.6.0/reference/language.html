문법

겉은 Go와 Python을 닮았고, 블록은 :에서 ;;까지다. 들여쓰기에는 의미가 없다.

# 한눈에 보는 fung
import fs

fn total_size(dir):
  fs.list(dir)!
    |> map(f => fs.stat("${dir}/${f}")!.size)
    |> fold(0, (acc, n) => acc + n)
;;

size = total_size(".")
label = size > 1_000_000 then "big" else "small"
print("${size} bytes (${label})")
263 bytes (small)

명세의 쪽들

규칙은 주제마다 한 쪽이다. 쪽마다 규칙, 실행한 예와 출력, 경계 사례와 그 자리의 에러를 함께 적는다.

  • 어휘: 토큰의 규칙: 이름, 숫자, 문자열, 기간, 주석, 예약어.
  • 문장과 블록: 문장과 블록(: … ;;), 줄 이어짐.
  • 값과 타입: 값의 종류와 그 성질, 문자열·리스트·맵·튜플·태그·범위.
  • 연산자: 산술·비교·논리 연산자, 파이프 |>, 우선순위.
  • 인덱스·슬라이스·필드: x[i], x[a..b], x.name의 규칙과 범위 밖.
  • 변수와 스코프: 대입, 블록 스코프, 바깥 변수, 최상위 이름.
  • 함수: fn, 람다, 인자 규약, 기본값, 클로저, 꼬리 호출.
  • 조건: if, then … else, and·or, 값 자리의 조건.
  • match와 패턴: match, 패턴의 종류, guard, 구조 분해 대입.
  • for: for의 값, 순회 대상, 버려지는 자리.
  • 결과값과 에러: Ok·Err, !·?·??, 버려지는 Err.
  • 모듈: import, 모듈 찾기, 공개 이름.
  • 타입 표기: 매개변수와 반환의 타입 표기와 그 검사.
  • 테스트와 디버깅: test 블록, assert, dbg.
  • 형식 문법: fung의 EBNF.

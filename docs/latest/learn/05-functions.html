함수

계산에 이름을 붙여 다시 쓰는 법. fung에서 함수는 숫자나 문자열과 똑같은 값이다.

이 장에서 배울 것
  • 함수가 무엇이고 왜 쓰는지
  • fn으로 함수를 정의하고 부르는 법, 짧은 형태 fn f(x) = …
  • 기본값 있는 매개변수, 이름 붙인 인자, 나머지 인자 ...rest
  • 람다 x => …와 함수를 값으로 다루는 법
  • 클로저: 함수는 만들어질 때 보이는 값을 복사한다
  • 최상위 함수가 볼 수 있는 이름
  • 파이프 |>와 부분 적용 _

함수란

같은 계산을 여러 곳에서 하게 되면, 그 계산에 이름을 붙여 두고 이름으로 부르는 것이 낫다. 고칠 때 한 곳만 고치면 되고, 읽는 사람은 disk_level(91)만 보고도 무슨 일을 하는지 안다. 이렇게 이름 붙인 계산이 함수(function)다.

함수는 값을 받아서 값을 돌려준다. 받는 값을 인자(argument), 돌려주는 값을 반환값(return value)이라고 한다. 이미 많이 써 봤다. len("web-1")은 len 함수에 인자 "web-1"을 주고 반환값 5를 받는 것이다. 이렇게 함수를 쓰는 것을 "함수를 부른다(호출, call)"고 한다.

함수 정의하기

함수는 fn 이름(매개변수, …):로 시작해 ;;로 닫는 블록으로 정의한다. 괄호 안의 이름들을 매개변수(parameter)라고 하고, 부를 때 준 인자가 차례로 매개변수에 들어간다. 블록의 마지막 식의 값이 반환값이다.

fn disk_level(usage):
  if usage >= 90:
    "critical"
  else if usage >= 75:
    "warning"
  else:
    "ok"
  ;;
;;

print(disk_level(91), disk_level(80), disk_level(12))
critical warning ok

마지막 항목이 반환값이므로, 거기에 else 없는 if나 대입을 두면 컴파일 에러다(E0223·E0224). 부르는 쪽이 그 값을 쓰면 조용히 nil이 되기 때문이다. 돌려줄 것이 없는 함수는 if에 else: nil을 붙이거나 마지막 줄에 nil을 쓴다.

fn warn(usage):
  if usage >= 90:
    print("disk almost full:", usage)
  else: nil ;;
;;

fn report(usages):
  for u in usages:
    if u >= 75: print("high:", u) ;;
  ;;
  nil
;;

warn(95)
report([80, 20])
disk almost full: 95
high: 80

본문이 식 하나뿐이면 = 뒤에 바로 쓴다. 짧은 함수는 대부분 이 모양이다.

fn percent(used, total) = used / total * 100
fn is_log(name) = ends_with(name, ".log")

print(percent(45, 50), is_log("app.log"), is_log("app.conf"))
90.0 true false

중간에 일찍 끝내고 싶으면 return 값을 쓴다. return만 쓰면 nil을 돌려준다.

fn port_kind(port):
  if port < 1024:
    return "privileged"
  ;;
  port < 49152 then "registered" else "dynamic"
;;

print(port_kind(22), port_kind(8080), port_kind(50000))
privileged registered dynamic

파일 최상위의 fn은 프로그램이 시작하기 전에 모두 만들어진다. 그래서 정의보다 위에서 불러도 되고, 함수끼리 순서와 상관없이 서로 부를 수 있다.

print(greet("ops"))

fn greet(team) = "hello, ${team}"
hello, ops

인자

매개변수에 기본값을 주면 부를 때 그 인자를 생략할 수 있다. 부를 때 이름: 값으로 이름 붙인 인자를 주면 순서와 상관없이 원하는 매개변수만 고를 수 있다. 이름 붙인 인자는 위치 인자 뒤에 쓴다.

fn endpoint(host, port = 443, scheme = "https") = "${scheme}://${host}:${port}"

print(endpoint("api.internal"))
print(endpoint("api.internal", 8080, "http"))
print(endpoint("api.internal", scheme: "http", port: 80))
https://api.internal:443
http://api.internal:8080
http://api.internal:80

마지막 매개변수 앞에 ...를 붙이면 남는 위치 인자를 모두 리스트로 받는다. 이것을 나머지 인자라고 한다.

fn remote(host, ...cmd) = "ssh ${host} ${join(cmd, " ")}"
print(remote("web-1", "df", "-h"))
print(remote("web-1"))
ssh web-1 df -h
ssh web-1

매개변수의 순서는 "필수 → 기본값 있는 것 → ...rest"다. 인자 개수가 맞지 않거나 모르는 이름을 주면 런타임 에러다.

fn endpoint(host, port = 443) = "${host}:${port}"
print(endpoint(prot: 80))
error[E0406]: endpoint has no argument named `prot`
  --> example.fung:2:15
  |
2 | print(endpoint(prot: 80))
  |               ^
  |
 call path (innermost first):
   example.fung:2 <entry>

위에서는 port를 prot로 잘못 썼다. 모르는 인자 이름이라는 E0406으로 멈춘다.

내장 함수도 똑같다. 예를 들어 join(xs, sep = "")는 sep에 기본값이 있어서 join(["a", "b"])로 부를 수 있다. 레퍼런스의 함수 항목에 이런 서명이 그대로 적혀 있다.

함수는 값이다

fung에서 함수는 숫자나 문자열과 같은 값이다. 이름에 대입할 수 있고, 다른 함수에 인자로 넘길 수 있고, 함수가 함수를 돌려줄 수도 있다. 4장의 filter(usages, u => u >= 90)이 바로 함수를 인자로 넘긴 것이다.

이름 없이 그 자리에서 만드는 짧은 함수를 람다(lambda)라고 한다. 매개변수 => 식 꼴이다. 매개변수가 둘 이상이거나 없으면 괄호로 감싼다.

double = x => x * 2
add = (a, b) => a + b
hello = () => "hello"
print(double(21), add(1, 2), hello(), type_of(double))
42 3 hello 'fn

람다의 본문은 식 하나다. 여러 문장이 필요하면 이름 없는 fn(…): … ;;를 쓴다.

check = fn(usage):
  level = usage > 90 then "critical" else "ok"
  "${usage}% ${level}"
;;
print([95, 40] |> map(check))
["95% critical", "40% ok"]

함수를 넘길 때는 괄호 없이 이름만 쓴다. map(xs, check)는 check 함수를 넘기는 것이고, check(95)는 check를 불러 나온 결과다.

클로저: 만들어질 때 보이는 값을 복사한다

함수 안에서 함수를 만들면, 안쪽 함수는 바깥의 이름을 쓸 수 있다. 아래의 tagger는 level을 받아 "줄 앞에 [level]을 붙이는 함수"를 만들어 돌려준다. 돌려받은 함수는 tagger가 끝난 뒤에도 level을 기억한다. 이렇게 바깥 값을 품은 함수를 클로저(closure)라고 한다.

fn tagger(level) = line => "[${level}] ${line}"

warn = tagger("WARN")
error = tagger("ERROR")
print(warn("disk 91%"))
print(["timeout", "refused"] |> map(error))
[WARN] disk 91%
["[ERROR] timeout", "[ERROR] refused"]

fung의 클로저 규칙은 하나다. 함수는 만들어질 때 보이는 변수의 값을 복사한다. 나중에 그 이름에 다른 값을 대입해도, 함수가 가진 값은 그대로다.

suffix = ".log"
is_target = name => ends_with(name, suffix)
suffix = ".txt"
print(is_target("app.log"), is_target("notes.txt"))
true false

is_target이 만들어질 때 suffix는 ".log"였으므로, 그 뒤에 suffix가 바뀌어도 is_target은 계속 .log를 찾는다. 값이 바뀌지 않는 언어라서 "그때의 값"과 "지금의 값"이 섞일 일이 없다.

최상위 함수가 볼 수 있는 이름

위 규칙을 최상위 fn에 적용하면 결론이 하나 나온다. 최상위 fn은 프로그램 시작 전에 만들어지므로, 그때는 복사할 변수가 아직 없다. 그래서 최상위 fn이 볼 수 있는 파일의 이름은 다음뿐이다.

  • 다른 최상위 fn과 import한 모듈(10장)
  • 최상위에서 한 번만 대입한 이름, 곧 상수(3장). 상수는 바뀔 일이 없으니 부를 때 읽는다.

두 번 이상 대입한 이름은 보이지 않는다. 그런 값은 인자로 넘긴다.

log_dir = "/var/log/app"
fn log_path(name) = "${log_dir}/${name}"
print(log_path("api.log"))
/var/log/app/api.log
level = 1
level = 2
fn show() = level
error[E0204]: undefined name `level`
  --> example.fung:3:13
  |
3 | fn show() = level
  |             ^^^^^ not found in this scope
  |
 help: `level` is a file-level variable (assigned on line 1) that a top-level fn cannot see: it is assigned more than once, and top-level fns see only the names assigned once; pass it as an argument

파이프

함수 결과를 다음 함수에 넣고, 그 결과를 또 다음 함수에 넣다 보면 괄호가 깊어진다. len(filter(lines, is_error))는 안쪽부터 거꾸로 읽어야 한다. 파이프 |>는 같은 것을 데이터가 흐르는 순서대로 쓰게 해 준다. 규칙은 둘뿐이다.

  • x |> f(a, b)는 f(x, a, b)다. 왼쪽 값이 오른쪽 호출의 맨 앞 인자로 들어간다.
  • x |> f는 f(x)다.
line = "  2026-10-20 ERROR disk full  "
words = line |> trim |> split(" ")
print(words)
log = ["INFO start", "ERROR disk full", "ERROR timeout", "INFO done"]
print(log |> filter(l => starts_with(l, "ERROR")) |> len)
["2026-10-20", "ERROR", "disk", "full"]
2

그래서 내장 함수는 모두 다루는 대상을 첫 매개변수로 받는다: filter(xs, f), split(s, sep), put(m, k, v). 직접 만드는 함수도 대상을 맨 앞에 두면 파이프에 그대로 이어진다. 대상이 첫 자리가 아닌 함수에는 람다로 넘긴다.

fn scale(factor, n) = factor * n
print(5 |> (n => scale(2, n)))
10

부분 적용

호출의 인자 자리에 _를 쓰면, 그 자리를 비워 둔 새 함수가 만들어진다. scale(10, _)는 n => scale(10, n)과 같다. map에 넘길 함수를 짧게 만들 때 쓴다.

fn scale(factor, n) = factor * n
print([1, 2, 3] |> map(scale(10, _)))
[10, 20, 30]

짚고 넘어가기

매개변수와 인자, 정의와 호출

정의는 "이런 계산이 있다"고 적어 두는 것이고, 호출은 그 계산을 실제로 하는 것이다. fn percent(used, total) = …의 used와 total이 매개변수(빈칸의 이름)이고, percent(45, 50)의 45와 50이 인자(빈칸에 넣은 값)다. 정의만 하고 부르지 않으면 아무 일도 일어나지 않는다.

최상위 함수에서 바뀌는 변수 읽기 (E0204)

최상위에서 두 번 이상 대입한 변수를 최상위 fn이 읽으면 E0204다. help: 줄이 이유를 알려 준다. 바뀌는 값은 인자로 넘기거나, 한 번만 대입하도록 고친다(예: level = if … ;;). 최상위 fn이 부를 때마다 파일의 "지금 값"을 찾는 언어에서는 함수의 결과가 호출 시점에 따라 달라지는데, fung은 그런 숨은 의존을 만들지 않는다.

파이프 오른쪽 호출의 _ (E0227)

파이프 값은 늘 맨 앞 인자로 들어가므로 "a.txt" |> path.join("/tmp", _)는 path.join("a.txt", "/tmp", _)가 되어 버린다. 그래서 이 모양은 컴파일 에러다. 다른 자리에 넣으려면 람다를 쓴다: "a.txt" |> (f => path.join("/tmp", f)).

꼬리가 아닌 깊은 재귀 (E0804)

fn total(n) = n == 0 then 0 else n + total(n - 1)은 자기 호출이 끝난 뒤 n +을 해야 하므로 꼬리 호출이 아니다. 깊이가 100,000을 넘으면 stack overflow 에러다. 모은 값을 인자로 넘기는 꼬리 재귀(4장)로 바꾸거나 fold·sum을 쓴다.

다른 언어는

Python의 def f(x): return …가 fung의 fn f(x) = …, lambda x: …가 x => …다. 이름 붙인 인자와 기본값, *args(fung의 ...rest)도 Python과 비슷하다. 다른 점은 클로저다. Python과 JavaScript의 클로저는 변수 자체를 붙잡아서 나중에 변수가 바뀌면 함수의 결과도 바뀌지만, fung은 만들어질 때의 값을 복사한다. 파이프는 Elixir의 |>와 같은 쪽(대상이 첫 인자)이고, 쉘의 |처럼 왼쪽 결과를 오른쪽으로 넘긴다.

해 보기

접속 주소 만들기

host를 받고, user(기본값 "deploy")와 port(기본값 22)를 고를 수 있는 함수 ssh_target을 만들어 deploy@web-1:22, root@db-1:2222 같은 문자열을 돌려주게 하자. 서버 목록 ["web-1", "web-2"]에 map으로 적용해 본다.

풀이 보기 
fn ssh_target(host, user = "deploy", port = 22) = "${user}@${host}:${port}"

print(["web-1", "web-2"] |> map(ssh_target))
print(ssh_target("db-1", user: "root", port: 2222))
["deploy@web-1:22", "deploy@web-2:22"]
root@db-1:2222
문턱값 함수 만들기

숫자 limit을 받아 "limit보다 큰가?"를 묻는 함수를 돌려주는 over(limit)을 만들자. 그것으로 [45, 91, 78, 99]에서 80보다 큰 값과 95보다 큰 값을 각각 골라 본다.

풀이 보기

over(80)이 돌려주는 람다는 만들어질 때의 limit(80)을 복사해 둔다.

fn over(limit) = n => n > limit

usages = [45, 91, 78, 99]
print(usages |> filter(over(80)))
print(usages |> filter(over(95)))
[91, 99]
[99]

정리

  • 함수는 fn 이름(매개변수): … ;;로 정의하고, 마지막 식이 반환값이다. 식 하나면 fn f(x) = ….
  • 최상위 fn은 시작 전에 만들어지므로 순서와 상관없이 부를 수 있다.
  • 매개변수는 필수 → 기본값 → ...rest 순서. 부를 때 이름: 값으로 골라 줄 수 있다.
  • 함수는 값이다. 람다 x => …로 그 자리에서 만들고, 인자로 넘기고, 돌려준다.
  • 함수는 만들어질 때 보이는 변수의 값을 복사한다. 최상위 fn은 상수만 읽을 수 있다.
  • x |> f(a)는 f(x, a). 대상이 첫 인자라는 규칙 덕분에 파이프가 이어진다. f(a, _)는 부분 적용.

레퍼런스: 함수, 변수와 스코프, 파이프, 타입 표기(인자와 반환값의 타입을 적어 검사하는 법), E0204, E0227. 클로저가 값을 복사하는 방법은 함수와 클로저에서 다룬다.

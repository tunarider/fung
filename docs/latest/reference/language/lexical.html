§레퍼런스언어 명세

어휘

토큰의 규칙: 이름, 숫자, 문자열, 기간, 주석, 예약어.

주석

#부터 줄 끝까지. 다른 주석 형식은 없다(//는 정수 나눗셈이다). 파일 첫 줄의 #!/usr/bin/env fung도 그냥 주석이다.

파일 맨 앞의 BOM(U+FEFF) 하나는 건너뛴다. 그 밖의 BOM은 문자열(원시 문자열 포함)과 주석 안에서는 다른 글자처럼 그대로 받고, 토큰 사이(둘째 BOM 포함)에 오면 E0101이다.

줄 끝은 \n이나 \r\n이다. 홀로 선 CR(\r)은 문자열 안이 아니면 주석 안에서도 E0101이다. 터미널과 편집기가 CR을 서로 다르게 그려서, 주석처럼 보이는 코드가 실행되는 일을 막는다.

이름과 태그

  • 대문자로 시작하지 않으면 이름이다. 소문자, _, 한글처럼 대소문자가 없는 글자, 제목 문자 ǅ(Lt), 글자 숫자 Ⅷ(Nl)이 모두 그렇다: file_list, _cache, 파일목록.
  • 첫 글자가 유니코드 대문자(일반 범주 Lu)면 태그: Ok, Circle. 선언 없이 쓴다(값과 타입). 그래서 대문자 이름은 변수가 될 수 없다: MAX_RETRIES = 3과 {HOME} = cfg는 컴파일 에러 E0225다. 상수도 소문자로 쓰고(max_retries = 3), 대문자 키는 {HOME: home} = cfg나 cfg.HOME으로 읽는다.
  • 이름 표기는 snake_case. _로 시작하는 최상위 이름은 모듈 밖에서 보이지 않는다.
  • 이어지는 글자는 글자·숫자·_와 결합 문자(유니코드 UAX #31의 식별자 규칙): हिंदी, café. 이름은 NFC로 정규화해서, 조합형과 분해형으로 쓴 é는 같은 이름이다. 맵 키 자리(m.k, {k: 1}, 패턴 {k: v})의 식별자는 문자열이라 쓴 그대로다(m.k는 정확히 m["k"]). 모듈 멤버(lib.이름)는 이름이라 NFC로 찾는다.

예약어

fn if else then match when for in not and or return import as type test assert true false nil

이름만 올 수 있는 세 자리, 곧 . 뒤, 맵 리터럴의 키, 맵 패턴의 키에서는 예약어도 그냥 이름이다. JSON의 type 같은 키를 그대로 쓰기 위해서다. 변수나 함수 이름으로는 쓸 수 없다.

event = {type: "deploy", match: "api-*"}
print(event.type, event.match)
deploy api-*

숫자

형태예비고
정수42 1_000_00064비트. _는 숫자 사이에만. 두 자리 이상이면 0으로 시작하지 않는다(0755는 E0102, 8진수는 0o755).
진법0xff 0o17 0b1010정수. 범위는 10진 정수와 같은 64비트다(-0x8000000000000000까지). 접두사는 소문자만(0XFF는 E0102).
실수3.14 2.5e-3 1e9소수점 양쪽에 숫자가 필요하다(.5, 1.은 안 됨, E0102). 정수 바로 뒤의 .는 소수부나 범위 ..만 될 수 있다(1.foo도 E0102). 지수가 있으면 실수이고 지수는 소문자 e만(1E5는 E0102). 0이 아닌 수가 0.0으로 아래 넘치면 E0102(1e-400).

문자열

  • "…": 이스케이프와 보간 ${식}. 이스케이프는 \n \t \r \\ \" \$ \u{1F600} \xHH뿐이고, 모르는 이스케이프("C:\data")는 컴파일 에러다. \xHH는 바이트 하나다("\xe9"는 글자 é가 아니라 바이트 0xE9, 글자는 "\u{e9}"). 실제 줄바꿈은 넣을 수 없다.
  • `…`: 원시 문자열. 이스케이프도 보간도 없고, 여러 줄이 된다. 정규식과 Windows 경로에 쓴다.
  • 보간 안에는 어떤 식이든 온다: "${m["k"]}".
  • 길이와 인덱스는 글자(유니코드 코드 포인트) 단위다. len("참치") == 2, "참치"[0] == "참". 따로 문자 타입은 없다.
  • 문자열은 바이트 열이고, 글자 연산이 그것을 UTF-8로 읽는다. UTF-8에 속하지 않는 바이트는 그 하나가 한 글자이고, 값으로 보일 때는 "\xff"처럼 보인다(바이트). 소스 파일은 UTF-8이어야 한다(E0312).
name = "fung"
print("hello, ${name}! ${1 + 2}")
pattern = `^\d{4}-\d{2}$`
hello, fung! 3

심볼

'ok, 'not_found, 'Red. ' 뒤에 식별자가 온다(대문자로 시작해도 된다). 이름만 있는 값으로, 선언 없이 쓰는 열거형이다. 문자열과는 다른 타입이라 'ok == "ok"처럼 심볼과 문자열을 비교하면 런타임 에러 E0517이다(sym(s)로 바꿔 비교한다).

기간

500ms 30s 1.5s 1h30m. 단위는 ms s m h이고 큰 단위부터 쓴다. 숫자 바로 뒤에 붙여야 한다(30 s는 숫자와 이름 s).

성분마다 숫자는 10진 정수처럼 0으로 시작하지 않고(1h05m은 E0105), 소수점은 마지막 성분에만 온다(1h30.5m은 되고 1.5h30m은 E0105). 기간은 나노초 단위라, 0이 아닌 성분이 0 ns로 반올림되면 E0105다(0.0000004ms).

기간을 숫자로 바꿀 때는 원하는 단위로 나눈다. d / 1ms는 ms 수(실수), d // 1m은 몇 분(정수), d % 1m은 분으로 나눈 나머지(기간)다. 숫자를 기간으로는 n * 1ms.

elapsed = 1m30s
print(elapsed / 1ms, elapsed // 1m, elapsed % 1m)
90000.0 1 30s

경계 사례와 에러

제목 문자(Lt)나 글자 숫자(Nl)로 시작하는 이름은 태그가 아니라 변수가 된다.

ǅx = 1
Ⅷ = 2
print(ǅx + Ⅷ, type_of(Red))
3 'sym

숫자의 밑줄은 숫자 사이에만 온다. 잘못된 모양은 그 자리에서 멈춘다.

print(1_000_000)
print(1__0)
error[E0102]: malformed number "1_"
  --> example.fung:2:7
  |
2 | print(1__0)
  |       ^
  |

기간은 큰 단위부터 쓴다. 작은 단위 뒤에 큰 단위가 오면 기간이 아니다.

print(1h30m, 90s)
print(30m1h)
error[E0105]: malformed duration "30m1h"
  --> example.fung:2:7
  |
2 | print(30m1h)
  |       ^
  |

진법의 접두사와 지수는 소문자로 쓴다. 대문자는 도움말이 소문자 모양을 보인다.

print(0xFF, 1e5)
print(0XFF)
error[E0102]: malformed number "0XFF"
  --> example.fung:2:7
  |
2 | print(0XFF)
  |       ^
  |
 help: write the base prefix in lowercase: `0xFF`

기간의 소수점은 마지막 성분에만 온다.

print(1h30.5m)
print(1.5h30m)
error[E0105]: malformed duration "1.5h30m"
  --> example.fung:2:7
  |
2 | print(1.5h30m)
  |       ^
  |
 help: only the last part of a duration has a fraction: write `1h30.5m`, not `1.5h30m`

문자열의 이스케이프는 정해진 것뿐이다(\n, \t, \r, \\, \", \$, \u{…}, \xHH).

print("a\tb")
print("\q")

  --> example.fung:2:8
  |
2 | print("\q")
  |        ^
  |

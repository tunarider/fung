값과 타입

type_of(x)가 위 타입 이름을 심볼로 돌려준다: type_of(1) == 'int, type_of(Circle(3)) == Circle, type_of('red) == 'sym.

실수

  • 실수는 늘 소수점이나 지수가 붙어 찍혀 정수와 구별된다(1.0). 절댓값이 1021 이상이거나 10-4보다 작으면 지수로 쓴다(1e21, 9e-5), 그 사이는 소수다(100000000000000000000.0, 0.0001). 자릿수는 같은 실수로 되읽히는 가장 짧은 것이다(0.1 + 0.2는 0.30000000000000004).
  • -0.0은 -0.0으로 찍히지만 0.0 == -0.0이고, 같은 값이므로 unique([0.0, -0.0])은 [0.0]이다.
  • //·%는 실수에도 쓴다. 피연산자 하나가 실수면 결과도 실수다: 7.5 // 2 == 3.0, 7 % 2.0 == 1.0.
  • 숫자는 int와 float를 넘어 값으로 같으므로, match의 리터럴 패턴 1.0은 1에도 맞고, 2.0 in 0..3은 true다(1.5 in 0..3은 false).

맵

  • {name: "a"}는 {"name": "a"}의 축약이다. 식별자 모양이면 대소문자와 상관없이 축약된다({DB_HOST: h}).
  • 값이 같은 이름의 변수면 키만 쓴다: {name, port}는 {name: name, port: port}. 대문자 키는 그런 변수가 없으므로 축약할 수 없다({HOME}은 E0225).
  • 같은 키를 두 번 쓰면 컴파일 에러. 없는 키를 읽으면 런타임 에러이고, 기본값이 필요하면 get(m, k, d)를 쓴다.
  • 수정된 사본은 함수로 만든다: put, merge, remove.

비교와 동일성

타입==< 등
int, float값. 섞여도 숫자로 비교(1 == 1.0), 253을 넘는 정수도 정확히값
str내용(바이트)바이트 순(UTF-8이면 코드 포인트 순과 같다)
dur, time값(time은 같은 순간이면 시간대 무관)값
list, tuple원소가 차례로 같음앞 원소부터 사전식

bool, nil, sym, 태그값에러
range같은 정수 열(0..5 == 0..=4, 빈 범위끼리는 같음). 출력은 쓴 모양 그대로에러
fn에러 E0501(같음이 없다)에러
module, file, task, scope, sender, receiver, atom같은 객체인가에러
타입이 다를 때false(같지 않다). 숫자끼리(int와 float)는 수로 견준다에러

unique, contains, in은 이 표의 ==를, sort, sort_by, min, max는 <를 따른다. 함수는 같음이 없으므로 해시도 없어 unique에 넣으면 E0501이다.

타입이 다른 두 값은 같지 않다. "8080" == 8080, 'ok == "ok", Ok(1) == 1은 모두 false다. 리스트·튜플·맵·태그 안에서 맞붙어도, in도 같다([1, 'a] == [1, "a"]는 false, "1" in [1, 2]는 false). 숫자끼리는 타입을 넘어 수로 견준다(1 == 1.0). JSON·파일·명령 출력·환경 변수에서 온 값은 늘 문자열이므로, env("PORT") == 8080이나 back.kind == 'not_found는 늘 거짓이다. 조건이 한 번도 참이 되지 않으면 두 값의 타입부터 본다. 한쪽을 바꿔서(int(s), str(n), sym(s)) 견준다. 타입을 가리려면 type_of나 패턴을 쓴다: 리터럴 패턴('not_found =>, 1 =>)도 타입까지 본다.

순서는 다르다. 문자열과 수 사이, 개수가 다른 두 튜플 사이에는 "어느 쪽이 작은가"의 답이 없으므로 < 등은 에러다(E0501). 이 검사는 값과 상관없이 끝까지 간다: [1, "a"] < [2, 1]은 첫 원소에서 답이 정해져도 둘째 쌍이 견줄 수 없으므로 에러이고, sort·sort_by·min·max는 시작하기 전에 모든 원소(sort_by는 키)를 첫 원소와 견준다. 그래서 정렬이 자료에 따라 되다 말다 하지 않는다. 길이가 다른 두 리스트는 짧은 쪽이 앞이다([1] < [1, 2]).

경계 사례와 에러

맵의 키는 문자열이다. 다른 값을 키로 쓰면 어느 자리에서든(m[k], k in m, get·put·remove, group_by의 키 함수) 바꾸라는 힌트와 함께 E0514로 멈춘다. 심볼 키(m['a])면 힌트가 문자열로 쓰는 법을 보인다.

print(group_by(["ab", "c"], s => "${len(s)}"))
print(group_by(["ab", "c"], s => len(s)))
{"2": ["ab"], "1": ["c"]}

  |
2 | print(group_by(["ab", "c"], s => len(s)))

  |

타입이 다른 두 값은 같지 않다. 심볼과 문자열, 바깥에서 온 글과 수가 흔한 경우다. 한쪽을 바꿔 견준다.

print('ok == 'ok, 1 == 1.0, nil == 'ok)
print("8080" == 8080, 'ok == "ok", int("8080") == 8080, sym("ok") == 'ok)
true true false
false false true true

print(sort([[2, "b"], [1, "a"]]))
print(sort([[1, "a"], [2, 2]]))

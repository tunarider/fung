변수와 스코프

대입, 블록 스코프, 바깥 변수, 최상위 이름.

대입 x = 식은 이름을 값에 붙인다. 같은 이름에 다시 대입할 수 있지만 값 자체를 바꾸지는 않는다. 규칙은 넷이고 예외는 없다.

  1. 이름은 위에서 아래로 묶인다. 대입보다 앞에서 읽으면 컴파일 에러(E0204).
  2. 최상위 fn은 프로그램 시작 전에 모두 만들어진다. 그래서 순서와 상관없이 서로 부를 수 있다.
  3. 함수 값은 만들어질 때 보이는 변수의 값을 복사한다. 나중에 그 이름에 다시 대입해도 함수가 가진 값은 그대로다.
  4. 블록은 바깥 이름을 읽을 수 있지만 대입할 수 없다(E0205). 블록 안에서 만든 이름은 밖으로 새지 않는다(E0206). if 가지, match 절, for가 모두 블록이고, 절의 패턴과 for의 변수가 묶는 이름도 그 블록의 이름이다.

여기서 따라 나오는 것: 최상위 fn은 만들어질 때 최상위 변수가 아직 없으므로 복사할 것이 없다. 대신 최상위에서 한 번만 대입되는 이름은 상수라서 최상위 fn이 부를 때 읽는다(다른 최상위 fn과 모듈이 보이는 것과 같은 이유다). 모듈 상태는 counter = atom(0)처럼 둔다. 두 번 이상 대입되는 이름은 보이지 않으니 인자로 넘긴다. 최상위 fn이 자기 본문의 맨 바깥 블록에서 묶는 이름은 그 함수의 지역이고 같은 이름의 상수를 가린다. 맨 바깥 블록에서 묶지 않는 상수 이름에 안쪽 블록(if·match 가지, 람다)에서 대입하는 것은 다른 블록과 같이 바깥 이름에 대입하는 것이라 E0205다. 맨 바깥 블록이 묶는 이름은 함수 전체에서 지역이라 보통 블록 규칙을 따른다. 파일이 시작하는 중에 상수의 대입보다 먼저 그것을 읽는 fn을 부르면 E0809다. 람다와 익명 함수는 그 자리에서 만들어지므로 그때까지의 변수를 복사한다.

dir = "./logs"
fn clean() = fs.list(dir)       # 된다: dir은 한 번만 대입되는 상수
level = 1
level = 2
fn show() = level               # E0204: level은 두 번 대입된다. 인자로 넘긴다

total = 0
for f in files:
  total = total + 1             # E0205: 블록 안에서 바깥 변수에 대입할 수 없다
;;
total = len(files)              # 값을 식으로 만든다

함수 이름. 최상위 fn의 이름은 상수다: 같은 파일에 같은 이름의 fn을 둘 두면 E0210, 그 이름에 대입하면 E0209다(REPL만 다시 정의할 수 있다). 블록 안의 지역 fn은 그 자리에서 만들어지는 함수 값이라 3번 규칙대로 바깥 인자와 지역 변수를 복사하고, 자기 자신과 앞에서 정의한 이름만 부를 수 있다. 같은 블록의 뒤에서 정의하는 지역 fn을 부르면 E0208이다. 서로 부르는 함수들은 최상위에 둔다.

값의 수명. 함수 안의 변수(와 진입 파일·모듈 본문의 블록 안에서 묶은 이름)를 마지막으로 읽으면 값이 읽은 쪽으로 넘어가고, 그 길에서 더 읽힐 수 없게 된 첫 문장이 끝나면 변수는 값을 놓는다(람다가 붙잡는 것도 읽기다). 함수 본문의 문장이든 if·match 가지 안의 문장이든 같다. 그래서 홀로 쥔 맵·리스트를 받은 put·+는 복사하지 않고 제자리에서 고친다(fold로 쌓는 맵이 빠른 이유). 그래서 함수 안에서 만든 채널의 보내는 끝을 생산 태스크에 넘기면, 생산이 끝날 때 채널이 닫힌다. 한 번도 읽지 않는 변수(_watch = stop_signal())는 함수가 돌아올 때까지 산다. 쥐고 있는 것 자체가 뜻일 때 쓴다. 최상위 변수는 프로그램 끝까지 산다.

경계 사례와 에러

정의하기 전에 읽으면 에러다.

print(x)
x = 1
error[E0204]: undefined name `x`
  --> example.fung:1:7
  |
1 | print(x)
  |       ^ not found in this scope
  |

블록 안에서는 바깥 변수를 바꾸지 못한다. 블록의 값을 받아 대입한다.

total = 0
for x in [1, 2]:
  total = total + x
;;
print(total)
error[E0205]: cannot reassign `total` here: it was defined outside this block
  --> example.fung:3:3
  |
3 |   total = total + x
  |   ^^^^^
  |
 help: a block cannot change an outer variable; build the value with an expression instead, e.g. `x = if … ;;` or `fold`

최상위 fn 안의 블록도 같다. 상수 limit를 가리는 지역은 함수 본문의 맨 바깥 블록에서만 만들 수 있다.

limit = 10
fn clamp(n):
  if n > limit:
    limit = n
  ;;
  limit
;;
print(clamp(3))
error[E0205]: cannot reassign `limit` here: it was defined outside this block
  --> example.fung:4:5
  |
4 |     limit = n
  |     ^^^^^
  |
 help: a block cannot change an outer variable; build the value with an expression instead, e.g. `x = if … ;;` or `fold`

블록 안에서 만든 이름은 블록 밖에서 보이지 않는다.

if true:
  inner = 1
  print(inner)
;;
print(inner)
error[E0206]: `inner` is not visible here: it was defined inside a block
  --> example.fung:5:7
  |
5 | print(inner)
  |       ^^^^^
  |
 help: assign the block's value instead: `inner = if … ;;`

for의 변수도 for가 끝나면 사라진다. 같은 이름의 prelude 함수가 있어도 그것으로 돌아가지 않는다.

for line in ["a", "b"]:
  print(line)
;;
print(line)
error[E0206]: `line` is not visible here: it was defined inside a block
  --> example.fung:4:7
  |
4 | print(line)
  |       ^^^^
  |
 help: `line` is bound in a `for` body, only there; use the for's value instead: `xs = for … ;;`

대문자로 시작하는 이름은 태그라서 변수 이름이 될 수 없다.

Count = 1
print(Count)
error[E0225]: `Count` starts with an uppercase letter, so it is a tag and cannot name a variable
  --> example.fung:1:1
  |
1 | Count = 1
  | ^^^^^ this is a tag
  |
 help: name variables in lowercase: `{HOME: home} = cfg`, `max_retries = 3`

지역 fn은 바깥 인자를 복사하고 자기 자신을 부를 수 있지만, 같은 블록의 뒤에서 정의하는 fn은 부를 수 없다.

fn repeat(s, n):
  fn go(i) = i == 0 then "" else s + go(i - 1)
  go(n)
;;
print(repeat("ab", 3))
ababab
fn outer():
  fn a() = b()
  fn b() = 1
  a()
;;
print(outer())
error[E0208]: local function `b` is defined later in this block
  --> example.fung:2:12
  |
2 |   fn a() = b()
  |            ^
  |
 help: local functions can only call themselves; move both functions to the top level

최상위 fn의 이름은 상수라서 다시 정의하거나 대입할 수 없다.

fn f() = 1
fn f() = 2
print(f())
error[E0210]: function `f` is defined twice
  --> example.fung:2:1
  |
2 | fn f() = 2
  | ^
  |
fn f() = 1
f = 2
print(f)
error[E0209]: cannot reassign `f`: it is a function or an imported name
  --> example.fung:2:1
  |
2 | f = 2
  | ^
  |

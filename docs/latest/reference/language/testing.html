§레퍼런스언어 명세

테스트와 디버깅

test 블록, assert, dbg.

fn half(n) = n // 2

test "half rounds down":
  assert half(5) == 2
  assert half(-5) == -3
;;

# [파일:줄] half(10) = 5 를 표준 에러로 찍고 값을 돌려준다
x = dbg(half(10)) + 1
print(x)
[example.fung:9] half(10) = 5
6
  • test "이름": … ;;는 최상위에만 둔다. 이름은 보간 없는 문자열이고, 한 파일 안에서 겹치거나 비면 E0233이다(보고가 실패한 시험을 이름으로 알린다). fung run은 무시하고 fung test가 실행한다. 블록 하나가 실패해도 다음 블록이 돈다. 다만 exit(n)이 불리거나(띄운 태스크에서도) 교착이 보고되면 그 파일의 나머지 블록은 건너뛰고, 건너뛰기를 실패 하나로 센다.
  • test 본문은 함수 본문이라 return·?로 일찍 끝낼 수 있다(돌려준 값이 Err면 버려지는 Err라 E0606으로 실패한다).
  • assert 식은 어디서나 쓴다. 비교가 실패하면 양쪽 값을 보여 준다(E0807).
  • dbg(x)는 식의 소스 텍스트와 값을 찍고 값을 그대로 돌려준다.

경계 사례와 에러

assert가 거짓이면 식을 보이며 멈춘다(fung test 밖에서도 같다).

xs = [1, 2]
assert len(xs) == 2
assert len(xs) == 3
error[E0807]: assertion failed: len(xs) == 3
  --> example.fung:3:1
  |
3 | assert len(xs) == 3
  | ^
  |
  len(xs) = 2
 call path (innermost first):
   example.fung:3 <entry>

test 블록은 최상위에만 둔다.

fn f():
  test "inner": assert true ;;
  1
;;
error[E0114]: test must be at the top level
  --> example.fung:2:3
  |
2 |   test "inner": assert true ;;
  |   ^
  |

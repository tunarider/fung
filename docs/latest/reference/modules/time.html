time — 시각

import time. 지금 시각을 얻고, 글자로 된 시각을 읽고 쓰고, 시간대를 바꾼다. 시각은 언어의 값 타입이라 ==, <, t + 1h, t2 - t1이 바로 된다.

시각, 기간, 시간대

시간을 다루는 값은 두 가지다. 둘을 구분하는 것이 시간 계산의 첫걸음이다.

  • 시각(instant, time 타입): "2026년 10월 4일 9시 5분"처럼 시간 위의 한 점이다. time.now()나 time.parse로 만든다.
  • 기간(duration, dur 타입): "90분"처럼 두 점 사이의 길이다. 리터럴로 바로 쓴다: 500ms, 30s, 1h30m(기간 리터럴).

시각에 기간을 더하거나 빼면 시각이고, 시각에서 시각을 빼면 기간이다. 시각끼리는 ==·<로 비교한다.

import time

start = time.parse("2026-10-04T09:00:00Z")!
end = start + 1h30m
print(end, end - start, start < end)
print((end - start) / 1m, "minutes")
2026-10-04T10:30:00Z 1h30m true
90.0 minutes

같은 순간도 사는 곳에 따라 벽시계가 다르게 읽힌다. 런던에서 0시 5분일 때 서울은 9시 5분이다. 지역마다 정한 시계의 규칙이 시간대(time zone)이고, 기준이 되는 시계가 UTC(협정 세계시)다. 시간대는 UTC와의 차이인 오프셋(offset)으로 적는다: 서울은 +09:00, UTC 자체는 Z. 어떤 지역은 여름에 시계를 한 시간 앞당기는 서머타임(DST)이 있어서 오프셋이 철마다 바뀐다.

fung의 시각 값은 순간과 함께 시간대를 기억한다. 출력하면 ISO 8601 꼴(2026-10-04T09:05:07+09:00, UTC면 …Z)로 그 시간대의 벽시계와 오프셋을 보인다. 시간대가 달라도 같은 순간이면 ==는 참이다. 시간대를 정하지 않은 값은 컴퓨터의 로컬 시간대를 쓴다. 로컬 시간대는 환경 변수 TZ(없으면 /etc/localtime)로 정해진다. TZ는 Asia/Seoul 같은 이름(시간대 데이터베이스 $TZDIR나 /usr/share/zoneinfo에서 찾는다)이나 KST-9 같은 POSIX 시간대 문자열이고, ""·UTC면 UTC, 모두 실패하면 UTC다. 이 매뉴얼의 예제는 TZ=UTC로 돈다.

유닉스 시간(Unix time)은 1970-01-01T00:00:00Z부터 센 초의 수다. 로그와 API가 시각을 정수 하나로 주고받을 때 흔히 쓴다.

시각은 UTC 기준으로 0000년부터 9999년까지 나타낼 수 있다. 계산이 이 범위를 넘으면 런타임 에러 E0503이다.

형식 토큰

time.parse와 time.format의 format 인자는 토큰으로 모양을 적는다. 목록에 없는 글자는 그대로 쓰고 그대로 기대한다. 긴 토큰부터 맞춘다(MMM이 MM보다 먼저).

토큰뜻예
YYYY네 자리 연도2026
YY두 자리 연도(읽을 때 2000~2099)26
MM두 자리 월10
MMM영문 월 약자(읽을 때 대소문자 무시)Oct
DD두 자리 일04
ddd영문 요일 약자(읽을 때 이름만 검사하고 날짜와 대조하지 않음)Sun
HH두 자리 시(24시간제)09
mm두 자리 분05
ss두 자리 초07
SSS밀리초 세 자리123
Z오프셋(콜론 있음)+09:00
ZZ오프셋(콜론 없음)+0900

읽을 때는 자리 수를 정확히 맞춰야 한다(9:05는 HH:mm에 맞지 않는다). 12시간제(AM/PM)와 이스케이프는 없다.

함수

time.now

지금 시각을 돌려준다.

time.now()

설명

컴퓨터 시계의 지금 시각을 로컬 시간대로 돌려준다. 실행할 때마다 값이 다르다. 이 값은 시스템 시계를 읽은 것이고 단조 시계(앞으로만 가는 시계)를 함께 싣지 않는다. 그래서 두 now() 사이에 시스템 시각이 바뀌면(NTP 보정, 사람이 바꿈) t2 - t1로 잰 경과 시간이 틀리거나 음수일 수 있다. 짧은 작업의 시간 재기 정도에는 충분하다.

매개변수

없음.

돌려주는 값

time 값.

time.parse

글자로 적은 시각을 읽어 시각 값으로 바꾼다.

time.parse(s, format = nil)

설명

format이 없으면 RFC 3339(ISO 8601의 인터넷용 꼴)를 엄격하게 읽는다: 2026-10-04T09:05:07Z, 2026-10-04T09:05:07.5+09:00. 날짜와 시각 사이는 T(공백은 안 됨), 필드는 모두 두 자리, 소수 초는 .과 1~9자리, 끝에는 Z나 오프셋이 꼭 있어야 한다. T와 Z는 소문자도 된다.

format이 있으면 형식 토큰대로 읽는다. 형식에 시간대 토큰(Z·ZZ)이 없으면 로컬 시간대의 벽시계로 읽는다. 형식에 없는 날짜 필드는 0000-01-01, 시각 필드는 0으로 채운다. 숫자 오프셋으로 읽은 값은 그 오프셋을 그대로 기억한다.

로컬 시간으로 읽은 벽시계 시각이 서머타임 경계에 걸리면: 시계를 앞당겨 없는 시각(빈틈)은 빈틈만큼 뒤로 밀리고(02:30 → 03:30), 시계를 되돌려 두 번 있는 시각은 이른 쪽이다.

매개변수

  • s: 읽을 문자열.
  • format: 형식 문자열. nil이면 RFC 3339.

돌려주는 값

Ok(time).

에러

  • Err({kind: 'parse, message}): 형식에 맞지 않거나 범위를 넘는다(13월, 2월 30일). message는 cannot parse 2026-13-04T09:05:07Z as a time: month out of range처럼 이유를 담는다.
  • s가 문자열이 아니면 런타임 에러 E0403.

예제

RFC 3339

import time

print(time.parse("2026-10-04T09:05:07Z"))
print(time.parse("2026-10-04T09:05:07.5+09:00"))
print(time.parse("2026-10-04 09:05:07"))
Ok(2026-10-04T09:05:07Z)
Ok(2026-10-04T09:05:07.5+09:00)
Err({kind: 'parse, message: "cannot parse `2026-10-04 09:05:07` as a time: expected `T` between the date and the time"})

time.format

시각을 문자열로 쓴다.

time.format(t, format = nil)

설명

format이 없으면 ISO 8601 꼴이고, print·str·"${t}"도 같은 꼴을 쓴다. 소수 초는 0이 아닐 때만 붙는다. format이 있으면 형식 토큰대로 쓴다. 값이 기억하는 시간대의 벽시계로 쓰므로, 다른 시간대로 보이려면 먼저 time.utc나 time.local로 바꾼다.

매개변수

  • t: 시각.
  • format: 형식 문자열. nil이면 ISO 8601.

돌려주는 값

문자열.

time.utc

같은 순간을 UTC 시간대로 바꾼다.

time.utc(t)

설명

순간은 그대로 두고 시간대만 UTC로 바꾼다. 출력과 time.format·time.parts의 벽시계가 UTC 기준이 된다. 서버 여러 대의 로그를 합칠 때처럼, 시간대가 섞인 시각을 한 기준으로 맞출 때 쓴다.

매개변수

  • t: 시각.

돌려주는 값

UTC 시간대의 time 값.

예제

import time

seoul = time.parse("2026-10-04T09:05:07+09:00")!
u = time.utc(seoul)
print(u, u == seoul, time.parts(u).hour)
2026-10-04T00:05:07Z true 0

time.unix

시각을 유닉스 시간(초)으로 바꾼다.

time.unix(t)

설명

1970-01-01T00:00:00Z부터 t까지의 초를 정수로 돌려준다. 초 밑은 과거 쪽으로 내린다(23:59:59.5Z는 …59초). 1970년 전의 시각은 음수다. 시간대와 무관하다.

매개변수

  • t: 시각.

돌려주는 값

정수.

예제

import time

print(time.unix(time.parse("2026-10-04T09:05:07+09:00")!))
print(time.unix(time.parse("1969-12-31T23:59:59Z")!))
1791072307
-1

time.from_unix

유닉스 시간(초)을 시각으로 바꾼다.

time.from_unix(n)

설명

정수 n초를 로컬 시간대의 시각으로 돌려준다. 밀리초로 된 값은 n // 1000으로 나눠서 넘긴다.

에러

time.parts

시각을 연·월·일·시·분·초·요일로 나눈다.

time.parts(t)

설명

{year, month, day, hour, minute, second, weekday} 맵을 돌려준다. 값은 모두 정수이고 weekday만 심볼('mon 'tue 'wed 'thu 'fri 'sat 'sun)이다. 값이 기억하는 시간대의 벽시계 기준이다. "주말이면 건너뛴다", "매시 정각에만" 같은 조건에 쓴다.

매개변수

  • t: 시각.

돌려주는 값

맵.

예제

나누기

import time

print(time.parts(time.parse("2026-10-04T09:05:07+09:00")!))
{year: 2026, month: 10, day: 4, hour: 9, minute: 5, second: 7, weekday: 'sun}

주말 검사

import time

fn is_weekend(t) = time.parts(t).weekday in ['sat, 'sun]

json — JSON

import json. JSON 텍스트를 fung 값으로 읽고(parse), fung 값을 JSON 텍스트로 쓴다(stringify). 모든 글자를 훑는 일이라 네이티브 코드로 만들었다.

JSON이란

JSON(JavaScript Object Notation)은 데이터를 글자로 적는 형식이다. 웹 API의 응답, 설정 파일, 로그 한 줄 등 프로그램끼리 데이터를 주고받는 곳 대부분이 JSON을 쓴다. 생김새는 fung의 맵·리스트 리터럴과 거의 같다.

{"name": "web-1", "port": 8080, "tags": ["prod", "eu"], "healthy": true, "owner": null}

JSON 텍스트는 그냥 문자열이다. 문자열인 채로는 "port" 값을 꺼낼 수 없으므로, 먼저 fung 값(맵, 리스트, 숫자 …)으로 바꿔야 한다. 이것을 파싱(parsing, 읽기)이라 하고, 반대로 fung 값을 JSON 텍스트로 바꾸는 것을 직렬화(serialization, 쓰기)라 한다. json.parse와 json.stringify가 각각을 맡는다.

외부에서 오는 JSON은 깨져 있을 수 있으므로 json.parse는 결과값(Ok/Err)을 돌려준다. 반대로 json.stringify가 실패하는 것은 JSON에 없는 값(함수, 기간 등)을 넘긴 프로그램의 잘못이라 런타임 에러로 멈춘다(에러 규칙).

json.parse

JSON 텍스트를 fung 값으로 읽는다.

json.parse(s)

설명

s 전체가 JSON 값 하나여야 한다. 앞뒤 공백은 괜찮지만 값 뒤에 다른 글자가 남으면 Err다. 변환 규칙은 위의 표와 같다. 표준(RFC 8259)을 엄격하게 따른다: 끝의 쉼표([1, 2,]), 주석, 작은따옴표 문자열은 받지 않는다. 같은 키가 두 번 나오거나, 짝 없는 서로게이트 이스케이프(\ud800)가 있거나, 64비트 정수나 실수의 범위를 넘는 숫자가 있거나, 중첩이 10,000단계를 넘어도 Err다. 공백은 스페이스·탭·LF·CR만 공백이다.

파싱한 맵은 보통의 fung 맵이라 data.name이나 data["name"]으로 읽는다. 키가 없을 수 있으면 get으로 기본값을 준다.

매개변수

  • s: JSON 텍스트(문자열).

돌려주는 값

Ok(값).

에러

  • Err({kind: 'parse, line, col, message}): 형식이 틀렸다. line·col은 1부터 세는 문제 글자의 위치(열은 글자 단위)이고, message는 invalid JSON at line 1, column 9: expected a string for an object key처럼 위치와 이유를 담는다. 이유의 예: unexpected end of input, unexpected text after the value, duplicate key "a", number out of range, nesting too deep (limit 10000).
  • s가 문자열이 아니면 런타임 에러 E0403.

json.stringify, http.get, JSON API에서 필드 뽑기

json.stringify

fung 값을 JSON 텍스트로 쓴다.

json.stringify(v, indent = nil)

설명

v를 JSON 문자열로 바꾼다. 맵·리스트·문자열·정수·실수·true·false·nil은 위의 표대로 그대로 가고, 튜플은 배열, 심볼은 이름 문자열('ok → "ok"), 시각은 ISO 8601 문자열("2026-10-04T09:05:07Z")이 된다. 맵은 키 순서대로 쓴다. 실수는 늘 소수점을 붙인다(1.0). JSON에 대응하는 것이 없는 값(기간, 함수, 태그 Ok(1), 범위 range(…), 채널, atom 등)은 런타임 에러 E0513이다. 기간은 d / 1s처럼 숫자로, 범위는 map(r, x => x)처럼 리스트로 바꿔서 넘긴다.

indent가 없으면(또는 0) 공백 없는 한 줄이다. 숫자를 주면 그 칸 수로 들여 쓴 여러 줄이 된다(사람이 읽을 파일에). 문자열은 꼭 필요한 것만 이스케이프한다: ", \, U+0020 미만의 제어 문자. 한글 같은 비ASCII 글자는 그대로 둔다.

매개변수

  • v: 바꿀 값.
  • indent: nil(한 줄) 또는 들여쓰기 칸 수(0 이상의 정수).

돌려주는 값

JSON 문자열.

에러

  • 런타임 에러 E0513: JSON으로 바꿀 수 없는 값이 들어 있다(cannot convert dur to JSON).
  • 런타임 에러 E0403: indent가 음수다.
  • 런타임 에러 E0806: 결과가 1억 글자를 넘는다.

cli — 명령줄 옵션

import cli. 명령줄 인자를 옵션(--name value)과 나머지로 나눈다. 일부러 작게 만들었다. 값의 검사와 변환은 보통의 fung 코드로 한다. fung으로 썼다.

명령줄 인자와 옵션

터미널에서 fung deploy.fung --env prod --dry-run web-1 web-2처럼 스크립트를 실행하면, 스크립트 이름 뒤의 단어들이 명령줄 인자(command-line arguments)다. fung은 이것을 prelude 값 args에 문자열 리스트로 넣어 준다: ["--env", "prod", "--dry-run", "web-1", "web-2"]. 셸이 따옴표를 풀고 공백에서 나눈 뒤의 모습이다.

인자 중 --로 시작하는 것은 관례상 옵션(option, 플래그)이다. 옵션은 값을 하나 받거나(--env prod, --env=prod), 켜고 끄는 스위치일 수 있다(--dry-run). 옵션이 아닌 인자(web-1 web-2)는 보통 작업 대상이다. cli.parse는 이 관례대로 args를 옵션 맵과 나머지 리스트로 나눈다.

인자결과
--name valueflags.name = "value"(다음 인자가 --로 시작하지 않을 때)
--name=valueflags.name = "value"(값에 =가 더 있어도 첫 =에서만 나눈다)
--nameflags.name = true(다음 인자가 없거나 --로 시작할 때, 또는 bools에 있는 이름일 때)
--그 뒤는 --로 시작해도 모두 rest
그 밖(file.txt, -v, -)순서대로 rest

옵션 이름의 -는 _로 바뀐다(--dry-run → flags.dry_run). flags.dry_run처럼 점으로 바로 읽을 수 있게 하려는 것이다. 같은 옵션이 두 번 나오면 뒤의 것이 이긴다. 한 글자 옵션(-v)과 묶음(-xvf)은 따로 해석하지 않고 rest에 둔다.

왜 이렇게 작은가

cli는 도움말 생성, 필수 옵션 검사, 타입 변환을 하지 않는다. 그런 기능은 규칙이 많아 배울 것이 늘고, 스크립트마다 원하는 모양이 다르다. 대신 결과가 평범한 맵과 리스트이므로 get(flags, "port", "8080"), int(...), parse_dur, match로 필요한 만큼 직접 쓴다.

cli.parsefung으로 작성

명령줄 인자를 옵션 맵과 나머지 리스트로 나눈다.

cli.parse(argv, bools = [])

설명

argv를 앞에서부터 읽으며 위의 표대로 나눈다. 값은 언제나 문자열(값 없는 옵션은 true)이므로 숫자나 기간이 필요하면 직접 바꾼다. bools에 적은 이름(앞의 -- 없이, -는 그대로: "dry-run")은 값을 받지 않는 스위치로 다룬다. 이것이 없으면 --dry-run web-1의 web-1이 dry_run의 값이 되어 버린다.

없는 옵션을 flags.port로 읽으면 E0508(없는 키)이다. 선택 옵션은 get의 기본값으로 읽는다(get(opts.flags, "port", "8080")). opts.flags.port ?? "8080"은 ??에 닿기 전에 E0508로 멈춘다.

매개변수

  • argv: 문자열 리스트. 보통 args를 그대로 넘긴다.
  • bools: 값을 받지 않는 옵션 이름의 리스트.

돌려주는 값

{flags, rest} 맵. flags는 이름(문자열 키) → 문자열 또는 true, rest는 옵션이 아닌 인자의 리스트(순서 유지).

에러

  • argv가 리스트가 아니면 런타임 에러 E0601(맞는 패턴 없음).

예제

스크립트의 인자 나누기

실행 방법 
fung example.fung --env prod --dry-run web-1 web-2
import cli

opts = cli.parse(args, bools: ["dry-run"])
print(opts)
print(opts.flags.env, opts.rest)
{flags: {env: "prod", dry_run: true}, rest: ["web-1", "web-2"]}
prod ["web-1", "web-2"]

bools가 없으면

import cli

print(cli.parse(["--dry-run", "web-1"]))
print(cli.parse(["--dry-run", "web-1"], bools: ["dry-run"]))
{flags: {dry_run: "web-1"}, rest: []}
{flags: {dry_run: true}, rest: ["web-1"]}

기본값과 변환

실행 방법 
fung example.fung --retries 5 --timeout 2s report.csv
import cli

opts = cli.parse(args)
retries = int(get(opts.flags, "retries", "3"))
wait = parse_dur(get(opts.flags, "timeout", "30s"))!
verbose = get(opts.flags, "verbose", false)
print(retries + 1, wait, verbose, opts.rest)
6 2s false ["report.csv"]

§레퍼런스

모든 함수

import 없이 쓰는 prelude와, 이름으로 가져오는 표준 모듈. 모든 서명은 런타임의 실제 매개변수 표와 맞춰 본다(테스트가 지킨다).

읽는 법

  • f(a, b = 1, ...rest): b는 기본값이 있고 rest는 남는 위치 인자를 리스트로 받는다. 내장 함수도 이름 붙인 인자를 받는다: exec(cmd, cwd: "/tmp").
  • 모든 함수는 "대상이 첫 번째 인자"라서 파이프로 이어진다: xs |> filter(f) |> map(g)는 map(filter(xs, f), g)와 같다(파이프).
  • 외부 요인으로 실패할 수 있는 함수는 Ok(값)/Err({kind, message, …})를 돌려준다. kind는 심볼이다: 'not_found 'exists 'permission 'io 'parse 'invalid 'timeout 'closed 'cancelled 'error 'exit 'network.
  • 인자 타입이 틀린 것은 코드 오류라 런타임 에러(E0403)다.
  • fung으로 작성 표시는 fung 코드로 쓴 함수다. 나머지는 Rust로 구현했다(네 층).

import 없이 쓴다. 같은 이름의 변수나 함수를 만들면 경고(W0103)가 난다.

출력과 입력

  • print 인자들을 공백 하나로 이어 한 줄로 표준 출력에 쓴다.
  • eprint print와 같은 모양으로 표준 에러에 쓴다.
  • read_line 한 줄을 읽어 Ok(줄)을, 더 읽을 것이 없으면 Ok(nil)을 돌려준다.
  • read_lines 남은 줄을 모두 읽어 Ok(리스트)로 돌려준다.
  • dbg [파일:줄] 식 = 값을 표준 에러에 찍고 x를 그대로 돌려준다.

타입과 변환

  • type_of 값의 타입 이름을 심볼로 돌려준다.
  • int 문자열이나 실수를 정수로 바꾼다. 변환할 수 없으면 E0513.
  • float 정수나 문자열을 실수로 바꾼다. 변환할 수 없으면 E0513.
  • str 값을 문자열로 바꾼다. 문자열이면 그대로, 아니면 리터럴 모양의 문자열.
  • sym 이름 모양의 문자열을 심볼로 바꾼다(sym("ok") == 'ok).
  • parse_int 문자열을 정수로 읽어 Ok(정수) 또는 Err({kind: 'parse, message})를 돌려준다.
  • parse_float 문자열을 실수로 읽어 Ok(실수) 또는 Err({kind: 'parse, message})를 돌려준다.
  • parse_dur 기간 리터럴 문법의 문자열("1h30m", "500ms")을 Ok(dur) 또는 Err({kind: 'parse, message})로 읽는다.

  • range 범위 값을 만든다. range(n)은 0..n, range(a, b)는 a..b.
  • contains x in c와 같다: 리스트의 원소인지, 맵의 키인지, 부분 문자열인지.
  • map 각 원소에 f를 부른 결과를 모아 새 리스트로 돌려준다.
  • try_map f가 돌려준 결과값을 모아, 모두 Ok면 Ok(리스트), 아니면 처음 나온 Err를 돌려준다.
  • filter f(x)가 true인 원소만 모은 새 리스트를 돌려준다.
  • fold init에서 시작해 원소를 하나씩 f로 합쳐 값 하나로 접는다: f(f(init, x1), x2)….
  • each 각 원소에 f를 부르고 결과는 버린다. 출력이나 전송처럼 부수효과만 필요할 때 쓴다.
  • find f(x)가 true인 첫 원소를, 없으면 nil을 돌려준다.
  • any f(x)가 true인 원소가 하나라도 있으면 true.
  • all 모든 원소에서 f(x)가 true면 true. 빈 컬렉션은 true.
  • sort 작은 것부터 정렬한 새 리스트를 돌려준다.
  • sort_by f(x)를 키로 삼아 안정 정렬한 새 리스트를 돌려준다.
  • reverse 순서를 거꾸로 뒤집은 새 리스트를 돌려준다.
  • unique 처음 나온 순서를 지키며 중복을 뺀 새 리스트를 돌려준다.
  • flatten 리스트의 리스트를 한 단계만 펼친다: [[1, [2]], 3] → [1, [2], 3].
  • group_by f(x)를 키로 원소를 묶은 맵을 돌려준다.
  • zip 두 컬렉션의 원소를 차례로 짝지은 튜플의 리스트를 돌려준다.
  • sum 수의 합을 돌려준다. 빈 리스트는 0.
  • min 가장 작은 원소를, 비었으면 nil을 돌려준다.
  • max 가장 큰 원소를, 비었으면 nil을 돌려준다.

에러와 종료

  • fail 인자를 print처럼 이은 메시지로 런타임 에러(E0803)를 내고 멈춘다.
  • with acquire()로 얻은 것을 use에 넘기고, use가 어떻게 끝나든 release를 부른다.
  • exit 프로그램을 끝내고 종료 코드 code를 남긴다.
  • args 스크립트 경로 뒤의 명령행 인자를 담은 문자열 리스트. 함수가 아니라 값이다.

프로세스와 환경

  • exec 명령을 쉘 없이 실행하고 끝나기를 기다려 Ok({out, err, code})를 돌려준다. 0이 아닌 종료는 Err.
  • sh 문자열 cmd를 /bin/sh -c cmd로 실행한다. 파이프나 글로브 같은 쉘 기능이 필요할 때만 쓴다.
  • env 환경 변수 name의 값(문자열)을, 없으면 nil을 돌려준다. 인자가 없으면 전체를 맵으로.

동시성

  • scope 범위를 열고 f(s)를 부른다. 본문과 그 안의 태스크가 모두 끝나면 본문의 결과를 돌려준다.
  • supervise scope와 같지만 태스크의 런타임 에러가 다른 태스크나 본문에 번지지 않고 on_fail(e)로 간다.
  • spawn 범위 s 안에서 f()를 새 태스크로 띄우고 태스크 핸들을 돌려준다.
  • await 태스크가 끝나기를 기다려 그 결과를 돌려준다.
  • timeout f()를 부르되, d가 지나면 f 안의 모든 것을 취소하고 Err({kind: 'timeout})을 돌려준다.
  • cancel 태스크나 범위를 취소한다. 그 아래의 태스크에도 전파된다.
  • channel 채널을 만들고 두 끝 (tx, rx), 곧 보내는 끝과 받는 끝을 돌려준다.
  • send 보내는 끝 tx로 값 v를 보낸다. Ok(nil), 닫혔으면 Err({kind: 'closed}).
  • recv 받는 끝 rx에서 값 하나를 받는다. Ok(v), 닫혔고 남은 값이 없으면 Err({kind: 'closed}).
  • close 보내는 끝 tx의 채널을 지금 닫는다.
  • stop_signal 정지 요청을 받는 끝(receiver)을 돌려준다. 정지 요청이 오면 이 끝이 닫힌다.
  • request_stop 코드에서 정지 요청을 보낸다. 첫 신호(SIGINT·SIGTERM)와 똑같이 동작한다.
  • atom 값 v를 담은 칸(atom)을 만든다. 태스크 사이에 나누는 바뀌는 상태는 이것으로 둔다.
  • swap f(지금 값)으로 atom의 값을 바꾸고 새 값을 돌려준다. 여러 태스크가 동시에 바꿔도 갱신이 사라지지 않는다.
  • reset atom의 값을 v로 바꾸고 v를 돌려준다.
  • deref atom의 지금 값을 돌려준다. 기다리지 않는다.
  • sleep 기간 d만큼 기다린다. 그동안 다른 태스크가 돈다.

fs — 파일과 디렉터리

  • fs.read 파일 전체를 문자열 하나로 읽는다.
  • fs.read_lines 파일을 줄 리스트로 읽는다.
  • fs.write 파일에 문자열을 쓴다. 있던 내용은 지운다.
  • fs.append 파일 끝에 문자열을 덧붙인다.
  • fs.list 디렉터리 바로 안의 이름들을 돌려준다.
  • fs.glob 와일드카드 패턴에 맞는 경로들을 돌려준다.
  • fs.walk 디렉터리 아래의 모든 파일 경로를 하위 디렉터리까지 돌려준다.
  • fs.exists 경로에 무엇이 있는지 true/false로 알려 준다.
  • fs.stat 경로의 이름, 크기, 디렉터리 여부를 알려 준다.
  • fs.mkdir 디렉터리를 만든다. 위의 디렉터리도 없으면 함께 만든다.
  • fs.remove 파일 하나나 빈 디렉터리 하나를 지운다.
  • fs.remove_all 디렉터리를 안의 것까지 통째로 지운다.
  • fs.move 파일이나 디렉터리의 이름을 바꾸거나 다른 곳으로 옮긴다.
  • fs.copy 파일 하나를 복사한다.
  • fs.open 파일을 열어 핸들을 돌려준다.
  • fs.close 파일 핸들을 닫는다.
  • fs.write_line 핸들에 한 줄을 쓴다.
  • fs.with_open 파일을 열어 함수에 넘기고, 끝나면 무슨 일이 있어도 닫는다.
  • fs.with_temp_dir 임시 디렉터리를 만들어 함수에 넘기고, 끝나면 통째로 지운다.

time — 시각

regex — 정규식

  • regex.split 맞는 곳을 경계로 문자열을 나눈다.

http — HTTP

conc — 동시성 도우미

§레퍼런스prelude

결과값

실패할 수 있는 함수는 Ok(값)이나 Err(내용)을 돌려준다. Ok·Err는 평범한 태그다. 풀 때는 주로 ! ? ??나 match를 쓰고(문법), 이 페이지의 두 함수는 결과값을 가릴 때 쓴다.

결과값이란

파일 읽기, 수 읽기, 외부 명령 실행처럼 실패할 수 있는 일이 있다. 파일이 없을 수도 있고, 사용자가 "abc"를 포트 번호로 줄 수도 있다. 많은 언어는 이런 실패를 예외(exception)로 다룬다. 실패가 일어나면 지금 하던 일을 멈추고 어딘가의 try/catch로 튀어 간다. 어디서 튈지 함수 모양만 보고는 알 수 없다는 것이 단점이다.

fung은 실패를 값으로 돌려준다. 실패할 수 있는 함수는 성공하면 Ok(값)을, 실패하면 Err(내용)을 돌려준다. 이 둘을 결과값(result)이라고 부른다. 결과값은 평범한 태그 값이라 변수에 담고, 리스트에 넣고, 함수에 넘길 수 있다. 받은 쪽은 결과를 꺼내기 전에 성공인지 실패인지 정해야 하므로 실패를 모르는 사이에 지나치지 않는다.

표준 라이브러리의 Err 내용은 {kind: 심볼, message: 문자열, …} 맵이다. kind로 종류를 가리고('not_found, 'parse, 'timeout …), message를 사람에게 보여 준다.

print(parse_int("42"))
print(parse_int("abc"))
Ok(42)
Err({kind: 'parse, message: "not an integer: abc"})

결과값을 푸는 방법은 넷이다. 자세한 규칙은 결과값과 에러에 있다.

쓰는 법뜻어울리는 자리
r!Ok(v)면 v, Err면 프로그램을 멈춘다(E0603)스크립트의 맨 위: 실패하면 더 할 일이 없을 때
r?Ok(v)면 v, Err면 지금 함수가 그 Err를 돌려준다함수 안: 실패를 부른 쪽에 넘길 때
r ?? 기본값Ok(v)면 v, Err(나 nil)면 기본값실패해도 쓸 값이 있을 때
match r:Ok(v) =>와 Err(e) =>로 가른다실패의 종류마다 다르게 할 때
 
fn port_of(s):
  n = parse_int(s)?
  n > 0 and n < 65536 then Ok(n) else Err({kind: 'invalid, message: "out of range: ${n}"})
;;

print(port_of("8080"), port_of("x") ?? 80)
match port_of("70000"):
  Ok(p)  => print("port", p)
  Err(e) => print("bad:", e.message)
;;
Ok(8080) 80
bad: out of range: 70000

결과값을 쓰지 않고 버리면(문장으로 쓴 호출이 Err를 돌려주면) E0606으로 멈춘다. 실패를 조용히 넘기지 않기 위한 규칙이다. 일부러 버릴 때는 _ = 식으로 쓴다.

결과값과 다른 실패도 하나 있다. 런타임 에러는 코드가 틀린 경우(없는 키 읽기, 0으로 나누기, 타입이 틀린 인자)에 프로그램을 멈추는 것으로, 값으로 받을 수 없다. 에러 번호와 뜻은 에러 목록에 있다.

함수

is_okfung으로 작성

Ok(…)이면 true.

is_ok(x)

설명

type_of(x) == 'Ok와 같다. 결과값이 아닌 값(nil, 수 등)에도 에러 없이 false를 돌려준다. 하나의 결과값을 다룰 때는 match나 !·?·??가 낫다. is_ok는 결과값의 리스트를 거를 때 빛난다: rs |> filter(is_ok).

매개변수

  • x: 아무 값.

돌려주는 값

bool.

에러

없다.

예제

여러 값

print(is_ok(Ok(1)), is_ok(Err(1)), is_ok(nil), is_ok(42))
true false false false

성공한 것만 세기

inputs = ["80", "http", "443", ""]
rs = map(inputs, parse_int)
print(len(filter(rs, is_ok)), "of", len(rs), "parsed")
print(filter(rs, is_ok) |> map(r => r!))
2 of 4 parsed
[80, 443]

is_err, try_map, type_of

is_errfung으로 작성

Err(…)이면 true.

is_err(x)

설명

type_of(x) == 'Err와 같다. 결과값이 아닌 값에는 false다. 실패한 것만 모아 보고할 때 쓴다.

매개변수

  • x: 아무 값.

돌려주는 값

bool.

에러

없다.

예제

여러 값

print(is_err(Err("x")), is_err(Ok(1)), is_err(nil))
true false false

실패한 것만 보고하기

hosts = ["web-1", "web-2", "web-3"]
rs = map(hosts, h => exec(["sh", "-c", h == "web-2" then "exit 3" else "true"]))
bad = zip(hosts, rs) |> filter(((_, r)) => is_err(r)) |> map(((h, _)) => h)
print(len(bad), "failed:", bad)
1 failed: ["web-2"]

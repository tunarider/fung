regex — 정규식

import regex. 정규식으로 문자열에서 모양을 찾고, 꺼내고, 바꾸고, 나눈다. 문법은 RE2 계열이라 역참조와 전후방 탐색이 없는 대신 항상 선형 시간에 돈다.

정규식이란

정규식(regular expression, regex)은 "문자열의 모양"을 적는 작은 언어다. "숫자가 하나 이상", "ERROR로 시작하는 줄", "키=값 꼴" 같은 조건을 짧은 패턴으로 쓴다. grep, sed, 편집기의 찾기 기능이 쓰는 그것이다. 고정된 글자를 찾을 때는 prelude의 contains·split·replace가 더 간단하고 빠르다. 모양이 들쭉날쭉할 때 정규식을 쓴다.

자주 쓰는 문법:

패턴뜻
abc글자 그대로
.줄바꿈이 아닌 아무 글자 하나
\d \w \s숫자, 단어 글자(글자·숫자·_), 공백 하나. 대문자(\D …)는 그 반대
[abc] [a-z] [^0-9]괄호 안의 글자 하나, 범위, 여집합
x* x+ x?0번 이상, 1번 이상, 0번이나 1번
x{3} x{2,5}정확히 3번, 2~5번
^ $문자열의 처음과 끝((?m)을 붙이면 줄의 처음과 끝)
\b단어의 경계
a|ba 또는 b
(…)캡처 그룹: 맞은 부분을 따로 꺼낸다
(?P<name>…)이름 있는 캡처 그룹
(?:…)꺼내지 않는 묶음
(?i)대소문자 무시
\. \(특수 글자를 글자 그대로

문법은 Rust regex 크레이트의 것(RE2 계열)이다. 역참조(\1)와 전후방 탐색((?=…), (?<=…))이 없다. 그 대신 어떤 패턴과 입력이든 입력 길이에 비례하는 시간에 끝나므로, 외부 입력에 패턴을 돌려도 "끝나지 않는 정규식" 문제가 없다. \d·\w·\s·\b는 유니코드를 알아본다(아랍 숫자 ٣도 \d다). ASCII만 원하면 (?-u:\d)처럼 쓴다. 그룹 이름은 ASCII 글자·숫자·_이고 겹치면 안 된다.

패턴은 원시 문자열 … 로 쓴다. 보통 문자열 "…"에서는 \d가 모르는 이스케이프라 컴파일 에러이고, ${name}은 보간이 되어 버린다. 원시 문자열은 쓴 글자 그대로다.

위치는 글자 단위다. 매치의 start·end는 바이트가 아니라 글자(유니코드 코드 포인트) 인덱스이므로 s[m.start..m.end]가 그대로 맞는다.

잘못된 패턴은 프로그램의 잘못이므로 런타임 에러 E0515다(invalid pattern a(: unclosed group). 패턴의 중첩은 250단계, 컴파일한 크기는 128 MiB까지다. 컴파일한 패턴은 캐시되므로, 같은 패턴을 반복문에서 여러 번 써도 다시 컴파일하지 않는다. 따로 "컴파일된 정규식" 값을 만들 필요가 없다.

매치 맵

regex.find와 regex.find_all은 맞은 곳 하나를 다음 맵으로 준다.

키값
text맞은 부분 전체(문자열)
start end맞은 부분의 글자 인덱스(end는 마지막 글자 다음)
groups캡처 그룹의 리스트(전체 매치는 빼고, 순서대로). 잡히지 않은 그룹은 nil
named이름 있는 그룹의 맵(이름 → 문자열 또는 nil)

함수

regex.is_match

s의 어딘가에 패턴이 맞는지 알려 준다.

regex.is_match(s, pat)

설명

패턴이 s의 어느 부분에든 맞으면 true다. 문자열 전체가 맞아야 한다면 ^…$로 감싼다. 맞은 내용이 필요 없을 때 regex.find보다 간단하다. 이름이 match가 아닌 것은 match가 예약어이기 때문이다.

매개변수

  • s: 검사할 문자열.
  • pat: 패턴.

돌려주는 값

true 또는 false.

에러

  • 런타임 에러 E0515: 패턴이 잘못되었다.
  • 런타임 에러 E0403: s나 pat이 문자열이 아니다.

예제

로그 줄 고르기

import regex

lines = ["INFO ok", "ERROR disk full", "error: retry", "WARN slow"]
print(lines |> filter(l => regex.is_match(l, `(?i)^error`)))
["ERROR disk full", "error: retry"]

전체 모양 검사

import regex

fn is_host(s) = regex.is_match(s, `^[a-z][a-z0-9-]*-\d+$`)

print(is_host("web-1"), is_host("db-12"), is_host("Web-1"), is_host("web-1.example.com"))
true true false false

잘못된 패턴

import regex

print(regex.is_match("a", `a(`))
error[E0515]: invalid pattern `a(`: unclosed group
  --> example.fung:3:21
  |
3 | print(regex.is_match("a", `a(`))
  |                     ^
  |
 call path (innermost first):
   example.fung:3 <entry>

regex.find, contains, starts_with

regex.find

처음 맞는 곳을 찾아 매치 맵으로 돌려준다.

regex.find(s, pat)

설명

s에서 왼쪽부터 처음 맞는 곳 하나를 찾는다. 없으면 nil이다(실패가 아니라 "없음"이라 결과값이 아니다). 캡처 그룹으로 값을 꺼낼 때 쓴다. nil일 수 있으므로 m.groups를 읽기 전에 확인하거나 match로 나눈다.

매개변수

  • s: 찾을 대상 문자열.
  • pat: 패턴.

돌려주는 값

매치 맵 또는 nil.

에러

regex.is_match와 같다.

예제

이름 있는 그룹으로 꺼내기

import regex

m = regex.find("listen port=8080 proto=tcp", `(?P<key>port)=(?P<val>\d+)`)
print(m.named.key, int(m.named.val) + 1)
print(m.text, m.start, m.end)
port 8081
port=8080 7 16

없으면 nil

import regex

fn version(s) = match regex.find(s, `v(\d+)\.(\d+)`):
  nil => "unknown"
  m   => "major ${m.groups[0]}, minor ${m.groups[1]}"
;;

print(version("release v2.14 is out"))
print(version("nightly build"))
major 2, minor 14
unknown

글자 단위 위치와 잡히지 않은 그룹

import regex

m = regex.find("참치 42개", `(\d+)(개)?(마리)?`)
print(m)
print("참치 42개"[m.start..m.end])
{text: "42개", start: 3, end: 6, groups: ["42", "개", nil], named: {}}
42개

같이 보기

regex.find_all, regex.is_match

regex.find_all

겹치지 않는 모든 매치를 리스트로 돌려준다.

regex.find_all(s, pat)

설명

왼쪽부터 차례로 찾고, 한 매치가 끝난 자리에서 다음을 찾는다(겹치지 않는다). 앞 매치 바로 뒤의 빈 매치는 세지 않는다. 맞는 곳이 없으면 빈 리스트다. 각 원소는 매치 맵이다.

매개변수

  • s: 찾을 대상 문자열.
  • pat: 패턴.

돌려주는 값

매치 맵의 리스트.

에러

regex.is_match와 같다.

예제

숫자 모두 꺼내기

import regex

ms = regex.find_all("took 12ms, 340ms and 7ms", `\d+`)
print(ms |> map(m => int(m.text)) |> sum)
359

키=값 쌍을 맵으로

import regex

line = "user=kim role=admin  region=eu"
pairs = regex.find_all(line, `(?P<k>\w+)=(?P<v>\S+)`)
print(pairs |> fold({}, (acc, m) => put(acc, m.named.k, m.named.v)))
{user: "kim", role: "admin", region: "eu"}

로그 줄 나누기

import regex

log = ["GET /a 200", "POST /b 500", "junk", "GET /c 404"]
rows = log |> map(l => regex.find(l, `^(\w+) (\S+) (\d{3})$`)) |> filter(m => m != nil)
print(rows |> map(m => m.groups) |> filter(g => g[2] != "200"))
[["POST", "/b", "500"], ["GET", "/c", "404"]]

regex.replace

맞는 곳을 모두 바꾼 문자열을 돌려준다.

regex.replace(s, pat, repl)

설명

s에서 패턴이 맞는 곳을 모두 repl로 바꾼다(첫 곳만이 아니다). 맞는 곳이 없으면 s 그대로다. repl 안에서 캡처 그룹을 다시 쓸 수 있다.

repl 안의 표기뜻
$1 $2번호 그룹(1부터). $0은 전체 매치
${name}이름 있는 그룹
${1}번호 그룹, 뒤에 글자를 붙일 때
$$$ 글자 하나

$ 뒤의 이름은 가능한 한 길게 읽는다. 그래서 $1x는 "이름이 1x인 그룹"이고, 그런 그룹이 없으면 빈 문자열이 된다. 그룹 뒤에 글자를 붙이려면 ${1}x로 쓴다. ${…}를 쓰는 repl은 보간을 피하려고 원시 문자열 … 로 쓴다.

매개변수

  • s: 대상 문자열.
  • pat: 패턴.
  • repl: 바꿀 문자열.

돌려주는 값

바꾼 문자열.

에러

regex.is_match와 같다.

예제

날짜 꼴 바꾸기

import regex

print(regex.replace("2026-10-04, 2026-10-05", `(\d+)-(\d+)-(\d+)`, "$3/$2/$1"))
04/10/2026, 05/10/2026

비밀 가리기

import regex

line = "login user=kim password=hunter2 token=abc123"
print(regex.replace(line, `(?P<key>password|token)=\S+`, `${key}=***`))
login user=kim password=*** token=***

$1x와 ${1}x, $$

import regex

print(regex.replace("ab", `(a)`, "$1x"))
print(regex.replace("ab", `(a)`, `${1}x`))
print(regex.replace("cost 5", `(\d+)`, "$$$1"))
b
axb
cost $5
보통 문자열에 ${name}

regex.replace(s, pat, "<${w}>")처럼 보통 문자열에 ${w}를 쓰면 fung이 먼저 변수 w를 보간하려 해서 E0204(없는 이름)가 난다. 그룹을 가리키는 ${w}는 원시 문자열 <${w}> 에 쓴다.

같이 보기

replace(고정된 글자 바꾸기), 설정 파일 값 치환

regex.split

맞는 곳을 경계로 문자열을 나눈다.

regex.split(s, pat)

설명

패턴이 맞는 곳마다 잘라 그 사이 조각들의 리스트를 돌려준다. prelude의 split처럼 빈 조각도 남긴다(구분자가 맨 앞이나 맨 끝, 또는 연달아 있을 때). 문자열 맨 앞과 맨 끝의 빈 매치로는 자르지 않으므로 regex.split("abc", "")는 ["a", "b", "c"]이고, 빈 문자열을 빈 패턴으로 나누면 []다.

매개변수

  • s: 나눌 문자열.
  • pat: 구분자 패턴.

돌려주는 값

문자열 리스트.

에러

regex.is_match와 같다.

예제

여러 모양의 구분자

import regex

print(regex.split("web-1, web-2;db-1   cache-1", `[,;\s]+`))
["web-1", "web-2", "db-1", "cache-1"]

빈 조각

import regex

print(regex.split("a,,b,", `,`))
print(regex.split("  a  b ", `\s+`))
print(regex.split("abc", ""))
["a", "", "b", ""]
["", "a", "b", ""]
["a", "b", "c"]

빈 조각이 필요 없으면 filter(x => x != "")로 걸러 낸다.

내장 함수

import 없이 쓰는 prelude와, 이름으로 가져오는 표준 모듈. 모든 서명은 실제 매개변수 표에서 뽑았다.

읽는 법

  • f(a, b = 1, ...rest): b는 기본값이 있고 rest는 남는 위치 인자를 리스트로 받는다. 내장 함수도 이름 붙인 인자를 받는다: exec(cmd, cwd: "/tmp").
  • 모든 함수는 "대상이 첫 번째 인자"라서 파이프로 이어진다: xs |> filter(f) |> map(g)는 map(filter(xs, f), g)와 같다(파이프).
  • 외부 요인으로 실패할 수 있는 함수는 Ok(값)/Err({kind, message, …})를 돌려준다. kind는 심볼이다: 'not_found 'exists 'permission 'io 'parse 'invalid 'timeout 'closed 'cancelled 'error 'exit 'network.
  • 인자 타입이 틀린 것은 코드 오류라 런타임 에러(E0403)다.
  • fung으로 작성 표시는 fung 코드로 쓴 함수다. 나머지는 Go로 구현했다(네 층).

128개 함수

prelude: 늘 쓸 수 있는 함수

import 없이 쓴다. 같은 이름의 변수나 함수를 만들면 경고(W0103)가 난다.

출력과 입력

표준 출력·에러에 쓰고, 표준 입력이나 파일 핸들에서 줄을 읽는다.

print(...args)

인자들을 공백으로 이어 한 줄로 표준 출력에 쓴다. 문자열은 따옴표 없이, 나머지는 리터럴 형태로 찍는다. 태스크 여럿이 동시에 찍어도 줄이 섞이지 않는다.

print("total:", 3, [1, 2], 'ok)
eprint(...args)

print와 같지만 표준 에러에 쓴다.

read_line(f = nil)

한 줄을 읽어 Ok(줄), 끝이면 Ok(nil). 줄 끝의 \n·\r는 뗀다. f가 nil이면 표준 입력, 파일 핸들이면 그 파일. 닫힌 핸들이면 Err({kind: 'closed}).

read_lines(f = nil)

남은 줄 전부를 Ok(리스트)로. 규칙은 read_line과 같다.

dbg(x)

[파일:줄] 식 = 값을 표준 에러에 찍고 x를 그대로 돌려준다. 식의 소스 텍스트는 컴파일러가 채운다.

타입과 변환

int·float·str·sym은 잘못된 입력에 런타임 에러를 낸다(코드가 틀린 것으로 본다). 믿을 수 없는 입력은 parse_*로 검사한다.

type_of(x)

값의 타입 이름을 심볼로: 'int 'str 'list 'map 'fn …, 태그 값이면 태그 이름('Ok, 'Circle).

print(type_of(1.5), type_of(Ok(1)), type_of('x))
int(x)

문자열("42", "-1_000")이나 실수(0 쪽으로 버림)를 정수로. 변환할 수 없으면 E0513.

print(int("42") + 1, int(-3.9))
float(x)

정수나 문자열을 실수로.

str(x)

문자열이면 그대로, 아니면 리터럴 형태의 문자열.

sym(x)

이름 모양의 문자열을 심볼로(sym("ok") == 'ok).

parse_int(s)

Ok(정수) 또는 Err({kind: 'parse, message}). 공백은 허용하지 않는다.

print(parse_int("1_000"), parse_int("x"))
parse_float(s)

Ok(실수) 또는 Err('parse).

parse_dur(s)

기간 리터럴 문법(1h30m, 500ms, -5s, 앞뒤 공백 허용)을 Ok(dur) 또는 Err('parse)로. --timeout 30s 같은 옵션에 쓴다.

print(parse_dur("90s")!, parse_dur("soon"))

컬렉션

리스트를 받는 함수는 범위와 채널(닫힐 때까지 받는다)도 받는다. 원소를 도는 함수는 Go로, 그 위의 조합은 fung으로 썼다.

len(x)

문자열(글자 수), 리스트, 맵, 튜플, 범위의 길이.

print(len("참치"), len([1, 2]), len(0..10))
is_empty(x)fung으로 작성

len(x) == 0.

map(xs, f)

f(x)를 모은 새 리스트.

print([1, 2, 3] |> map(x => x * 10))
filter(xs, f)

f(x)가 true인 원소만. f는 bool을 돌려줘야 한다.

fold(xs, init, f)

왼쪽부터 접는다: f(f(init, x1), x2)…

print(fold([1, 2, 3], 0, (acc, x) => acc + x))
each(xs, f)

부수효과용 순회. nil을 돌려준다(for는 리스트를 만든다).

find(xs, f)

f(x)가 참인 첫 원소, 없으면 nil.

any(xs, f)

하나라도 참이면 true.

all(xs, f)

모두 참이면 true. 빈 리스트는 true.

sort(xs)

비교 표의 순서로 정렬한 새 리스트. 비교할 수 없는 값이 섞이면 에러.

sort_by(xs, f)

f(x)를 키로 안정 정렬. 내림차순은 키에 -를 붙이거나 reverse.

print(["bb", "a", "ccc"] |> sort_by(len))
reverse(xs)fung으로 작성

거꾸로 뒤집은 리스트.

unique(xs)fung으로 작성

처음 나온 순서를 지키며 중복을 뺀다.

flatten(xs)

한 단계만 펼친다: [[1, [2]], 3] → [1, [2], 3].

group_by(xs, f)

f(x)(문자열이어야 한다)를 키로 묶은 맵. 키와 각 목록은 처음 나온 순서.

print(group_by(["ab", "c", "de"], s => str(len(s))))
zip(xs, ys)fung으로 작성

짝지은 튜플의 리스트. 짧은 쪽 길이까지.

first(xs)fung으로 작성

첫 원소, 비었으면 nil.

last(xs)fung으로 작성

마지막 원소, 비었으면 nil.

take(xs, n)fung으로 작성

앞에서 최대 n개. 넘쳐도 에러가 아니다(슬라이스와 다른 점).

drop(xs, n)fung으로 작성

앞의 n개를 뺀 나머지. 넘쳐도 에러가 아니다.

range(a, b = nil)fung으로 작성

range(n)은 0..n, range(a, b)는 a..b.

sum(xs)fung으로 작성

숫자의 합. 빈 리스트는 0.

min(xs)fung으로 작성

가장 작은 값, 비었으면 nil.

max(xs)fung으로 작성

가장 큰 값, 비었으면 nil.

contains(c, x)fung으로 작성

x in c와 같다: 리스트 원소, 맵 키, 부분 문자열.

맵

맵은 불변이다. 아래 함수들은 모두 새 맵을 돌려준다.

get(m, k, default = nil)fung으로 작성

키가 있으면 값, 없으면 default. 맵이 아니면 에러.

print(get({a: 1}, "b", 0))
put(m, k, v)

k를 v로 둔 사본. 기존 키면 자리를 지킨다.

merge(a, b)

둘을 합친 사본. 같은 키는 b가 이긴다.

remove(m, k)

k를 뺀 사본. 없는 키면 그대로.

keys(m)fung으로 작성

키의 리스트(넣은 순서).

values(m)fung으로 작성

값의 리스트.

pairs(m)

(키, 값) 튜플의 리스트. for (k, v) in pairs(m):로 돈다.

문자열

인덱스와 길이는 글자 단위다.

chars(s)

글자 하나짜리 문자열의 리스트.

split(s, sep)

sep로 나눈다. 빈 조각도 남긴다. sep가 ""면 글자 단위.

print(split("a,,b", ","))
join(xs, sep = "")

원소를 sep로 잇는다. 문자열이 아닌 원소는 str로 바꾼다.

lines(s)fung으로 작성

줄 리스트. \n으로 나누고 줄 끝의 \r을 떼며, 마지막 줄바꿈은 빈 줄을 만들지 않는다. split(s, "\n") 대신 쓴다.

print(lines("a\nb\n"))
trim(s, cut = nil)

양 끝의 공백을, cut을 주면 그 글자들을 지운다.

print(trim("  x "), trim("--x--", "-"))
upper(s)

대문자로.

lower(s)

소문자로.

replace(s, old, new)

모든 old를 new로. 패턴이 필요하면 regex.replace.

starts_with(s, prefix)

접두사 검사.

ends_with(s, suffix)

접미사 검사.

repeat(s, n)

s를 n번 이어 붙인다("a" * 3은 없다).

pad_left(s, n, pad = " ")fung으로 작성

왼쪽을 pad로 채워 n글자로. 이미 길면 그대로.

print(pad_left("7", 3, "0"), "[" + pad_right("ab", 4) + "]")
pad_right(s, n, pad = " ")fung으로 작성

오른쪽을 채운다.

결과값

Ok·Err는 평범한 태그다. 풀 때는 주로 ! ? ??나 match를 쓴다(문법).

is_ok(x)fung으로 작성

Ok(…)이면 true.

is_err(x)fung으로 작성

Err(…)이면 true.

반복 패턴

while 대신 쓰는 꼬리 재귀 도우미들. 모두 fung으로 썼다.

until(x, f, pred)fung으로 작성

pred(x)가 참이 될 때까지 x = f(x)를 되풀이한 값.

print(until(1, x => x * 2, x => x > 100))
iterate(x, f, n)fung으로 작성

f를 n번 적용한 값.

retry(f, times = 3, delay = 0ms)fung으로 작성

f()가 Ok를 돌려줄 때까지 최대 times번, 사이에 delay만큼 쉬며 부른다. 모두 실패하면 마지막 Err.

에러와 종료

fail(...args)

인자를 print처럼 이은 메시지로 런타임 에러(E0803)를 낸다. "여기 오면 버그"를 말할 때 쓴다: x ?? fail("x is required").

at_exit(f)

프로그램이 끝날 때(정상, exit, 에러 모두) f()를 부른다. 등록의 역순으로 실행된다.

exit(code = 0)

어느 태스크에서 불러도 프로그램을 끝낸다. 남은 태스크는 취소되고 at_exit 핸들러가 돈 뒤 그 코드로 끝난다.

args

스크립트 경로 뒤의 명령행 인자(문자열 리스트). 함수가 아니라 값이다.

프로세스와 환경

명령은 쉘을 거치지 않는 exec가 기본이다. 종료 코드 0이 아니면 Err이므로 exec(…)!가 쉘의 set -e와 같다.

exec(cmd, cwd = nil, env = nil, stdin = nil)

cmd는 문자열 리스트(["git", "status"]). 성공하면 Ok({out, err, code}), 0이 아닌 종료는 Err({kind: 'exit, code, out, err, message}), 실행 파일이 없으면 Err('not_found). env는 현재 환경에 덧붙일 맵.

r = exec(["echo", "hi"])!
print(trim(r.out))
sh(cmd, cwd = nil, env = nil, stdin = nil)

/bin/sh -c cmd. 파이프나 글로브 같은 쉘 기능이 필요할 때만.

env(name = nil)

환경 변수 값(문자열) 또는 nil. 인자가 없으면 전체를 맵으로.

port = env("PORT") ?? "8080"
print(port)

동시성

태스크는 고루틴 위에서 돈다. 값은 불변이라 태스크 사이에 그냥 넘긴다. 바뀌는 상자는 atom뿐이다.

spawn(f)

f()를 새 태스크로 실행하고 태스크 핸들을 돌려준다. 취소는 자식 태스크에 전파된다. 태스크가 실패했는데 그 결과를 끝내 아무도 await하지 않으면 task failed:로 보고되고 종료 코드가 1이 된다. 보고 시점은 핸들이 버려져 GC가 알아챌 때나 프로그램이 끝날 때다. 핸들을 들고 있는 한 나중에 await해도 된다.

await(t, timeout = nil)

태스크의 결과. 정상 종료면 반환값, 런타임 에러로 죽었으면 Err({kind: 'error, message}), 취소됐으면 Err('cancelled), 시간이 지나면 Err('timeout). 여러 번 불러도 같은 결과.

t = spawn(() => 6 * 7)
print(await(t))
cancel(t)

태스크를 취소한다. 취소는 실패가 아니라 종료 코드에 영향이 없다.

channel(n = 0)

채널. n은 버퍼 크기이고, 0이면 받는 쪽이 있을 때까지 send가 막힌다. for와 map 등으로 닫힐 때까지 순회할 수 있다.

send(ch, v)

Ok(nil), 닫혔으면 Err('closed).

recv(ch, timeout = nil)

Ok(v), 닫혔으면 Err('closed), 시간이 지나면 Err('timeout).

ch = channel(1)
send(ch, "hi")
print(recv(ch)!)
close(ch)

채널을 닫는다.

atom(v)

바꿀 수 있는 상자.

swap(a, f)

잠금 아래서 f(현재 값)을 정확히 한 번 실행해 새 값으로 바꾸고 그 값을 돌려준다. f 안에서 같은 atom을 swap하면 E0703.

hits = atom(0)
each(1..=3, _ => swap(hits, n => n + 1))
print(deref(hits))
deref(a)

현재 값.

sleep(d)

기간만큼 기다린다. 취소되면 깨어난다.

pmap(xs, f, limit = 0)fung으로 작성

병렬 map. limit은 동시에 도는 태스크 수(0은 제한 없음). 결과 순서는 입력 순서.

print(pmap([1, 2, 3], x => x * x, limit: 2))
fan_in(chs)fung으로 작성

여러 채널을 하나로 모은 채널. 모두 닫히면 닫힌다.

모듈

표준 모듈은 이름으로 가져온다: import fs. 모두 실행 파일에 들어 있다.

fs — 파일과 디렉터리

import fs. 실패할 수 있는 연산은 Ok/Err를 돌려주고, Err의 kind는 'not_found 'exists 'permission 'io 중 하나다.

fs.read(path)

파일 전체를 Ok(문자열)로.

fs.read_lines(path)fung으로 작성

파일을 줄 리스트로(lines와 같은 규칙).

fs.write(path, text)

덮어쓴다. Ok(nil).

fs.append(path, text)

끝에 덧붙인다(없으면 만든다).

fs.list(dir, full = false)

디렉터리 안의 이름들(이름순). full: true면 dir을 붙인 경로.

fs.glob(pattern)

패턴에 맞는 경로들(정렬됨). * ? […].

fs.walk(dir)

아래의 모든 파일 경로(디렉터리 제외, 재귀).

fs.exists(path)

true/false(결과값이 아니다).

fs.stat(path)

Ok({name, size, is_dir}).

fs.mkdir(path)

중간 디렉터리까지 만든다.

fs.remove(path)

파일이나 빈 디렉터리를 지운다.

fs.remove_all(path)

디렉터리를 통째로 지운다.

fs.move(from, to)

이름을 바꾸거나 옮긴다.

fs.copy(from, to)

파일 하나를 복사한다(권한 유지).

fs.open(path, mode = 'read)

파일 핸들을 Ok(file)로. mode는 'read 'write 'append. 핸들은 태스크 사이에 공유해도 연산 단위로 직렬화된다.

fs.close(f)

닫는다. 닫힌 핸들에 읽고 쓰면 Err('closed).

fs.write_line(f, line)

핸들에 한 줄 쓴다.

fs.with_open(path, f, mode = 'read)fung으로 작성

열고 f(핸들)을 부른 뒤 결과가 무엇이든 닫고 그 결과를 돌려준다. defer 대신 쓰는 모양이다.

fs.with_open("notes.txt", fn(h):
  line = read_line(h)?
  print(line)
;;)
fs.with_temp_dir(f)fung으로 작성

임시 디렉터리를 만들어 f(경로)를 부르고 지운다.

path — 경로 계산

import path. 파일 시스템을 건드리지 않는 순수한 경로 연산이다.

path.join(...parts)

이어 붙이고 정리한다.

path.base(p)

마지막 요소: "a/b.txt" → "b.txt".

path.dir(p)

마지막 요소를 뺀 부분.

path.ext(p)

점을 포함한 확장자: "a.tar.gz" → ".gz".

path.stem(p)

확장자를 뺀 이름: "a.tar.gz" → "a.tar".

path.abs(p)

현재 디렉터리 기준 절대 경로(문자열).

cli — 명령행 옵션

import cli. fung으로 썼다.

cli.parse(argv, bools = [])fung으로 작성

{flags, rest}를 돌려준다. --name value, --name=value, 값 없는 --name(true)를 받고, bools에 있는 이름은 값을 먹지 않는다. -- 뒤는 전부 rest. 이름의 -는 _가 된다. 값은 문자열이므로 변환은 직접 한다.

import cli
opts = cli.parse(["--dry-run", "--n", "3", "a.txt"], bools: ["dry-run"])
print(opts.flags.dry_run, int(opts.flags.n), opts.rest)

json — JSON

import json. 파서는 성능 때문에 Go로 썼다.

json.parse(s)

Ok(값) 또는 Err({kind: 'parse, line, col, message}). 객체는 키 순서를 지키는 맵, 소수점·지수 없는 숫자는 정수(int64를 넘으면 Err), 그 외 숫자는 실수, null은 nil.

import json
data = json.parse(`{"name": "fung", "tags": ["a"], "n": 3}`)!
print(data.name, data.tags, data.n + 1)
json.stringify(v, indent = nil)

JSON 문자열. 튜플은 배열, 심볼은 문자열, 시각은 ISO 8601 문자열이 된다. 기간·함수·태그 등은 런타임 에러(E0513). indent는 들여쓰기 칸 수. HTML 이스케이프는 하지 않는다.

import json
print(json.stringify({ok: true, ids: (1, 2), at: 'now}))

time — 시각

import time. 시각은 언어의 값 타입이라 ==, <, t + 1h, t2 - t1(기간)이 바로 된다.

time.now()

현재 시각(로컬 시간대).

time.parse(s, format = nil)

Ok(time) 또는 Err('parse). 형식이 없으면 ISO 8601(RFC 3339). 범위를 넘는 값(13월, 2월 30일)은 Err.

import time
t = time.parse("2026-10-04 09:05", "YYYY-MM-DD HH:mm")!
print(time.format(t + 90m, "HH:mm"))
time.format(t, format = nil)

문자열로. 형식이 없으면 ISO 8601.

time.utc(t)

같은 순간을 UTC로.

time.local(t)

같은 순간을 로컬 시간대로.

time.unix(t)

유닉스 초(정수).

time.from_unix(n)

유닉스 초에서 시각으로(로컬 시간대).

time.parts(t)

{year, month, day, hour, minute, second, weekday}. weekday는 'mon…'sun.

regex — 정규식

import regex. Go의 RE2 문법이다: 역참조와 전후방 탐색이 없는 대신 항상 선형 시간에 돈다. 위치는 글자 단위 인덱스이고, 잘못된 패턴은 런타임 에러(E0515)다. 컴파일한 패턴은 캐시된다.

regex.is_match(s, pat)

맞는 곳이 있으면 true. (match는 예약어라 이 이름이다.)

regex.find(s, pat)

첫 매치 {text, start, end, groups, named} 또는 nil. groups는 캡처 그룹 리스트(안 잡힌 그룹은 nil), named는 이름 있는 그룹 맵.

import regex
m = regex.find("port=8080", `(?P<key>\w+)=(?P<val>\d+)`)
print(m.named.key, int(m.named.val) + 1)
regex.find_all(s, pat)

겹치지 않는 모든 매치의 리스트.

regex.replace(s, pat, repl)

모든 매치를 바꾼다. repl에서 $1, ${name}으로 그룹을 쓴다.

import regex
print(regex.replace("2026-10-04", `(\d+)-(\d+)-(\d+)`, "$3/$2/$1"))
regex.split(s, pat)

매치로 나눈다. 빈 조각도 남긴다.

http — HTTP

import http. 응답을 받았으면 상태 코드와 무관하게 Ok다(404도 Ok). 전송 실패는 Err('network), 시간 초과는 Err('timeout). 응답 헤더 키는 소문자다.

http.get(url, headers = {}, timeout = 30s)

Ok({status, headers, body}). timeout이 0s면 제한 없음.

import http
r = http.get("https://example.com")!
print(r.status, r.headers["content-type"])
http.post(url, body, headers = {}, timeout = 30s)

본문은 문자열(JSON은 json.stringify로).

http.request(method, url, body = nil, headers = {}, timeout = 30s)

임의의 메서드.

http.serve(addr, handler, ready = nil)

addr(":8080")에서 요청을 받으며 막힌다. 요청마다 새 태스크에서 handler(req)를 부른다. req는 {method, path, query, headers, body}, 응답은 문자열(200) 또는 {status = 200, headers = {}, body = ""}. 핸들러 에러는 500으로 답하고 서버는 계속 돈다. 끝내려면 서버 태스크를 cancel한다. ready는 리스닝 직후 실제 주소로 한 번 불린다(":0"의 포트를 아는 방법). 헤더는 10초 안에 와야 하고 본문은 16MB까지(넘으면 413).

import http
http.serve(":8080", req => match req.path:
  "/health" => "ok"
  _         => {status: 404, body: "not found"}
;;)

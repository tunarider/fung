# 02. 값과 타입

## 기본 값

| 종류 | 예시 | 비고 |
|------|------|------|
| 정수 | `42`, `1_000_000`, `0xff` | 64비트. 범위를 넘으면 에러 (조용히 넘어가지 않음) |
| 실수 | `3.14`, `1e9` | `/`는 항상 실수 결과, `//`는 정수 나눗셈 |
| 문자열 | `"a ${x}\n"`, `` `C:\raw` `` | 아래 참고. 글자 수준 규칙은 01 |
| 불리언 | `true`, `false` | |
| nil | `nil` | "없음"을 뜻하는 정상 값. 허용 연산은 아래 참고 |
| 심볼 | `'ok`, `'readonly` | Lisp식 quote 표기 |
| 기간 | `500ms`, `30s`, `1h30m` | 단위 `ms` `s` `m` `h` (05. 동시성 모델). 기간끼리 `+ -`, 숫자와 `* /`, 순서 비교 가능 |
| 시각 | `time.now()` | 리터럴 없음. `time.now()`·`time.parse`·`time.from_unix`로 만든다. 시간대를 보존한다. 출력은 ISO 8601. `==`·순서 비교, `+ - dur`, `time - time → dur` (07). 패턴 상수로는 쓸 수 없다 |
| 범위 | `0..10`, `0..=10` | 자체 타입의 **게으른** 값. 리스트를 미리 만들지 않는다 (07) |
| 파일 | `fs.open(p)!` | 열린 파일 핸들. **상태가 있는 자원**(읽을 때마다 위치가 움직이고, 닫으면 끝). `type_of` → `'file`, 출력은 `<file "경로">`. 06 참고 |

### 문자열

- `"..."`: `${}` 보간, 이스케이프 지원. `` `...` ``: 원시 문자열. (01. 문법 참고)
- 길이·인덱싱은 **글자(룬) 단위**. `len("참치") == 2`
- `s[0]`은 글자 하나짜리 **문자열**이다. 별도 문자 타입은 없다.
- 룬 단위라 `s[i]`는 O(n)이다. 글자를 훑을 때는 `chars(s)`로 리스트를 만든다.
- 순서 비교는 코드 포인트 순. 한글 가나다순과 일치하므로 일상 용도엔 충분하고, 로케일 정렬은 추후 라이브러리.

### 심볼

- 내용 없이 이름만 있는 값. 선언 없이 쓰는 열거형 값.
- 문자열과 다른 타입: `'ok == "ok"`는 거짓.
- 내부적으로 정수로 바뀌어 비교가 빠르다.

### nil

- 허용: `==` `!=`, `??`, `print`, 리스트 원소·맵 값·인자·반환값으로 담기.
- 그 외(산술, 순서 비교, 인덱스, 필드, 호출, `!`, `?`)는 즉시 런타임 에러. nil은 조용히 퍼지지 않는다.

## 자료구조

### 리스트

`[1, 2, 3]` — 같은 종류의 것이 몇 개든 모인 것. map/filter의 대상.

- 인덱스·슬라이스가 **범위를 벗어나면 런타임 에러.** 음수 인덱스는 뒤에서부터.
  느슨하게 잘라내려면 `take`/`drop`(범위를 넘어도 있는 만큼). Python식 슬라이스 클램핑은 "조용히 넘어가는 동작"이라 채택하지 않음.

### 맵

```
user = {name: "a", tags: [1, 2]}
user.name          # user["name"] 의 축약
get(user, "age", 0)
```

- **삽입 순서를 유지한다.** 순회·출력 순서는 넣은 순서와 같다. 단, `==`는 순서를 무시한다.
- 값이 같은 이름의 변수면 키만 쓴다 (2026-10-14): `{name, port}`는 `{name: name, port: port}`. 패턴도 같다: `{line, col} = e`는
  `line`·`col`을 묶는다. 예약어 키(`{type: t}`)와 문자열 키는 축약할 수 없다 — 그 이름의 변수가 있을 수 없으므로.
- 키는 **항상 문자열**. `{name: ...}`은 `{"name": ...}`의 축약. 식별자 모양이면 대소문자와 무관하게 축약할 수 있다
  (`{DB_HOST: 1}`, `m.DB_HOST`, 패턴 `{DB_HOST: v}`); 키 자리에는 값이 오지 않으므로 태그와 헷갈릴 일이 없다.
- 리터럴 안에서 같은 키를 두 번 쓰면(`{a: 1, a: 2}`) 컴파일 에러. 조용히 하나를 버리지 않는다.
- 없는 키 접근은 에러. 기본값이 필요하면 `get(m, "k", 기본값)` 또는 `??`.
- 수정된 사본은 **함수로만** 만든다: `put(m, "k", v)`, `merge(m, other)`, `remove(m, "k")`.
  `user |> put("name", "a")`처럼 파이프와 이어진다.
  - 기각: `with` 키워드 (예약어 추가, 중첩 갱신이 지저분), 리터럴 펼치기 `{...m, k: v}` (`merge`와 방법이 둘).

### 튜플

길이가 고정된, 자리마다 의미가 있는 묶음.

```
fn divmod(a, b) = (a // b, a % b)
(q, r) = divmod(7, 2)

match point:
  (0, 0) => "원점"
  (x, 0) => "x축 위"
  _      => "그 외"
;;
```

- 원소 하나: `(a,)`, 빈 튜플: `()`
- 지원하는 연산은 `==`, 순서 비교, 패턴 매칭, `len`뿐. **인덱스 `t[0]`는 없다.** 꺼낼 때는 패턴으로 이름을 붙인다.
  번호로 접근하고 싶은 데이터는 리스트다.

### 순회 대상

- `for`, `map`, `filter`, `fold` 등이 받는 것은 **리스트와 범위**뿐. (`for`는 채널도 받는다, 05.)
- 채널도 순회 대상이다: 닫힐 때까지 받은 값을 차례로 준다 (05).
- 문자열은 `chars(s)`, 맵은 `pairs(m)` · `keys(m)` · `values(m)`로 명시적으로 바꿔서 순회한다.
  맵을 바로 순회하면 "키인지 쌍인지", 문자열은 "글자인지 줄인지"를 언어가 추측해야 하므로 없앴다.
- `map`·`filter`의 결과는 입력이 범위여도 리스트다.

## 태그

- **대문자로 시작하는 이름은 태그 전용.** 변수·함수·모듈 이름은 소문자로 시작해야 한다.
- 선언 없이 바로 쓴다 (오타 책임은 작성자에게).

```
Circle(3)      # 태그 Circle, 인자 [3]
Rect(2, 5)     # 태그 Rect, 인자 [2, 5]
Red            # 인자 없으면 심볼 'Red
```

- 태그 값은 **튜플이 아니라 자체 타입**이다. 내부적으로 "이름 + 인자 목록".
- `type_of(Circle(3))`은 `'Circle` (타입 표기 `s: Circle`과 같은 이름). `type_of(Red)`는 `'sym`.
- 인자는 패턴으로만 꺼낸다. `.0` 같은 위치 접근은 없다.
- `Ok(x)` / `Err(e)`도 일반 태그. 특별 취급은 아래 축약 연산자에서만.

## 비교와 동일성

| 타입 | `==` | `<` 등 순서 비교 |
|------|------|------|
| int, float | 값. 섞이면 숫자로 (`1 == 1.0` 참). **정확 비교**: 2^53을 넘는 정수를 float64로 바꾸지 않고 판정한다 (Python과 같음. `9007199254740993 == 9007199254740992.0`은 거짓). M2에서 구현 | 값 (같은 규칙) |
| str | 글자열 | 코드 포인트 순 |
| bool, nil, sym | 값 | 에러 |
| dur | 값 | 값 |
| time | 같은 순간이면 참 (시간대 무관) | 순간 기준 |
| list, tuple | 길이 같고 원소가 차례로 `==` | 앞 원소부터 차례로. 앞이 전부 같으면 짧은 쪽이 작음 |
| map | 키 집합이 같고 각 값이 `==`. 삽입 순서 무시 | 에러 |
| 태그 값 | 이름 같고 인자가 차례로 `==` | 에러 |
| range | 시작·끝·포함 여부 같음 | 에러 |
| fn, module, file, task, channel, agent | **동일성** (같은 객체인가). `f == f` 참, `(x => x) == (x => x)` 거짓 | 에러 |
| 타입이 다를 때 | `false` (숫자끼리 제외) | 에러 |

`sort`, `unique`, `contains`, `in`은 모두 이 표를 따른다.

## 엄격함

- 암묵적 형변환 없음: `"5" + 3`은 에러, `int("5") + 3`으로 쓴다.
- 선언 안 한 변수는 컴파일 시점 에러.
- 처리 안 된 런타임 에러는 즉시 중단 + 호출 경로 출력 (08).

## 에러 처리와 축약 연산자

```
text = fs.read("a.json")!           # Err면 프로그램 중단 (스크립트용)
data = json.parse(text)?            # Err면 현재 함수에서 그 Err를 그대로 반환
port = env("PORT") ?? "8080"        # 왼쪽이 nil 또는 Err면 오른쪽 값
cfg = fs.read(p) ?? "{}" |> json.parse   # Ok(text)는 text로 풀린다
```

| 왼쪽 값 | `x!` | `x?` | `x ?? b` |
|------|------|------|------|
| `Ok(v)` | `v` | `v` | `v` |
| `Err(e)` | 프로그램 중단 (종료 코드 1) | 현재 함수에서 `Err(e)` 반환 | `b` |
| `nil` | 런타임 에러 | `nil` 그대로 (`?`는 Err만 본다) | `b` |
| 그 외 값 | 런타임 에러 | 런타임 에러 | 그 값 그대로 |

- `!`·`?`를 결과값이 아닌 값에 쓰는 것은 거의 확실히 버그(결과값을 돌려주지 않는 함수에 붙임)라 에러로 한다.
- `?`가 nil에 반응하지 않는 이유: nil은 실패가 아니라 "없음"이라는 정상 값이다. nil을 거르는 것은 `??`의 몫이고,
  nil 반환이 조용히 호출자로 퍼지는 동작은 엄격함 원칙에 어긋난다.
- `Err`의 내용은 **아무 값이나** 된다. 표준 라이브러리는 `{kind: 심볼, message: 문자열, …}` 맵을 쓰고 (06),
  사용자 코드에도 권장하지만 강제하지 않는다 (`return Err("없음")` 가능).
  `!`로 중단될 때는 내용이 `message` 키를 가진 맵이면 그 문장을, 아니면 리터럴 형태를 보여 준다.

# 배경과 결정 원칙

설계 대화에서 나온 맥락 중 각 섹션 문서에 담기지 않은 것을 모았다.
새 결정을 내릴 때 이 문서의 원칙을 기준으로 삼는다.

## 출발점

- 언어를 만드는 목적은 **공부 + 일상의 소소한 사용**. 본격 범용 언어가 아니다.
- "쉘 대용"의 의미: 쉘을 대체하려는 게 아니다. 파일 이름 여러 개 바꾸기 같은,
  평소 쉘 스크립트로 짜던 소소한 작업을 편하게 하려는 것. 본격 쉘 작업은 계속 쉘로 한다.
- 웹서버는 "간단한 것" 수준, GUI는 방식 무관하게 "추후에 만들 수 있는" 수준이 목표.
- 성능·안정성을 최우선으로 두지 않는다. 다만 효율·안정성 측면의 문제는 반드시 짚고 판단한다.

## 다른 언어에서 가져오고 싶었던 것

| 언어 | 좋아하는 점 | 결과 |
|------|------------|------|
| Go | 문법의 간결함 | 표면 문법의 기준 |
| Lisp | 함수형 파이프라인 구성 방식, 내부 구조 | 파이프 `\|>`, "겉은 Go, 속은 Lisp" 균일 트리, 심볼 `'sym`, 매크로 여지 |
| Node | 자유도 | 일단 채택 안 함. 세부 사항에서 필요하면 재논의 |
| PHP | "문법 에러만 아니면 아무튼 실행" 같은 편안함 | 부작용이 걱정되어 **버림**. 대신 엄격한 규칙. 단, 선택적 타입 표기를 런타임에 검사하는 방식만 PHP에서 가져옴 |

## 결정 원칙 (대화에서 반복된 판단 기준)

1. **엄격함 우선.** 조용히 넘어가는 동작(암묵 변환, truthiness, 정수 wrap, 없는 키 nil)은 에러로 만든다.
   예외: 대문자 이름 자동 태그는 "개발자가 알아서 잘 할 것"이라 믿고 선언 없이 허용.
2. **짧은 축약 문법을 좋아한다.** (`!` `?` `??` `then`, 짧은 함수 `=`, 람다 `=>`)
3. **괄호와 강제 들여쓰기를 싫어한다.** Python식 들여쓰기 강제는 절대 안 됨. 필요하면 한 줄로 쓸 수 있어야 한다 (JS 느낌).
   → `:` ~ `;;` 블록과 선택적 `;`가 여기서 나왔다 (Bash의 `;;`, OCaml의 `;;`와 닮음).
4. **Go는 내부에서 쓰되 겉으로 드러나지 않게.** 문법·용어·API·동작에 fung 고유의 자주성이 있어야 한다.
   단, 숨기는 대상은 이름과 의미이고, 효율·안정성을 위해 Go를 얇게 감싸는 것은 괜찮다.
5. **언어 핵심은 최소한, 나머지는 fung으로 직접.** (동시성 원시 연산, 2층 표준 라이브러리)
6. **같은 일을 하는 방법은 하나로.** (`#` 주석만, 문자열 `"`/`` ` `` 역할 분리, 맵 키는 항상 문자열)
7. **논리적으로 일관되게.** 매뉴얼을 기준으로 "이때는 이렇다, 저때는 저렇다" 같은 예외 조항이 적어야 한다.
   규칙 하나에서 결과가 따라 나와야 하고, 편의를 위해 특례를 더하는 것보다 규칙을 줄이는 쪽을 택한다 (2026-10-13 추가).

## 섹션별로 기각된 대안 (요약)

- 블록: 중괄호 `{}`, 들여쓰기 → `:` ~ `;;`
- 주석 `//` → 정수 나눗셈 `//`와 겹치고, 방법이 두 개가 되어 제외
- 삼항 `c ? a : b` → `?`, `:`와 충돌. `then ... else`로 대체
- 한 줄 if를 `if c: a, b`로 → 쉼표가 인자 구분과 충돌
- 심볼 `:ok` (Elixir) → `:`가 블록 시작이라 `'ok`
- 순수 함수형, 정적 타입 + 타입 추론 → 실용적 함수형 + 동적 타입
- 여러 절 함수, 자동 커링 → `match` 본문, `_` 부분 적용
- async/await, 액터를 언어 핵심에 → 태스크·채널·atom 원시 연산만
- `defer` → 에러를 잡는 구문이 없어 실익이 작고 꼬리 호출 최적화와 충돌. 감싸는 함수 + `at_exit`
- 최상위 `fn`이 최상위 변수를 호출 시점에 찾기 (C/Python식), 함수 정의와 함수 식의 스코프 규칙 분리 (Elixir식) → 예외 조항 없이 "함수는 만들어질 때 보이는 변수를 복사한다" 하나로 (03)
- 리플렉션 자동 Go 연결, Go 플러그인(.so) → 손으로 감싸기, 사용자 Go 확장 미개방
- 확장자 `.fg` → FaceGen과 겹치고, 명령 `fg`가 쉘 내장 명령과 충돌. `.fung` / `fung`

## 이름의 의미

- **fung**: 한국어 "펑"(빠르게 만들고 치고 빠진다는 느낌) + **fun**ction + **g**o.

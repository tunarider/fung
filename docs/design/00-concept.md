# 00. 기본 컨셉

## 목표

- 개인 학습용 + 실생활에서 소소하게 쓰는 언어. 본격 범용 언어가 목표가 아니다.
- 간단한 스크립트(파일 이름 일괄 변환 등). 진짜 쉘 작업은 계속 쉘 스크립트로 한다.
- 간단한 웹서버 구현 가능.
- GUI는 **언어가 직접 지원하지 않는다.** 필요해지면 별도 도구나 바인딩을 바깥에 붙인다.
  Go 표준 라이브러리에는 GUI가 없으므로, 그 시점에 "표준 라이브러리만" 원칙의 예외 여부를 정한다.
- 성능·안정성보다 **쓰기 편함** 우선.

## 구현 방식

- Go로 구현, 바이트코드 VM.
  - 트리 순회 인터프리터가 더 단순하다는 것을 알고 고른 선택이다. 목적이 컴파일러와 VM의 동작 원리를
    배우는 것이고, 꼬리 호출 최적화(아래)도 VM 쪽이 자연스럽다. 대신 M1~M3의 구현량이 두 배 정도 늘어난다.
- GC는 Go 런타임에 맡긴다. 동시성은 고루틴 기반.
- 파이프라인: 렉서 → 파서 → 균일 트리 → 코어 언어로 풀어내기(desugar) → 바이트코드 컴파일 → VM.

## 패러다임: 실용적 함수형

- 데이터는 불변, 함수는 일급, 값을 만드는 구문은 모두 식 (문장 자리와 식 자리를 구분하지 않는다. 선언과 대입만 문장. 01 참고).
- 부수효과(출력, 파일, 명령 실행)는 자유롭게 허용.
- 반복은 map / filter / fold / 재귀. `while`과 변수 변경에 기대는 루프는 없다.
  - 상태가 있는 반복(폴링, 재시도, 누적, 상태 기계)은 **꼬리 재귀**로 쓴다.
    따라서 꼬리 호출 최적화는 선택 기능이 아니라 이 결정의 전제 조건이다 (03).
  - 자주 쓰는 반복 패턴은 표준 라이브러리 함수(`retry`, `until`, `iterate` 등 후보)로 제공해
    재귀를 직접 쓸 일을 줄인다 (06).

## 타입

- 동적 타입 + 선택적 타입 표기.
- 타입 표기는 PHP처럼 런타임에 검사한다. 정적 검사기는 추후 별도 도구로 얹을 수 있게 둔다.
- 규칙은 엄격하다. PHP식 관대함(암묵 변환, 에러 무시 후 계속 실행)은 채택하지 않는다.

## "겉은 Go, 속은 Lisp"

- 작성하는 문법은 Go/Python 계열, 괄호 최소화.
- 파싱 결과는 S-표현식 같은 균일한 리스트 트리로 만든다 (Elixir, Julia 방식).
- 이를 작은 코어 언어(`if`, `fn`, `let`, `do`, `match`, `quote` 등)로 풀어낸 뒤 컴파일한다.
- 사용자 매크로는 당장 넣지 않지만, 넣을 수 있게 구조를 열어둔다.

```
total = sum(files)                         → (let total (sum files))
files |> filter(is_log) |> map(size)        → (map (filter files is_log) size)
if x > 0: a else: b ;;                     → (if (> x 0) a b)
```

## Go와의 관계

- 내부 구현에는 Go를 적극 활용한다 (GC, 고루틴, 표준 라이브러리).
- 사용자에게는 Go가 드러나지 않게 한다.
  - 문법·용어·API 이름은 fung 고유의 것으로 설계한다. Go 패키지를 1:1로 옮기지 않는다.
  - Go의 동작 특성이 그대로 새어 나오지 않게 한다 (맵 순회 순서, 정수 오버플로, 시간 형식 등).
  - Go 패닉과 Go 스택 추적은 사용자에게 보이지 않는다. 모두 fung 에러로 변환한다.
  - 사용자는 Go 도구 없이 `fung` 실행 파일 하나로 쓸 수 있다.
- 효율·안정성을 위해 얇게 감싸는 편이 나은 곳은 감싼다. 숨기는 대상은 이름과 의미이지, 구현이 아니다.

## 채택하지 않은 것

- 순수 함수형(Haskell식 부수효과 격리)
- `loop` / `recur` (Clojure식 변수 없는 반복 문법) → 키워드와 "꼬리 위치 검사"가 늘어난다. 재귀 + 라이브러리 함수로 충분
- `while` + 블록 안 지역 변수 재할당 → 익숙하지만 "실용적 함수형" 정체성이 흐려지고, `for` 안에서 `total = total + x`가 조용히 0이 되는 함정이 되살아난다
- PHP식 관대함
- Node식 자유도 (세부 사항에서 필요해지면 그때 재논의)
- 쉘 명령 전용 문법 (`exec(...)` 함수로 충분)

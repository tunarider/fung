값과 타입

값의 종류와 그 성질, 문자열·리스트·맵·튜플·태그·범위.

타입예설명
int4264비트 정수. 넘치면 에러.
float3.1464비트 실수. NaN·Inf가 되면 에러.
str"a"불변 바이트 열, UTF-8로 읽는 글자 단위 인덱스.
booltrue조건 자리에는 bool만 온다.
nilnil"없음"이라는 정상 값. ==, ??, 출력, 컬렉션에 담기 외의 연산은 에러.
sym'ok이름만 있는 값.
dur1h30m기간. 기간끼리 + -와 / // %, 숫자와 * /, 순서 비교.
timetime.now()시각. 리터럴 없음. ± dur, time - time은 기간, 순서 비교. 출력은 ISO 8601.
list[1, 2]순서 있는 목록.
map{a: 1}키는 항상 문자열. 넣은 순서를 지킨다.
tuple(1, "a")고정 개수. 원소는 패턴으로만 꺼낸다. 하나짜리는 (x,).
태그Ok(1) Circle(3)이름 + 인자. 타입 이름은 태그 이름 자체.
range0..10 0..=10게으른 정수 범위. 리스트를 미리 만들지 않는다.
fnx => x함수. 내장 함수도 같은 타입.
modulefs모듈의 공개 이름들로 된 불변 레코드.
filefs.open(p)!열린 파일 핸들. 상태가 있는 자원.
task scope sender receiver atomscope(s => spawn(s, f)), (tx, rx) = channel()동시성 값(내장 함수). 채널은 보내는 끝과 받는 끝 두 값으로 다룬다. atom은 값을 보이지 않고 <atom>으로 찍힌다(deref로 읽는다).

type_of(x)가 위 타입 이름을 심볼로 돌려준다: type_of(1) == 'int, type_of(Circle(3)) == 'Circle, type_of('red) == 'sym.

맵

  • {name: "a"}는 {"name": "a"}의 축약이다. 식별자 모양이면 대소문자와 상관없이 축약된다({DB_HOST: h}).
  • 값이 같은 이름의 변수면 키만 쓴다: {name, port}는 {name: name, port: port}. 대문자 키는 그런 변수가 없으므로 축약할 수 없다({HOME}은 E0225).
  • 같은 키를 두 번 쓰면 컴파일 에러. 없는 키를 읽으면 런타임 에러이고, 기본값이 필요하면 get(m, k, d)를 쓴다.
  • 수정된 사본은 함수로 만든다: put, merge, remove.

비교와 동일성

타입==< 등
int, float값. 섞여도 숫자로 비교(1 == 1.0), 253을 넘는 정수도 정확히값
str내용(바이트)바이트 순(UTF-8이면 코드 포인트 순과 같다)
dur, time값(time은 같은 순간이면 시간대 무관)값
list, tuple원소가 차례로 같음앞 원소부터 사전식
map키 집합과 값이 같음(순서 무시)에러
bool, nil, sym, 태그, range값에러
fn, module, file, task, scope, sender, receiver, atom같은 객체인가에러
타입이 다를 때false(숫자끼리 제외). 단 심볼과 문자열은 에러 E0517에러

sort, unique, contains, in은 모두 이 표를 따른다.

심볼과 문자열의 비교는 에러다. JSON·파일·명령 출력에서 온 값은 늘 문자열이라 back.kind == 'not_found가 조용히 거짓이 되는 것이 가장 흔한 함정이기 때문이다. 리스트·맵 안에서 맞붙어도, in도 같다. 문자열 쪽을 sym(s)로 바꾼다. 패턴('not_found =>)은 비교가 아니라서 그대로 맞지 않을 뿐이다.

경계 사례와 에러

맵의 키는 문자열이다. 다른 값을 키로 쓰면 바꾸라는 힌트와 함께 멈춘다(group_by의 키 함수도 문자열을 돌려줘야 한다).

print(group_by(["ab", "c"], s => "${len(s)}"))
print(group_by(["ab", "c"], s => len(s)))

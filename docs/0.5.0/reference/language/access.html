§레퍼런스언어 명세

인덱스·슬라이스·필드

x[i], x[a..b], x.name의 규칙과 범위 밖.

  • xs[i]: 음수는 뒤에서부터(xs[-1]). 범위를 벗어나면 에러.
  • xs[a..b], xs[..b], xs[a..], xs[a..=b]: 리스트와 문자열의 슬라이스. 범위를 벗어나거나 시작이 끝보다 뒤면 에러이고, 있는 만큼만 원하면 take·drop을 쓴다(리스트와 문자열 모두). 열린 끝은 비워 쓴다: 끝에 nil을 주면 에러다.
  • m.name은 m["name"]과 같다. 모듈의 fs.read도 같은 규칙이다.
  • 튜플은 인덱스로 꺼내지 않는다. 패턴으로 꺼낸다: (a, b) = pair.
xs = [10, 20, 30, 40]
print(xs[-1], xs[1..3], xs[..2], "참치김밥"[1..3])
40 [20, 30] [10, 20] 치김

경계 사례와 에러

인덱스는 범위 밖이면 에러다. 음수는 뒤에서 센다. 느슨하게 자르려면 take·drop.

xs = [10, 20, 30]
print(xs[-1], take(xs, 5), drop(xs, 1))
print(xs[3])
30 [10, 20, 30] [20, 30]

슬라이스의 시작이 끝보다 뒤면 범위 밖이 아니라 따로 에러다.

xs = [1, 2, 3]
print(xs[1..])
print(xs[2..1])
[2, 3]

없는 키의 필드는 에러다. 기본값이 필요하면 get.

m = {name: "a"}
print(get(m, "age", 0))
print(m.age)

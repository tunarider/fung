# 값과 이름

:::goals

- 값과 타입이 무엇인지, `type_of`로 타입을 보는 법
- 숫자(정수와 실수), 문자열, bool, `nil`, 심볼, 기간
- 타입을 바꾸는 법(`int`, `float`, `str`)과 fung이 저절로 바꿔 주지 않는 이유
- 이름에 값을 붙이는 대입과 이름 규칙
- 값은 바뀌지 않고, 이름이 다른 값을 가리킬 뿐이라는 것
- 블록 안에서 바깥 변수를 바꿀 수 없다는 규칙

:::

## 값과 타입 {#values}

프로그램이 다루는 데이터 하나하나를 **값(value)**이라고 한다. `42`도 값이고 `"web-1"`도 값이다. 값마다 **타입(type)**이 있다. 타입은 "이 값은 어떤 종류인가"이고, 그 값으로 무엇을 할 수 있는지를 정한다. 숫자끼리는 곱할 수 있지만 서버 이름끼리 곱하는 것은 뜻이 없다.

`type_of(값)`은 값의 타입 이름을 알려 준다.

```fung run
print(type_of(42), type_of(3.14), type_of("web-1"))
print(type_of(true), type_of(nil), type_of('ok), type_of(30s))
```

이름 앞의 `'`는 그것이 심볼이라는 표시다(아래에서 설명한다). 이 장에서는 위의 여섯 가지 타입을 다룬다. 여러 값을 묶는 리스트, 맵, 튜플은 7장에서 다룬다.

## 숫자 {#numbers}

fung의 숫자는 두 가지다.

- **정수**(`int`): `42`, `-7`, `1_000_000`. 소수점이 없는 수다. 긴 수는 `_`로 끊어 읽기 쉽게 쓸 수 있다.
- **실수**(`float`): `3.14`, `0.5`, `2.5e-3`. 소수점이 있는 수다. 소수점 양쪽에 숫자가 있어야 해서 `.5`가 아니라 `0.5`라고 쓴다.

```fung run
print(1 + 2, 10 - 3, 4 * 5)
print(7 / 2, 7 // 2, 7 % 2)
print(2 ** 10, 1_000_000, 1 + 2.0)
```

산술 연산자는 대부분 익숙한 그대로다. 나누기만 셋으로 나뉜다.

- `/`는 늘 실수를 낸다. `7 / 2`는 `3.5`, 나누어떨어져도 `4 / 2`는 `2.0`이다.
- `//`는 정수 나눗셈이다(소수점 아래를 내림). `7 // 2`는 `3`이다.
- `%`는 `//`의 나머지다. `7 % 2`는 `1`이다.

`**`는 거듭제곱이다. 정수와 실수를 섞어 계산하면 결과는 실수다.

fung은 숫자가 틀어지는 것을 그냥 두지 않는다. 0으로 나누면 에러로 멈추고, 정수가 담을 수 있는 범위(약 ±922경)를 넘어도 에러다. 많은 언어에서 넘친 정수는 조용히 음수로 돌아가 버리는데, fung에서는 그런 일이 없다.

```fung run exit=1 error=E0503
max = 9_223_372_036_854_775_807
print(max + 1)
```

실수는 컴퓨터 안에서 2진수로 저장되어서 10진수 소수를 정확히 나타내지 못할 때가 있다. 이것은 fung만이 아니라 거의 모든 언어가 같다.

```fung run
print(0.1 + 0.2)
```

## 문자열 {#strings}

**문자열**(`str`)은 글자들을 늘어놓은 값이다. 큰따옴표로 감싼다. `+`로 이어 붙이고, `len`으로 글자 수를 센다. 한글도 한 글자가 한 글자로 세진다.

```fung run
host = "web-1"
print("host: " + host)
print(len(host), len("서버"))
```

문자열은 6장에서 자세히 다룬다.

## bool {#bool}

**bool**은 참(`true`)과 거짓(`false`) 두 값뿐인 타입이다. 비교를 하면 bool이 나온다. `and`(둘 다 참인가), `or`(하나라도 참인가), `not`(반대로)으로 엮는다.

```fung run
usage = 91
print(usage > 90, usage == 100, usage != 0)
print(usage > 90 and usage < 95, not (usage > 90))
```

`==`는 같은지, `!=`는 다른지 묻는다. 대입의 `=`와 다르다는 데 주의한다. 조건에는 반드시 bool이 와야 한다. 다른 언어처럼 `0`이나 빈 문자열을 거짓으로 봐 주지 않는다. 조건은 4장에서 다룬다.

## nil: 없음 {#nil}

`nil`은 "값이 없음"을 나타내는 값이다. 빈 목록의 첫 원소처럼, 답이 없는 것이 정상인 경우에 돌아온다.

```fung run
print(first(["web-1", "web-2"]), first([]))
```

`nil`로 할 수 있는 일은 적다. `==`로 비교하기, 찍기, 그리고 `??`로 기본값 바꾸기 정도다. `a ?? b`는 `a`가 `nil`이면 `b`, 아니면 `a`다. 그 밖의 연산, 예를 들어 `nil + 1`은 에러다. "없는 값"이 조용히 `0`처럼 계산되어 퍼지지 않게 하기 위해서다.

```fung run
port = nil
print(port == nil, port ?? 8080)
print(3000 ?? 8080)
```

## 심볼 {#symbols}

**심볼**(`sym`)은 `'ok`, `'degraded`, `'not_found`처럼 `'` 뒤에 이름을 쓴 값이다. 이름 자체만 뜻이 있는 값으로, 몇 가지 정해진 상태 가운데 하나를 나타낼 때 쓴다. 미리 선언할 필요 없이 바로 쓴다.

```fung run
status = 'degraded
print(status, status == 'ok, status == 'degraded)
```

같은 일을 문자열 `"degraded"`로도 할 수 있지만, 심볼은 "프로그램 안에서 정한 이름"이고 문자열은 "바깥에서 온 글자"라는 차이가 있다. 그래서 fung은 둘을 섞어 비교하면 에러를 낸다(아래 "자주 하는 실수"). 9장에서 실패의 종류를 `'not_found` 같은 심볼로 구별하는 것을 보게 된다.

## 기간 {#durations}

**기간**(`dur`)은 시간의 길이다. 숫자 바로 뒤에 단위 `ms`(밀리초), `s`(초), `m`(분), `h`(시간)를 붙인다. 시간 제한이나 재시도 간격처럼 SRE 스크립트에 자주 나온다. 기간끼리 더하고 빼고, 숫자를 곱할 수 있다. 몇 분인지 숫자로 얻으려면 그 단위로 나눈다.

```fung run
timeout = 30s
print(timeout, timeout * 4, 1h30m, 90s)
print(1h30m // 1m, 2m > 90s)
```

## 타입 바꾸기 {#convert}

fung은 타입을 **저절로 바꾸지 않는다**. `"5" + 3`은 `8`도 `"53"`도 아니고 에러다. 파일이나 명령 출력, 명령줄 인자에서 온 값은 늘 문자열이라서, 숫자로 계산하려면 직접 바꿔야 한다.

```fung run exit=1 error=E0501
used = "91"
print(used + 1)
```

바꾸는 함수는 타입 이름과 같다.

```fung run
print(int("91") + 1, float("2.5") * 2)
print(str(42) + " servers", int(3.9), float(2))
```

- `int(x)`: 정수로. 실수는 소수점 아래를 버린다. 정수 모양이 아닌 문자열(`"abc"`, `"3.5"`)이면 에러로 멈춘다.
- `float(x)`: 실수로.
- `str(x)`: 어떤 값이든 문자열로.

사용자가 입력한 값처럼 숫자가 아닐 수도 있는 것을 바꿀 때는 멈추지 않고 실패를 돌려주는 `parse_int`를 쓴다. 그 결과를 다루는 법은 9장에서 배운다.

## 이름 붙이기 {#names}

값에 이름을 붙이면 나중에 그 이름으로 다시 쓸 수 있다. `이름 = 값` 꼴의 문장을 **대입(assignment)**이라고 하고, 이름을 **변수(variable)**라고 한다.

```fung run
disk_total_gb = 50
disk_used_gb = 45
free = disk_total_gb - disk_used_gb
print("free:", free, "GB")
```

이름의 규칙은 다음과 같다.

- 소문자나 `_`로 시작한다. 이어지는 글자는 글자, 숫자, `_`다. 한글 이름도 된다(`파일수 = 3`).
- 단어는 `_`로 잇는 것이 관례다(snake_case): `disk_used_gb`.
- **대문자로 시작하는 이름은 변수가 될 수 없다.** 대문자로 시작하는 것은 태그라는 다른 값이다(8장). `MAX_RETRIES = 3`은 E0225 에러다.
- `if`, `for`, `fn` 같은 **예약어(keyword)**는 이름으로 쓸 수 없다. 목록은 [레퍼런스](../reference/language.html#lexical)에 있다.
- 이름은 **쓰기 전에** 대입해야 한다. 아래 줄에서 대입할 이름을 위에서 읽으면 E0204다.

같은 이름에 다시 대입할 수도 있다. 그러면 그 이름은 새 값을 가리킨다.

```fung run
retries = 3
retries = retries + 1
print(retries)
```

## 값은 바뀌지 않는다 {#immutable}

fung에서 **값 자체는 절대 바뀌지 않는다**. 위의 `retries = retries + 1`도 `3`이라는 값을 `4`로 고친 것이 아니다. `retries + 1`로 새 값 `4`를 만들고, `retries`라는 이름표를 그 새 값에 옮겨 붙였을 뿐이다.

이 차이는 이름 두 개가 같은 값을 가리킬 때 드러난다. 문자열을 대문자로 바꾸는 `upper`는 원래 문자열을 고치지 않고 새 문자열을 돌려준다. 리스트에 원소를 더해도 새 리스트가 생긴다.

```fung run
name = "web-1"
loud = upper(name)
print(name, loud)

hosts = ["web-1", "web-2"]
all_hosts = hosts + ["db-1"]
print(hosts)
print(all_hosts)
```

`hosts`는 여전히 원소가 둘이다. 그래서 어떤 값을 다른 사람이 만든 함수에 넘겨도, 그 함수가 내 값을 몰래 바꿔 놓을 걱정이 없다. 12장에서 여러 일을 동시에 할 때도 이 성질 덕분에 값을 마음 놓고 나눠 쓴다.

## 상수 {#constants}

프로그램에서 한 번 정하고 바꾸지 않는 값을 **상수(constant)**라고 한다. fung에는 상수를 선언하는 따로 된 문법이 없다. 파일 최상위에서 **한 번만 대입한 이름**이 곧 상수다. 이름은 다른 변수와 똑같이 소문자로 쓴다.

```fung run
max_retries = 3
log_dir = "/var/log/app"
print(max_retries, log_dir)
```

상수와 두 번 이상 대입한 변수는 함수 안에서 볼 수 있는지가 다르다. 5장에서 다룬다.

## 블록은 바깥 변수를 바꿀 수 없다 {#blocks}

`:`로 열고 `;;`로 닫는 부분을 **블록(block)**이라고 한다. `if`(4장), `for`(4장), 함수 본문(5장)이 블록을 쓴다. 블록에는 규칙이 하나 있다.

**블록 안에서는 바깥 이름을 읽을 수 있지만, 바깥 이름에 다시 대입할 수는 없다.** 다른 언어에서 흔히 쓰는 아래 코드는 fung에서 컴파일 에러다.

```fung run exit=2 error=E0205
files = ["a.log", "b.log"]
count = 0
for f in files:
  count = count + 1
;;
```

블록 안에서 새로 만든 이름도 블록 밖으로 나오지 않는다(E0206). 대신 fung의 블록은 **값을 낸다**. 블록의 마지막 식이 그 블록의 값이다. 그래서 "블록 안에서 변수를 고친다" 대신 "블록이 낸 값을 대입한다"라고 쓴다. 위의 개수는 그냥 `len(files)`이고, 더 복잡한 계산은 4장의 `if` 식과 `fold`로 쓴다.

```fung run
files = ["a.log", "b.log"]
count = len(files)
usage = 91
level = if usage > 90: "critical" else: "ok" ;;
print(count, level)
```

## 짚고 넘어가기 {#notes}

:::box learn 변수는 상자인가, 이름표인가

프로그래밍 입문서는 변수를 흔히 "값을 넣는 상자"로 설명한다. 상자 안의 값을 꺼내 고쳐 넣을 수 있다는 그림이다. fung에는 **이름표** 그림이 맞다. 값은 한 번 만들어지면 그대로이고, 대입은 이름표를 어느 값에 붙일지 정할 뿐이다. 같은 값에 이름표 여러 개가 붙어 있어도, 값이 바뀌지 않으니 서로 영향을 줄 일이 없다.

:::

:::box mistake 블록 안에서 합계 쌓기 (E0205)

쉘이나 Python 습관대로 반복문 안에서 `total = total + x`를 쓰면 E0205다. 값이 바뀌지 않는 언어에서 이 코드를 허용하면, 블록 안의 대입은 바깥 변수를 고치지 못하고 **블록 안에 같은 이름의 새 변수를 만드는** 수밖에 없다. 그러면 반복이 끝난 뒤 바깥의 `total`은 조용히 `0`으로 남는다. 조용히 틀리는 대신 에러로 막은 것이다. 합계는 `sum(xs)`, 개수는 `len(xs)`, 그 밖의 누적은 4장의 `fold`로 쓴다.

:::

:::box mistake 심볼과 문자열 비교 (E0517)

`'ok == "ok"`는 거짓이 아니라 **에러**다. 파일, 명령 출력, JSON에서 읽은 값은 늘 문자열이라서, `state == 'ok`처럼 쓰면 조용히 늘 거짓이 되는 것이 가장 흔한 함정이기 때문이다. 문자열을 심볼로 바꿔 비교하려면 `sym(s) == 'ok`라고 쓴다.

```fung run
state = "ok"
print(sym(state) == 'ok)
```

:::

:::box mistake 대문자 상수 이름 (E0225)

다른 언어의 관례대로 `MAX_RETRIES = 3`이라고 쓰면 E0225다. fung에서 대문자로 시작하는 이름은 태그(8장)다. 상수도 `max_retries = 3`처럼 소문자로 쓴다.

:::

:::box other 다른 언어는

Python과 JavaScript는 `"5" + 3`을 각각 에러와 `"53"`으로 처리하고, 쉘은 모든 것이 문자열이다. fung은 Python처럼 에러를 내되, `0`·빈 문자열을 거짓으로 보는 것(truthiness)과 `None`·`undefined`를 조용히 계산에 쓰는 것도 막는다. 리스트를 제자리에서 고치는 `append` 같은 연산은 없다. 상수를 위한 `const` 키워드도 없다.

:::

## 해 보기 {#exercises}

:::exercise 디스크 사용률

디스크 전체가 `500` GB이고 `"437"` GB를 썼다(명령 출력에서 읽은 것이라 문자열이다). 사용률(%)과 남은 용량을 찍어 보자. 사용률은 실수로, 남은 용량은 정수로 찍는다.

:::solution

```fung run
total_gb = 500
used_gb = int("437")
print("usage:", used_gb / total_gb * 100, "%")
print("free:", total_gb - used_gb, "GB")
```

:::

:::

:::exercise 이름표 따라가기

아래 프로그램이 무엇을 찍을지 먼저 생각한 뒤 실행해 보자.

```fung run
a = [1, 2]
b = a
b = b + [3]
a = a + [9]
print(a, b)
```

:::solution

`b = a`는 같은 리스트에 이름표를 하나 더 붙인다. `b + [3]`과 `a + [9]`는 각각 **새** 리스트를 만들어 이름표를 옮긴다. 원래의 `[1, 2]`는 한 번도 바뀌지 않았으므로 `a`는 `[1, 2, 9]`, `b`는 `[1, 2, 3]`이다.

:::

## 정리 {#summary}

- 값마다 타입이 있다: `int`, `float`, `str`, `bool`, `nil`, `sym`, `dur` (그리고 7장의 리스트·맵·튜플).
- `/`는 실수, `//`는 정수 나눗셈, `%`는 나머지. 0 나누기와 정수 넘침은 에러다.
- fung은 타입을 저절로 바꾸지 않는다. `int`, `float`, `str`로 직접 바꾼다.
- `nil`은 "없음"이고, `??`로 기본값을 준다.
- 이름은 소문자로 시작하고, 쓰기 전에 대입한다. 최상위에서 한 번만 대입한 이름이 상수다.
- 값은 바뀌지 않는다. 대입은 이름표를 옮길 뿐이다.
- 블록 안에서는 바깥 이름에 대입할 수 없다(E0205). 블록이 낸 값을 대입한다.

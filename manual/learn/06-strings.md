# 문자열 다루기

:::goals

- 문자열이 글자의 나열이고, 길이와 위치를 글자 단위로 센다는 것
- 이스케이프와 보간 `${…}`
- 원시 문자열 <code>&#96;…&#96;</code>
- 인덱스와 슬라이스로 문자열의 일부를 꺼내는 법
- `split`·`join`·`trim`·`replace` 같은 자주 쓰는 함수
- 글자 수와 화면에 보이는 너비가 다를 수 있다는 것

:::

## 문자열은 글자의 나열이다 {#chars}

3장에서 본 대로 **문자열(string)**은 글자들을 늘어놓은 값이다. 글자마다 0부터 시작하는 위치 번호가 있고, `len`은 글자 수를 센다. fung은 글자를 **유니코드(Unicode)** 단위로 세므로, 한글 한 글자도 영문 한 글자와 똑같이 한 글자다.

```fung run
print(len("web-1"), len("참치김밥"), len("café"))
print(chars("web"), chars("서버"))
```

`chars(s)`는 문자열을 한 글자짜리 문자열들의 리스트로 바꾼다. fung에는 "글자" 타입이 따로 없고, 한 글자도 그냥 문자열이다.

문자열도 다른 값처럼 바뀌지 않는다. 아래의 모든 함수는 원래 문자열을 고치지 않고 **새 문자열을 돌려준다**.

## 이스케이프 {#escapes}

큰따옴표 문자열 안에서 따옴표 자체나 줄바꿈처럼 그냥 쓸 수 없는 글자는 `\`로 시작하는 **이스케이프(escape)**로 쓴다.

<table>
  <thead><tr><th>쓰는 것</th><th>뜻</th></tr></thead>
  <tbody>
    <tr><td><code>\n</code></td><td>줄바꿈</td></tr>
    <tr><td><code>\t</code></td><td>탭</td></tr>
    <tr><td><code>\r</code></td><td>캐리지 리턴(Windows 줄 끝의 앞 글자)</td></tr>
    <tr><td><code>\"</code></td><td>큰따옴표</td></tr>
    <tr><td><code>\\</code></td><td>역슬래시 하나</td></tr>
    <tr><td><code>\$</code></td><td>달러 기호(보간을 막는다)</td></tr>
    <tr><td><code>\u{1F600}</code></td><td>유니코드 번호로 쓴 글자</td></tr>
  </tbody>
</table>

```fung run
print("host\tstatus\nweb-1\tup")
print("say \"hi\"", "C:\\data", "price: \$5", "\u{D55C}")
```

이스케이프는 이 일곱 가지뿐이다. 모르는 이스케이프(`"C:\data"`의 `\d`)는 컴파일 에러 E0103이다. 큰따옴표 문자열 안에는 실제 줄바꿈을 넣을 수 없다. 여러 줄이 필요하면 `\n`을 쓰거나 아래의 원시 문자열을 쓴다.

## 보간: 문자열 안에 값 넣기 {#interpolation}

`"…${식}…"`은 식을 계산해서 그 자리에 끼워 넣는다. 이것을 **보간(interpolation)**이라고 한다. `+`로 이어 붙이는 것보다 읽기 쉽고, 문자열이 아닌 값도 알아서 글자로 바꿔 준다. `${…}` 안에는 어떤 식이든 쓸 수 있다.

```fung run
host = "web-1"
usage = 91
print("${host}: disk ${usage}%")
print("${host} has ${len(host)} chars, alert=${usage > 90 then "yes" else "no"}")
print("list: ${[1, 2]}, nil: ${nil}, sym: ${'ok}")
```

보간은 `str(x)`과 같은 모양으로 값을 글자로 바꾼다. 문자열은 따옴표 없이 그대로 들어가고, 리스트 안의 문자열은 따옴표가 붙는다.

`+`로 문자열을 이을 때는 양쪽 모두 문자열이어야 한다. `"port " + 8080`은 에러이고, `"port " + str(8080)`이나 `"port ${8080}"`으로 쓴다.

## 원시 문자열 {#raw}

역따옴표 <code>&#96;…&#96;</code>로 감싼 **원시 문자열(raw string)**은 쓴 그대로의 글자다. 이스케이프도 보간도 없고, 여러 줄에 걸쳐 쓸 수 있다. 역슬래시가 많은 정규식이나 Windows 경로, 여러 줄짜리 텍스트에 쓴다.

```fung run
pattern = `^\d{4}-\d{2}-\d{2}$`
path = `C:\logs\${app}`
banner = `== report ==
generated by fung`
print(pattern)
print(path)
print(banner)
```

큰따옴표는 "보간과 이스케이프가 되는 문자열", 역따옴표는 "쓴 그대로의 문자열"로 역할이 나뉜다. 작은따옴표 `'`는 문자열이 아니라 심볼(3장)이다.

## 인덱스와 슬라이스 {#slicing}

`s[i]`는 `i`번째 글자다. 번호는 0부터 센다. 음수는 뒤에서부터 세서 `s[-1]`이 마지막 글자다. `s[a..b]`는 `a`번째부터 `b`번째 **앞까지**를 잘라 낸 문자열로, 이것을 **슬라이스(slice)**라고 한다. 시작이나 끝을 비우면 처음이나 끝까지다.

```fung run
stamp = "2026-10-20T03:12:09Z"
print(stamp[0], stamp[-1])
print(stamp[0..4], stamp[5..7], stamp[..10], stamp[11..19])
print("참치김밥"[2..])
```

범위를 벗어나면 런타임 에러다. 조용히 짧은 문자열을 돌려주지 않는다. 길이를 모르는 문자열을 자를 때는 먼저 `len(s)`로 확인한다.

```fung run exit=1 error=E0507
code = "E05"
print(code[0..4])
```

## 자주 쓰는 함수 {#functions}

### 나누고 잇기: split, join, lines {#split-join}

`split(s, sep)`는 `sep`이 나올 때마다 잘라서 리스트를 만든다. 빈 조각도 남기므로, 공백이 여러 개 이어진 줄은 빈 문자열이 생긴다. `join(xs, sep)`은 반대로 리스트를 `sep`으로 잇는다. `lines(s)`는 줄 단위로 나눈다(`\r\n`도 처리하고, 마지막 줄바꿈은 빈 줄을 만들지 않는다).

```fung run
line = "2026-10-20 web-1 ERROR disk full"
fields = split(line, " ")
print(fields)
print(fields[2], fields[3..] |> join(" "))
print(split("a  b", " "), split("a  b", " ") |> filter(w => w != ""))
print(lines("web-1\nweb-2\n"))
print(join(["web-1", "web-2", "db-1"], ", "))
```

### 다듬기: trim, upper, lower, replace {#trim}

`trim(s)`은 양 끝의 공백과 줄바꿈을 지운다. 지울 글자를 줄 수도 있다. `upper`·`lower`는 대소문자를 바꾸고, `replace(s, old, new)`는 모든 `old`를 `new`로 바꾼다.

```fung run
print("[" + trim("  web-1 \n") + "]", trim("--web-1--", "-"))
print(upper("warn"), lower("ERROR"))
print(replace("db-1.prod.internal", ".prod", ".stage"))
print(replace("a,b,c", ",", "\t"))
```

### 묻기: starts_with, ends_with, in {#ask}

```fung run
name = "access-2026-10-20.log"
print(starts_with(name, "access"), ends_with(name, ".log"))
print("2026-10" in name, "error" in "Disk ERROR")
print("error" in lower("Disk ERROR"))
```

`in`은 대소문자를 구별한다. 대소문자를 무시하고 찾으려면 양쪽을 `lower`로 맞춘다. 패턴으로 찾고 바꾸는 일(숫자 여러 개, "어떤 글자든")은 정규식 모듈 [`regex`](../reference/modules/regex.html)가 맡는다.

### 채우기: repeat, pad_left, pad_right {#pad}

`repeat(s, n)`은 `s`를 `n`번 잇는다. `pad_left(s, n)`·`pad_right(s, n)`은 공백(또는 지정한 글자)으로 채워 `n`글자로 맞춘다. 표처럼 줄을 맞춰 찍을 때 쓴다.

```fung run
print(repeat("=", 24))
for (host, ms) in [("web-1", 12), ("web-2", 340), ("db-1", 7)]:
  print(pad_right(host, 8), pad_left(str(ms), 5), "ms")
;;
print(pad_left("7", 3, "0"))
```

`for (host, ms) in …`의 괄호는 둘씩 묶은 값(튜플)을 풀어 받는 것이다. 7장에서 다룬다.

## 글자 수와 화면 너비 {#width}

`len`이 세는 "글자"는 유니코드 **코드 포인트(code point)**, 곧 유니코드가 글자마다 붙인 번호 하나다. 이것은 화면에 보이는 모양과 늘 일치하지는 않는다.

- 터미널에서 한글·한자·일본어 글자는 영문 글자 **두 칸** 너비로 보인다. 그래서 `pad_right`로 글자 수를 맞춰도 한글이 섞이면 줄이 어긋난다.
- `é`는 한 글자로 쓸 수도 있고, `e`와 "위에 붙는 점" 두 코드 포인트로 쓸 수도 있다. 모양은 같아도 `len`이 다르고, `==`로 비교하면 다르다. 피부색이 붙은 이모지도 코드 포인트 여러 개다.

```fung run
print(len("é"), len("e\u{301}"), "é" == "e\u{301}")
for name in ["web-1", "데이터베이스"]:
  print(pad_right(name, 12) + "| up")
;;
```

두 번째 줄이 어긋나 보인다(브라우저 글꼴에 따라 덜 보일 수 있다). fung 소스의 정렬을 맞춰 주는 `fung fmt`는 화면 칸 수로 계산하지만, 문자열 함수의 `n`은 모두 글자 수다. 한글이 섞인 표를 맞춰야 하면 너비를 직접 계산한다. 아래 `width`는 한글 음절(`가`부터 `힣`까지)을 두 칸으로 센다. 문자열 비교가 코드 포인트 순서라는 점을 이용했다.

```fung run
fn width(s) = chars(s) |> map(c => "가" <= c and c <= "힣" then 2 else 1) |> sum
fn pad_cols(s, n) = s + repeat(" ", max([0, n - width(s)]))

for name in ["web-1", "데이터베이스", "캐시-1"]:
  print(pad_cols(name, 14) + "| up")
;;
```

## 짚고 넘어가기 {#notes}

:::box learn 글자는 어떻게 저장되나

컴퓨터는 글자를 숫자로 저장한다. **유니코드**는 세상의 글자마다 번호를 붙인 표다(`A`는 65, `가`는 44032). 그 번호를 바이트로 적는 방법 중 가장 널리 쓰이는 것이 **UTF-8**이고, 영문은 1바이트, 한글은 3바이트를 쓴다. fung의 문자열은 UTF-8로 저장하지만, `len`과 인덱스는 바이트가 아니라 번호(코드 포인트) 단위라서 한글을 반 글자로 자르는 일이 없다.

:::

:::box mistake 윈도우 경로의 역슬래시 (E0103)

`"C:\data\app"`은 `\d`를 모르는 이스케이프로 보고 컴파일 에러를 낸다. 더 고약한 것은 `"C:\new"`인데, `\n`은 줄바꿈이라 에러 없이 엉뚱한 문자열이 된다. 역슬래시가 들어가는 문자열은 원시 문자열 <code>&#96;C:\data\app&#96;</code>으로 쓰거나 `\\`로 쓴다.

:::

:::box mistake 문자열에 숫자 더하기 (E0501)

`"disk " + 91 + "%"`는 `cannot add str and int` 에러다. fung은 숫자를 저절로 글자로 바꾸지 않는다. `"disk ${91}%"`처럼 보간을 쓴다.

:::

:::box mistake 반복하며 문자열 쌓기

`fold(lines, "", (acc, l) => acc + l + "\n")`처럼 문자열을 조금씩 이어 붙이면, 매번 지금까지의 문자열 전체를 새로 만들어서 줄이 많으면 느려진다. 조각을 리스트로 모아 마지막에 `join`한다: `lines |> join("\n")`.

:::

:::box other 다른 언어는

Python의 f-문자열 `f"{host}: {usage}%"`이 fung의 `"${host}: ${usage}%"`이고, Python의 `r"…"`이 fung의 <code>&#96;…&#96;</code>다. 쉘의 `"$host"`와 달리 fung은 `${…}`만 보간하고, `$host`는 그냥 글자다. 쉘 `cut -d' ' -f3`은 `split(line, " ")[2]`, `tr a-z A-Z`는 `upper`, `sed 's/a/b/g'`는 `replace`다. Python의 `len`도 코드 포인트를 세지만, JavaScript의 `length`는 UTF-16 단위라서 이모지 하나가 2로 세진다.

:::

## 해 보기 {#exercises}

:::exercise 로그 한 줄 나누기

`"2026-10-20T03:12:09Z web-1 ERROR disk /var is 91% full"`에서 날짜(`2026-10-20`), 시각(`03:12:09`), 서버, 수준, 메시지를 꺼내 `[ERROR] web-1 2026-10-20 03:12:09: disk /var is 91% full` 꼴로 찍어 보자.

:::solution

공백으로 나눈 뒤 첫 조각을 슬라이스로 자르고, 네 번째 조각부터는 다시 잇는다.

```fung run
line = "2026-10-20T03:12:09Z web-1 ERROR disk /var is 91% full"
parts = split(line, " ")
stamp = parts[0]
date = stamp[..10]
clock = stamp[11..19]
message = parts[3..] |> join(" ")
print("[${parts[2]}] ${parts[1]} ${date} ${clock}: ${message}")
```

:::

:::

:::exercise 파일 이름 바꾸기

`["Access Log 2026.TXT", "error log.txt"]`의 각 이름을 소문자로 바꾸고, 공백을 `-`로, `.txt`를 `.log`로 바꾼 리스트를 만들어 보자. 결과는 `["access-log-2026.log", "error-log.log"]`이다.

:::solution

```fung run
names = ["Access Log 2026.TXT", "error log.txt"]
fn tidy(name) = name |> lower |> replace(" ", "-") |> replace(".txt", ".log")
print(names |> map(tidy))
```

:::

## 정리 {#summary}

- 문자열의 길이와 위치는 글자(코드 포인트) 단위다. 문자열은 바뀌지 않고, 함수는 새 문자열을 돌려준다.
- `"…"`는 이스케이프와 보간 `${식}`이 되고, <code>&#96;…&#96;</code>는 쓴 그대로이며 여러 줄이 된다.
- `s[i]`, `s[-1]`, `s[a..b]`, `s[..b]`, `s[a..]`. 범위를 벗어나면 에러다.
- 나누기 `split`·`lines`, 잇기 `join`, 다듬기 `trim`·`upper`·`lower`·`replace`, 묻기 `starts_with`·`ends_with`·`in`, 채우기 `repeat`·`pad_left`·`pad_right`.
- 글자 수와 화면 너비는 다를 수 있다. 한글은 두 칸이다.

레퍼런스: [문자열 함수](../reference/prelude/strings.html), [`split`](../reference/prelude/strings.html#fn-split), [`join`](../reference/prelude/strings.html#fn-join), [`trim`](../reference/prelude/strings.html#fn-trim), [`replace`](../reference/prelude/strings.html#fn-replace), [문자열 리터럴](../reference/language.html#lexical), [인덱스·슬라이스](../reference/language.html#access), [E0103](../reference/errors.html#E0103). 패턴으로 찾고 바꾸기는 [`regex`](../reference/modules/regex.html) 모듈에 있다.
